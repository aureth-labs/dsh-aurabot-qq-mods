# pet-home — 桌宠「小屋」场景素材

桌宠模块（`modules/pet`）「回小屋」复式场景窗的静态素材：白天/夜晚底图、家具分层图、姿势帧（a/b/c 各姿势）、
栏杆与补丁，以及场景布局 `manifest.json`。

## 用法

把本目录内容（`manifest.json` 与全部图片）放进数据目录 `modules-data/pet/house/`（目录即数据）即可。
没放素材时进屋会提示「素材未就绪」，不会白屏。后续版本计划照 `petPackUrl` 旧例支持自动下载落位。
