# 口袋aurabot（pocket）

把她的对话流接进你自己的手机 app。app 不是外挂，是她的第二个平台。

- **消息走原生流程**：app 发来的话会模拟成主人的私聊消息进入她原本的对话流——记忆召回、心情、表情包、语音、love-mode、其他模组全部照常生效。
- **记忆共用一套**：app 的聊天和 QQ 端落在同一条私聊流水（chatlog），每天的记忆整理照常把它提炼成长期记忆。换手机、卸载 app 都不丢记录。
- **主动搭话也能到手机**：speakup / autonomy 在 app 轮询在线时照常推过来。
- **手机宠物**：饱食度 / 心情 / 亲密度。装了「喂食」模组时直接读它的真实数值（饱食 = 100-饥饿、亲密度 = 好感度），你在 app 里喂她等于在面板上喂她；没装才用自己那套独立数值。
- **她的形象可换**：设置页「她的形象」从相册选一张图就能替换小窝头像（`/api/avatar`），随时一键恢复默认。
- **八套界面色调**：深海蓝 / 樱粉 / 薄荷绿 / 葡萄紫 / 落日橙 / 月白 / 深海夜 / 陈玫，面板里预设，手机端也能改；只换界面颜色，图标不动。

## 为什么模组自己开一个端口

DSH 面板那个端口要登录态，手机拿不到。所以模组自带一个局域网 HTTP 服务（默认 `7788`），同时托管 app 界面和 `/api/*` 接口。端口可在设置里改（改完重启插件）。

## 怎么装

1. 这个文件夹放进 `~/.dsh/plugins-data/aurabot/modules/`，面板「已安装」出现「口袋aurabot」即加载成功
2. 面板里点开「口袋aurabot」：先把「启用手机接口」打开（**默认是关的**），能看到配对链接、各条地址（每条都标了用途）、配对密钥、两种外网方案的开关，以及八套色调
3. 手机装 `口袋aurabot.apk`，配对页点「扫一扫电脑上的二维码」，扫面板上那个码就连上（地址和密钥自动填好）；没有相机、或者想用手机浏览器，也可以直接开配对链接 / 手填地址 + 密钥

在家同一个 WiFi 最省事；人在外面按下面的「在外面用」选一条路（面板上写得很全，照着点就行）。

安卓壳首次进 App 会申请**麦克风**和**相机**权限，点「📷 发图」/「从相册选」会直接弹系统选图（含拍照）。手机的页面跑在 `http://192.168.x.x` 这种非安全上下文里，浏览器不给用 `getUserMedia`，所以语音条走的是壳里的原生录音（`PocketMic` 桥），录完转 AAC 交给 `/api/voice-note` 识别；但走隧道（https）时浏览器有 `getUserMedia`，用手机浏览器直接开网页也能录音。

## 接口

界面走 `/`，接口走 `/api/*`，除 `/api/health` 外全部要配对密钥（请求头 `x-pocket-token`，或 URL 上带 `?token=`）。

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/health` | GET | 探活（配对用，不要密钥） |
| `/api/state` | POST/GET | 人格、心情、QQ 状态、宠物数值、当前色调 |
| `/api/message` | POST | `{ text }` 注入一条主人私聊消息；回复异步出现在 `/api/events` |
| `/api/events` | GET | `?after=<seq>` 增量拉她的回复、主动搭话、QQ 上下线 |
| `/api/history` | GET | `?days=3` 读她自己的 chatlog（只含主人私聊） |
| `/api/moments` | GET | 她的日记（diary 模组）+ 心情曲线（mood 历史） |
| `/api/pet` | POST | `{ action: feed/pet/play, food }` 投喂互动，返回反应和数值 |
| `/api/voice` | GET | `?text=…` 用她的语音模组合成一段 wav（音频直接回二进制） |
| `/api/skin` | GET | 当前人格对应的皮肤 |
| `/api/tone` | GET/POST | 读/换界面色调 |
| `/api/avatar` | GET/POST/DELETE | 小窝头像：GET 看当前、POST `{ image: dataURL }` 从相册换图、DELETE 恢复默认 |

面板侧同名接口挂在 `/aurabot/api/ext/pocket/` 下（要面板登录态），给面板自己读状态用。

## 在外面用（4G / 5G）

服务跑在家里电脑上，人在外面要有一条回家的路。面板「口袋aurabot」页会列出当前可用的地址并逐条标注用途，**外网方案都能在面板上直接操作**。

### 最省事的一条路（不想折腾就看这段，够用）

**什么都不用配**：面板点一次「启动隧道」，app 连上就完事。剩下的两件事模组自己会做：

- **隧道进程挂了会自动重启**：cloudflared 会自己悄悄退出（pid 还写着、进程已经没了、日志空着）。模组每 60 秒看一次，发现没了就拉起来，面板上显示「已重启 N 次」。所以「昨天还能连、今天不行」大多不再需要人管
- **换域名后手机自己更新**：临时隧道每次重启都换域名。app 每次连上电脑都会带走电脑当前的出门地址（`/api/state` 的 `endpoints`），**只要你在家连过一次 WiFi，它就自动记住新地址**，出门直接用——不用抄、不用填、也不用重新配对

所以普通用户的最短路径是：**装 app → 面板点「启动隧道」→ 在家连一次 WiFi → 出门就能用**。下面的 IPv6 / 固定域名 / Tailscale 都是给有特定需求的人看的。

什么时候才需要往下看：

| 你的情况 | 该用 |
| --- | --- |
| 家里没公网 IP、手机也没 IPv6 | 隧道（默认，什么都不用配） |
| 电脑经常重启、想一个地址用到老、或要把地址给别人 | 固定域名隧道 |
| 早就在用 Tailscale、账号登好了 | Tailscale |
| 手机套餐有 IPv6、光猫也放行过端口 | 公网 IPv6 直连（最快，不依赖第三方） |

1. **公网 IPv6 直连（地址固定，但门槛在手机侧）**
   - 现在三大运营商家宽基本都下发公网 IPv6，但**手机的流量不一定有 IPv6**（先在手机浏览器开 test-ipv6.com 确认；显示 0/10 就是纯 IPv4，这条路走不通）
   - 光猫 / 路由器里：开启 IPv6，防火墙放行 `7788`（Windows 侧也要放行入站，见下）
   - 手机填：`[240e:xxxx:xxxx::xxxx]:7788`（方括号不能少，这是 IPv6 的写法，不是可选装饰）
   - 建议把 IPv6 地址配成固定的（路由器里做 DHCPv6 静态分配），否则重启光猫可能会变
   - Windows 放行（管理员 PowerShell）：`New-NetFirewallRule -DisplayName "Pocket 7788" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 7788 -Profile Any`
     - 这一步模组替你做不了：改防火墙需要管理员权限，模组只是普通进程。跑一次就行，规则会一直留着
     - 不想敲命令：用群里的 `pocket-allow-7788.cmd`（双击自动提权，加完会顺便列出本机地址）
     - 360 / 火绒这类安全软件的「网络防护」也会拦入站，需要在它里面单独放行一次
2. **隧道（面板一键启动，任何网络都能连）**
   - 没装 cloudflared 时，面板按钮会变成「**一键下载 cloudflared**」——自动下到模块数据目录（`modules-data/pocket/bin/cloudflared.exe`），不需要管理员权限、不改系统 PATH、不用自己去 GitHub 找 releases。国内下不动时会自动换镜像重试，仍失败会给出手动放置的具体目录
   - 装好后点「启动隧道」，几秒后得到一个 `https://xxx.trycloudflare.com`，点「复制隧道地址」填进 app（也可以直接让 app 自动记，见上面「最省事的一条路」）
   - https 是真安全上下文：手机浏览器直接开这个网址也能用，且 `getUserMedia` 可用（语音条不依赖 app 原生录音）
   - 两种模式：**临时隧道**（默认，装好就能用，域名每次重启都换，但有守护 + app 自动同步）和**固定域名隧道**（进阶，域名恒定，见下）
3. **Tailscale（公司网络封端口、上面两条都走不通时的兜底）**
   - 电脑和手机都装，登同一账号，电脑会多出 `100.x.x.x`（模组会自动识别这个网段）
   - 填 `192.168.x.x:7788,100.x.x.x:7788`
   - **国内用之前要知道的三件事**（不是不能用，是别踩坑）：
     - **它自己就是 VPN**：手机上一开就占用了系统唯一的 VPN 槽位，**和代理 / 加速器不能同时开**——开 Tailscale 会把代理顶掉，反之亦然。所以"挂着梯子再用 Tailscale"这个组合在手机上不成立
     - **控制面和登录页在境外**：新设备首次登录（GitHub / Google 账号）在国内经常连不上或要反复重试。这一步过去之后，日常连接不再走登录页
     - **官方中继（DERP）没有中国大陆节点**，最近的是香港、东京、新加坡。两台机器打洞成功（`tailscale status` 里显示 `direct`）时流量不经过境外，速度就是你家宽带上行；一旦显示 `relay`，数据绕香港/东京一圈，延迟 150–300ms，网页能用、传图传语音会明显卡
   - 结论：**适合「已经在用 Tailscale、账号早就登好了」的人**；没装过的话优先用隧道——省掉登录这一步，也不用管中继。
   - 想要国内稳定，社区做法是自建中继（境内云主机跑 `derper`）或自建控制面（Headscale），那是另一套工程，不在这个模组的范围内
4. **公网 IPv4 + 端口映射**：需要运营商给公网 IPv4（多数家宽默认没有，要打电话要）

### 固定域名隧道（进阶，可以不弄）

**这一步是可选的。** 临时隧道已经有两层兜底（进程守护 + app 自动更新地址），普通用户不需要配这个。它只解决「想要一个永远不变的地址」：

临时隧道（`xxx.trycloudflare.com`）有两个硬伤：

- **每次 cloudflared 重启就换域名**——电脑重启、模组重载、进程被杀都算。手机里存的那条立刻失效，表现就是「昨天还能连、今天连不上」
- **没有 SLA**：官方定位就是「测试用」，进程偶尔会自己退出，而且不会留下任何日志（面板上表现为「未启动」，pid 还写着旧的）

固定域名隧道（Cloudflare named tunnel）解决这两点，免费，前提是有 **Cloudflare 账号 + 一个域名**（域名托管到 Cloudflare 即可，不需要额外付费服务）：

1. `dash.cloudflare.com` → **Zero Trust** → **Networks** → **Tunnels** → **Create a tunnel**（选 Cloudflared）→ 建好后复制那串 `eyJ…` 的 token
2. 在这条隧道里 **Add a public hostname**：Subdomain/Domain 填 `pocket.example.com`，**Service 填 `http://localhost:7788`**
3. 面板「固定域名隧道」区块：token 填第一栏，域名填第二栏（`pocket.example.com`，不要带 `https://`），点「保存并启动」

之后地址恒定，重启电脑也不会变。就绪判断不是猜的——模组会拿这个公网域名去请求一次 `/api/health`，通了说明域名解析、Cloudflare 指向、本机端口三样都对；30 秒不通会告诉你大概是哪一步没配好。

安全上做了两件事：token 走 `TUNNEL_TOKEN` 环境变量传入（**不出现在命令行**，任务管理器里看不到），也不会写进日志；它只存在模块设置里，跟配对密钥一样属于本机凭证。

### 外面的 WiFi 也会拦（公司、酒店、机场、商场）

不是自家网络时，"地址填对了也连不上"很常见，原因不在模组：

1. **要网页登录才放行**（访客网络、酒店、机场）——没点「同意 / 登录」之前什么都连不上，app 报 `P30`
2. **封高位端口**——企业网、校园网常只放行 80/443，IPv6 直连的 `7788` 直接不通（`P12` / `P15`），而隧道走 443 通常能过
3. **强制代理 / DNS 劫持**——域名被改写或中间解 TLS，报 `P17` / `P18`

所以在外面**优先用隧道**；反直觉但确实如此：自己手机开热点（纯蜂窝网络）往往比公司的 WiFi 更容易连上。

### 连不上怎么查（按顺序，两分钟能定位）

app 连不上时会在配对页**直接给出代号**（如 `P11`），并自动展开对应的处理办法。代号表：

| 代号 | 含义 | 谁的问题 | 常见原因 / 怎么修 |
| --- | --- | --- | --- |
| P11 | 局域网地址超时 | 手机 / 电脑 | 不在这个 WiFi、电脑防火墙没放行、手机开着 VPN |
| P12 | 公网 IPv6 超时 | 运营商 / 路由器 / 当前 WiFi | 手机没 IPv6；光猫没放行；**外面的 WiFi（公司、酒店、校园网）封 7788 这类高位端口** |
| P13 | 隧道域名超时 | 电脑 / 代理 | 电脑上隧道停了（重启后常见）；代理拦了 `trycloudflare.com` |
| P14 | 局域网地址不可达 | 手机 / 电脑 | 服务没开、换了网络、地址是旧的 |
| P15 | 公网 IPv6 不可达 | 运营商 / 路由器 / 当前 WiFi | 手机没 IPv6、连的 WiFi 只给 IPv4、地址变了 |
| P16 | 隧道域名不可达 | 电脑 | 隧道停了；DNS 被代理带偏 |
| P17 | 域名解析失败 | 手机当前网络 | 代理、私人 DNS、广告拦截改了 DNS |
| P18 | 证书不对（疑似被劫持） | 中间人 | 有代理或抓包软件在解 TLS |
| P19 | 地址格式不对 | 填写 | 端口写了两个、IPv6 少方括号、多了斜杠 |
| P21 | 密钥不对 | 填写 | 和面板上那条 `pk_` 开头的对不上 |
| P22 | 密钥试错太多被限流 | 安全机制 | 同一来源 60 秒内错 10 次，等一分钟 |
| P23 | 电脑接口没正常响应 | 电脑 | 端口被别的程序占了、服务没起来 |
| P24 | 电脑那边出错了 | 电脑 | 接口 5xx，看 DSH 日志 |
| P30 | 手机当前网络本身没通 | 手机当前 WiFi | 这个 WiFi 要网页登录才能上网（酒店 / 机场 / 商场），或根本没联网 |
| P99 | 未知原因 | — | 把原始报错一起发出来 |

编号有规律：**P1x = 路没通（手机 → 电脑）**，**P2x = 通了但被电脑拒**，**P3x = 手机当前网络本身有问题**。

**P30 是怎么判断的**：所有地址都失败后，app 会顺手访问一次外部地址（百度 / Cloudflare 的 204）。外部也打不开 → 你当前的 WiFi 根本没通网，先解决上网，别在地址上折腾。

最快的分层判断：手机浏览器直接打开 `http://电脑IP:7788/api/health`

- 看到 `{"ok":true,…}` → 网络是通的，问题在 app 里填的地址
- 打不开 / 一直转圈 → 网络层问题，和 app 无关

### 开关开着，但服务没起来（连 127.0.0.1:7788 也不通）

这跟网络无关，是电脑这边端口没在监听。面板顶部会直接标红 `服务没起来：<原因>`，并附一段启动流水账（哪次尝试、哪个端口、什么错），旁边有「重启服务」按钮——重抢一次端口，不用关整个模块。

| 原因 | 表现 | 处理 |
| --- | --- | --- |
| 端口被别的程序占了 | 面板显示「端口 7788 被占用，实际在 7789」 | 改端口，或关掉占用的程序（用 `netstat -ano` 找到 7788 对应的 PID） |
| 系统或网卡禁了 IPv6 | 流水账里有 `EAFNOSUPPORT` / `EADDRNOTAVAIL` | 模组会自动退回只监听 IPv4，面板标「仅 IPv4」；此时公网 IPv6 直连不可用，改走隧道 |
| 模块没装完整 | `前端文件缺失（…）` | 在市场里删掉重装 |
| 改过模块文件但没重载 | 流水账里没有新记录 | **DSH 对服务类模块的热重载不总生效**：把面板开关关一下再开，或重启 DSH |

流水账落在模块数据目录的 `boot.log`（如 `~/.dsh/plugins-data/aurabot/modules-data/pocket/boot.log`），只保留最后一段，出问题直接看它。

#### 面板上出现「要重启才生效」的橙色提示

这不是故障，是模组自己发现的：**磁盘上的文件比正在跑的这一份新**——你更新了模组（或改过代码），但 DSH 没有重新加载它。DSH 对会开端口这类模组的热重载不总生效（旧实例卸了、新实例没接上），表现就是「改完界面一点变化都没有」，点「重启服务」也没用（那只重开端口，不换代码）。

判断依据两条，命中任一就提示：

- `index.mjs` 的修改时间比本次启动晚 2 秒以上
- `module.json` 里的版本号与内存中正在跑的版本不一致

处理：把面板上「启用手机接口」开关关一下再打开；还不行就重启 DSH。重启后提示自动消失（`boot.log` 里会多一条新的「模块加载 v…」）。注意重启会停掉隧道，手机端地址可能要重新填。

**多地址一起填，逗号隔开**，比如 `192.168.1.5:7788, [240e::1]:7788`。
app 的地址解析认这几种写法：`192.168.1.5` / `host:7788` / `[240e::1]:7788` / `https://域名`，
启动和请求失败时会挨个探活，谁通自动用谁 —— 在家走局域网、出门切 IPv6、回来再切回来，不用手动改。

> 无论哪种，接口都有配对密钥门禁。把服务暴露到公网时密钥务必保留、别太短。

## 安全边界

- **默认关闭**：手机接口默认是关的，要在面板里手动开；关掉立即全部 401/403，QQ 端不受影响
- **密钥门禁**：所有数据接口都要配对密钥（`x-pocket-token`），密钥在面板显示/重置，留空自动生成；比较用常量时间算法（防时序侧信道），同一来源 60 秒内错 10 次直接 429 限流；启动日志里密钥脱敏（只露前两位）
- **探活接口最小化**：`/api/health` 只返回 ok/版本/端口/色调，不含人格名、主人名等信息
- **范围收死**：消息只能注入 `private:<主人QQ>` 这一个会话，接口发不了别人、发不了群、动不了 OneBot
- **只读她的数据**：历史只读 chatlog；写路径只有两条——走她正常对话流程、宠物互动写一条 `addEvent`
- **CSRF**：POST 必须 `application/json` + 自定义头
- **路径穿越**：静态文件只允许 `app/` 目录内的文件
- **子进程声明**：`capabilities` 含 `process`，只用来拉起 cloudflared 隧道（面板一键启停），不执行其他外部程序
- **联网声明**：只在局域网监听，不主动外联；`capabilities` 含 `filesystem`（读写自身 dataDir 与 chatlog）、`plugin-config`（读人格/主人配置）、`plugin-internals`（hub / mood / diary / memory / voice 模组导出）、`network`（开自己的局域网服务）

## 已知取舍

- 她的回复在 QQ 网关在线时会同时发到 QQ（同一个她，两块屏幕）。想只走手机，把 QQ 网关退出登录
- 配对二维码最多装 134 字节：隧道域名太长时会自动退回「只带密钥」的短码（地址就是码里的网址本身）；再长就只剩「复制配对链接」可用
- 网页版（手机浏览器直接打开）录不了语音：`http://192.168.x.x` 不是安全上下文，浏览器不给麦克风。要语音就装 apk，或用隧道 https 地址
- 临时隧道（trycloudflare）会自己退出、且换域名：模组每 60 秒判活并自动重启（面板显示「已重启 N 次」），app 会在连上时自动更新地址；但**换域名那一刻你正在外面**的话，旧地址就是打不开，需要回家连一次 WiFi（或配固定域名隧道）
- 语音识别依赖 DSH 的语音输入配置或 voicecall 配的 ASR（本地 whisper 等）；两边都没配时她会如实说听不清
- 投喂/摸头的数值属于 app 端，不改她在 QQ 那边的真实心情；但「被喂了白米饭」会作为事件进记忆

## 数据位置

- 宠物数值 / 自定义皮肤：`plugins-data/aurabot/modules-data/pocket/`
- 自定义头像：模组目录 `icons/avatar.png`（删掉这个文件 = 恢复默认头像）
- 隧道进程：cloudflared 独立运行，pid 写在 `plugins-data/aurabot/modules-data/pocket/`，模组热重载不影响它
- 隧道守护状态：同目录 `tunnel-want.json`（「用户希望隧道开着」+ 已自动重启次数）；删掉它就等于放弃自动重启
- 自己下的 cloudflared：同目录 `bin/cloudflared.exe`（面板「一键下载」装在这里，删掉即可重下）
- 聊天记录：不在本模块存——直接读她自己的 `chatlog/`（唯一事实来源）
