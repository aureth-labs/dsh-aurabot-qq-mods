# 自主学习

没人叫它也会自己跑：定时去 B 站翻评论区、读聊天流水，把「真人怎么说话」的样本筛出来收进库。

## 它做什么

每轮（默认 2 小时一次）干三件事：

1. **跟着 bili 逛的足迹走** —— 从记忆里捞她最近 72 小时看过的视频，去那些视频下面抓评论（不是乱抓热门，看什么学什么）
2. **学聊天流水** —— 读当天聊天记录，把真人有实质内容的发言收进金句库（占位符和纯表情会被剔掉）
3. **写小结** —— 每天指定时间写一份「今天学了什么」，记进记忆里，以后能翻

筛出来的评论分两堆：**人机反例** 和 **真人金句**，都交给「人机反面教材」模块的库。

## 怎么配置

| 项 | 默认 | 说明 |
|---|---|---|
| 自己去 B 站找评论学 | 开 | 关掉就只学聊天流水 |
| 学主人说话的样子 | 开 | 从自己聊天流水里读 |
| 隔多久跑一轮 | 2 小时 | |
| 一天最多跑几轮 | 6 | |
| 一轮看几个视频 | 3 | |
| 每个视频取多少条评论 | 20 | |
| 活跃时段 | 8–24 点 | 夜里不跑 |
| 每天写小结 | 开 | 23 点写 |

连续出错 3 次会自动歇一会儿，不硬刷。

## 依赖

需要先装「人机反面教材」（`anti-bot`）—— 判定和收库都在那边，这边只负责找样本和调度。

## 会访问哪里

- **联网**：B 站公开接口（热门视频、视频信息、评论区）。不需要登录。
  - `api.bilibili.com/x/web-interface/popular`
  - `api.bilibili.com/x/web-interface/wbi/view`
  - `api.bilibili.com/x/v2/reply/main`
- **读本机文件**：`plugins-data/aurabot/chatlog/YYYY-MM-DD.jsonl`（聊天流水，只读）
- 写自己数据目录的 `state.json` 和 `reports/`

## 怎么用

- QQ 命令：`/学` 立刻学一轮、`/学 状态` 看今天学了多少
- 工具：`self_learn_now`
- 接口：`/ext/self-learn/{state,now,report,make-report}`
- 面板：看今天跑了几轮、每轮学了什么、一键写小结
