# 输出安全（草稿 / 发言隔离）

把模型的思考草稿和真正发给 QQ 的话隔开，同时清理客服腔、沉默记号、任务状态回显和提示词泄漏。

## 做什么

- 聊天时要求模型把分析写进 `<draft>`，最终发言写进 `<say>`
- QQ 出口只发送 `<say>` 正文，不发送草稿和标签外的分析文字
- 容错处理缺少开头标签、缺少 `</say>` 等不完整格式
- 后台 JSON / 刷 B 站等系统任务不注入分区格式，不破坏结构化输出
- 去掉 AI 自称、客套收尾、总结腔和起手铺垫
- 清掉「已完成」以及复述系统消息、记忆、待办的状态回显
- 整句都是客服话时保持沉默，而不是发一句空话
- 识别多种「不说话」写法（中文 / 英文 / 带括号 / 带标点）
- 只处理文字：表情、语音、引用不受影响

## 怎么用

装上就生效。草稿隔离属于输出安全出口，始终开启，不提供关闭开关。

## 会访问什么

不联网、不读写文件、不碰账号配置。只处理插件交给模型的聊天提示和模型返回的文字。
