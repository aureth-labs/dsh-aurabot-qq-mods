# 毒舌模式（roast-mode）

主人用关键字开关的**损友式吐槽**模式：在某个聊天（私聊/群）里发开启关键字后，
模块按设定的接管方式回一句毒舌吐槽（引用回复）；发关闭关键字恢复。

> 风格边界：只做调侃、吐槽类的损友玩笑，不产辱骂、脏话或针对具体人的攻击内容。
> 语料由用户自备（可用文本文件），请遵守所在平台规则。

## 用法

- 发 `毒舌开启` / `毒舌关闭`（关键字可在面板改）在**当前聊天**开关模式。
- 默认只有主人能开关（面板可改）。
- **开着 = 整段接管**：该聊天的每条消息都归本模块回毒舌（引用回复），
  不会漏给大肥鱼；冷却秒数内的消息吞掉不回、也不给她。
  面板可调「冷却秒数」防刷屏；同一句语料不会连续重复。

## 语料

- 默认用内置预设语料（健康向损友吐槽）。
- 打开「从文本文件读语料」开关后，改读数据目录的 `corpus.txt`：
  **每行一句**；空行和 `#` 开头的注释行忽略；改完保存即生效（按修改时间缓存）。
  文件路径在面板/`status()` 里可见：`modules-data/roast-mode/corpus.txt`。

## 会访问哪些网址

无网络访问。仅读写本机模块数据目录（`filesystem` 能力）。
