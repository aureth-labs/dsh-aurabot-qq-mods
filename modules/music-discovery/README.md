# 搜歌与推荐

为 Aurabot 提供真实音乐库查询：搜歌、推荐、排行榜、歌单、听歌报告和 AI 解读。点歌时查到原曲再分享，明确要求翻唱时仍交给用户原有的翻唱功能，本模块不调用或依赖翻唱模块。

- 版本：0.2.0；扩展 API：1；最低插件版本：1.3.0。
- 作者：[luotong2333-web](https://github.com/luotong2333-web)；许可：MIT。
- 不需额外 npm 依赖、服务器或 GPU。QQ 功能需要用户自己的 QQ 音乐 API Key；不附带共享 Key，不承诺第三方 API 永久免费或无限配额。

## 配置与开关

安装后，在面板“已安装”中找到“搜歌与推荐”。模块行的总开关由宿主管理；展开模块设置，配置首选平台、条数、分享形式、只给主人用和 QQ 音乐 Key，点击保存生效。

六类能力分别有开关：

| 能力 | 默认 | 使用方式 |
|---|---|---|
| 推荐歌曲 | 开 | `/荐歌 学习`、`/荐歌 每日`、`/荐歌 猜你喜欢` |
| 歌曲搜索 | 开 | `/搜歌 晴天 周杰伦`；工具可搜歌曲、专辑、歌单、MV、电台、歌手 |
| 排行榜单 | 开 | `/榜单`、`/榜单 热歌`，选中后查看曲目 |
| 分类歌单 | 开 | `/歌单 轻音乐`、`/歌单 AI`，选中后查看曲目 |
| 听歌报告 | **关** | 主人私聊 `/报告 日`、`/报告 周`、`/报告 月` |
| AI 解读 | **关** | 主人私聊 `/解读 分析我的听歌风格` |

报告、解读需先打开对应开关并保存。普通聊天通过模型调用工具，斜杠命令由宿主限主人；本模块不接管全部聊天。默认平台为网易云、条数3（可设1–5）、网页链接、只给主人用，Key默认为空。

分项关闭会在工具、命令、导出方法执行时拦截，取消对应在途请求，不从旧候选继续分享；发送和卡片兜底前再次复核。场景推荐依赖“推荐歌曲+分类歌单”，歌单搜索依赖“歌曲搜索+分类歌单”，任一关闭即停。保存后生效，不需重启。

**已知宿主总开关限制：** 在实测的 Aurabot 1.3.0-beta.1 中，关闭能卸载本模块，重新打开后可能仍未加载，需要点同一行的“重新加载”。这是本次真实宿主检查未通过的项目，尚未修复；六个分项开关正常。本模块没有新增另一套总开关，也不修改插件加载器。

## QQ 音乐 Key

按[腾讯音乐官方说明](https://github.com/tencentmusic/qqmusic-skills/tree/main/qqmusic)获取自己的 Key，填写到本模块“QQ 音乐 API Key”密码字段。不要把它发进聊天、仓库或问题反馈。

选择 QQ 但未配置 Key 时，歌曲搜索会明确说明并改用网易云；显式指定 QQ 的请求不会冒充成功。仅QQ支持的功能会如实说明不可用。接口失效、限流、超时也会返回错误，不伪造歌曲或链接。

## 私人数据与权限

每日推荐、猜你喜欢、AI歌单、报告和解读使用 **Key 所属账号** 的数据，始终只允许当前主人私聊；将“只给主人用”关闭，也不会向群聊或其他人的私聊开放这些数据。

命令使用 `api.isOwner(msg.userId)`，工具使用当前会话 `api.core.hub.turnSendersAllOwner(sessionId)` 复核。请求前、返回私人内容前、每块SSE读取和每次分享都会现查；主人与群友混合轮不借权。被拒私人结果不写缓存，成功缓存的私人候选在撤权后也不能列出或分享。

缓存只在内存中，按聊天隔离：10分钟过期、最多200个聊天、每个聊天3组、每组最多5条。卸载时取消请求并清空。模块不读整份插件配置，不写本机文件、不启动进程、不执行平台返回文本、不派子智能体。

## 数据去向和能力声明

| 域名 | 发送的数据 | 用途 |
|---|---|---|
| `music.163.com` | 搜索词、场景关键词及歌单ID；无QQ Key | 网易云匿名公开搜索、场景歌单及曲目 |
| `a.y.qq.com` | QQ Key鉴权、搜索词/条目ID/页码/报告时间参数；解读时发送主人提出的解读问题与所选资产类型 | QQ官方查询及账号数据解读 |

账号推荐和报告的数据由QQ音乐平台根据Key返回，模块不向网易云发送这些私人结果。分享时，仅把用户选中的结果或链接通过宿主发到当前聊天。不上传日志、整个聊天记录或本机配置到其他服务。

能力声明：

- `network`：访问以上两个固定域名；只允许HTTPS，拒绝跨origin重定向携带凭据。
- `plugin-config`：通过 `api.settings()` 读取本模块设置，包括用户填写的Key；不调用 `api.config()` 读取整份配置。
- `plugin-internals`：仅用 `api.core.hub.turnSendersAllOwner` 做当前轮主人身份复核；该内部接口随宿主升级可能变化。

声明帮助审核，不是沙箱。模块与宿主同进程运行，请在安装前审阅来源和权限。

## 工具

| 工具 | 参数与作用 |
|---|---|
| `music_search` | `query`、`artist`、`version`、`platform`、`limit`、`page`、`type`（song/album/playlist/mv/radio/singer） |
| `music_recommend` | `kind=scene/daily/guess`，场景用`scene`；每日/电台仅主人私聊 |
| `music_charts` | `action=groups/detail`，详情用上游返回的`topId`及`page` |
| `music_playlist` | `action=ai/detail`，详情用上游返回的`dissId`及`page` |
| `music_report` | `period=day/week/month`，可选秒级`startTime`；周听歌时长为日均，月报忽略时间参数 |
| `music_interpret` | `query`、可选`assetTypes`（1收藏、2历史）；读取SSE，结果有界 |
| `music_share` | `index`或`keyword`；只分享当前聊天刚查到的歌曲，多候选需明确序号 |

页码从0开始，上限20；不自动遍历曲库。QQ分类歌单提供搜索、AI歌单列表和曲目详情，不提供文档未列出的自由文本创建歌单能力。QQ每日/电台是私人推荐，场景推荐使用网易云公共歌单，不将两者混称。

## 分享与AI解读的边界

- QQ歌曲分享使用平台H5链接；**未实现QQ原生音乐卡片适配**。网易云卡片仅在宿主明确“不支持”时退链接，发送回执不明不自动补发、不报告已发。
- QQ搜索未给版本字段时显示“版本未标注”，不把它说成原唱。无有效ID/链接不编造分享地址。
- AI解读支持已实际观察到的JSON SSE：`chunk_type=output`、`chunk_content`文本、`chunk_idx`数字，结束`event:done`/`[DONE]`。未知类型不猜内容，非空`references`等结构未作适配保证。
- 只有完整结果报告成功。错误、取消、超时、EOF无结束标记、4000字截断分别处理；可展示的部分内容会明确标注“不完整/部分”。

## 验证范围

2026-11-13在Windows、Aurabot 1.3.0-beta.1上验证：

- 219项离线测试在Node22.23.2和26.13.0通过；另有9项独立回归检查通过。
- 17项受控真实只读检查通过：QQ六类搜索、榜单与歌单详情、每日/电台/AI歌单、日周月报告、AI解读，以及网易云场景推荐。私人正文和Key未写进证据或本仓库。
- 宿主模拟21项中20项通过，含六分项开关、私人权限和模拟分享；未通过项是上述原生总开关重新启用自动加载。已经用“重新加载”恢复运行。

这些结果只说明实测环境下的行为，不能保证未来接口、所有账号或未知SSE类型。真实QQ投递显示与自然语言模型长期调用效果尚未验收，不把模拟捕获写成真实已发送。
