# 额度守门（model-quota-guard）

盯着几个模型渠道账号的剩余额度，当前账号额度低于阈值时，自动把当前聊天切换到一个还有额度的模型（按你给的候选顺序，倍率低的优先）。

## 做什么

- 定时读插件自己暴露的 `/plugins/dsh-connect-workbuddy/usage` 和 `/plugins/dsh-connect-trae/usage` 两个只读接口拿剩余额度。不登录、不花钱、不占会话。
- `api.on('model')` 是同步事件，模块只读缓存快照，不在事件里发请求；命中切换时返回 `{provider, model, reasoningEffort:''}` 交给宿主收敛。
- 当前账号额度读不到就不插手；候选里没有够用的就不换。

## 配置

- 自动切换（默认开）
- 额度低于多少就换（默认 10）
- 多少分钟探一次（默认 5）
- 换的时候在聊天里说一句（默认开）
- 候选顺序（一行一个 `provider:model`，从上往下挑第一个够用的）

## 怎么用

- 主人私聊发 `/额度` 看各账号还剩多少、守门最近有没有换过。
- 面板「模型」页改阈值和候选顺序。
- 只读接口：`/status`（当前额度快照）、`/simulate?threshold=N`（只演算不改配置，看阈值改成 N 会切到哪）。

## 会访问哪里

只访问本机 Harness（127.0.0.1 的自身端口）上两个插件的 usage 路由；不联网、不接触 QQ 消息内容、不读写账号凭据。
