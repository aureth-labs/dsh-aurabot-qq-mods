# 跨聊天近况（cross-chat-memory）

让她知道**自己在别的聊天里最近说过什么**。

## 解决什么问题

插件内置的记忆有个写死的条件：跨聊天那段提示只喂给主人私聊
（`src/features/memory.js` 的 `crossHint()` 里 `chat.userId === ownerQQ` 那一句）。
所以除了主人私聊，别的私聊和群里一开口就像失忆——

- 刚跟某人聊完，换个聊天再被问「你俩聊得怎么样」，答不上来；
- 群里说过的事，隔一会儿再提，像没发生过。

这个模块补的是**聊天流水**这一层。注意它和人像库（`persona-memory`）不是一回事：
人像库管「这个人是谁」，这里管「聊过什么」。

## 怎么做的

两条通道，故意分开：

| 通道 | 给谁 | 什么时候 |
|---|---|---|
| 自动注入（`api.context`） | 只给主人私聊 | 每轮聊天前，塞一小段「别处最近说过的话」 |
| 手动查询（`cross_chat_recall` 工具） | 任何聊天 | 她需要时自己翻，比如被别人当面问到 |

区别在于：**记忆在**和**主动推给谁看**是两件事。别人私聊不会突然冒出「我在别处干了什么」，
但真被问起来，她翻得到、答得上。

## 三道边界

1. **主人私事不外传**（`keepOwnerSecret`，默认开）
   主人的私聊流水、主人本人在任何地方的发言，都不进别人的上下文。
2. **群与群不串**（`shareGroupToGroup`，默认关）
   A 群的人和事不该冒到 B 群——那最像「记忆混乱」。
3. **只认真实聊天**
   只处理 `private:QQ号` 和 `group:群号`，`qzone:`、`bili:` 这类旁路记录一律不进。

## 设置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `hours` | 24 | 往回看几小时 |
| `quota` | 3 | 每个聊天取几条（取最近的） |
| `maxChars` | 420 | 一段最多多少字 |
| `minChars` | 4 | 单条最少几个字，过滤「嗯」「好」 |
| `ownerSeesPrivate` | 开 | 主人私聊能否看到别人的私聊近况 |
| `shareGroupToGroup` | 关 | 群与群是否互通 |
| `othersSeeCrossChat` | 关 | 别人私聊是否也自动注入 |
| `keepOwnerSecret` | 开 | 保护主人的私事 |

## 怎么用

- 装好即生效，不用配。
- 主人私聊里自然能看到别处近况，说「你刚才跟某某聊了什么」她会直接答。
- 面板展开本模块有设置表单；想看通没通，访问 `/aurabot/api/ext/cross-chat-memory/preview`
  ——会列出覆盖了哪些聊天、每个多少条、最近一条是什么。

## 会访问哪里

- 只读本机已存的聊天流水（`plugins-data/aurabot/chatlog/` 下的 jsonl），**不联网**。
- 群名走 `api.core.hub.groupName()`，人名走 `memory` 模块的人像库；都只是本地查询。

## 已知限制

- **默认只看最近 24 小时**。想串起更早的事，把 `hours` 调大（上限 720，30 天）。
- **每个聊天只取最近 3 条、整段 420 字封顶**。聊得密的时候只能拿到梗概，细节会掉。
- 群名和人名是异步拉的：模块刚启动的头一两轮，可能先显示「群123456」「QQ123456」，
  随后自动换成真名（后台补缓存，不是没生效）。
