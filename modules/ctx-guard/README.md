# 上下文守门（ctx-guard）

盯着每轮对话的 token 用量，到线就用私聊提醒你。

**只提醒，不自动处理。** 原因见下面「为什么不能自动压缩」。

## 它解决什么问题

AuraBot 的会话上下文会一直涨。等涨到你手动去 `/compact` 的时候，往往已经几千条消息、单轮十几万 token——**每一次回复都在为这些历史付钱**，而且模型也更容易跑偏。

这个模块在中间放一道哨：到线就用一条自然的话提醒你，你再去 DSH 界面点 `/compact`。

## 为什么不能自动压缩

试过了，做不到。DSH 的压缩服务（`ctx.compaction`）是 cordis 的 Service，只有在自己插件的 `inject` 里声明过它的插件才拿得到：

```
inject: ['agents', 'sessions', 'webServer', 'timer', ..., 'compaction']
```

但往 AuraBot 的 `host.js` 加声明会让**整个插件静默启动失败**（没有任何报错，日志一片空白）。模块侧也试过这些路子，全部拿不到：

| 尝试 | 结果 |
|---|---|
| `ctx.reflect.get('compaction')` | null |
| `ctx.get('compaction')` | null |
| 遍历全局 store | 空 |
| 沿 parent fiber 链上溯 | 拿不到 |
| 模块诊断输出 | `{"tokenMeter":"object:TokenMeter","compaction":null,"sessions":"object:SessionStore"}` |

`tokenMeter` 和 `sessions` 拿得到，唯独 `compaction` 恒为 null。所以压缩这一步只能交给人。

## 提醒文案

文案走「某样东西用完了 / 装满了，该补或该清」这个路子，刻意避开技术词和机械句式——企鹅对机械化语句敏感，你自己看着也像机器人。

**三档语气**，面板里切换，默认中性：

| 档位 | 适合 | 示例 |
|---|---|---|
| **中性** | 谁用都不出戏 | `我日记本写满了…翻到最后一页没地方落笔了` |
| **亲近** | 关系热的 bot | `我日记本写满了…给我买本新的呗` |
| **极简** | 严肃 / 冷淡人设 | `日记本写满了 没地方落笔` |

称呼用 `{who}` 占位符，取值来自 AuraBot 配置里的主人昵称。没填、或者填的是「你 / 用户 / 对方 / 他 / 她」这种代词，就把占位符连同后面的空格一起去掉，避免出现「你 我日记本写满了」这种读不通的句子。

**群聊提醒末尾加 `Group!`** —— 同一个人可能同时有私聊和群聊两个会话，加个尾巴能分出是哪个。

文案池还能让模型自己往下扩（面板可关），扩出来的会过两道过滤：

```js
const badTech = /【|】|\[|\]|群号|上下文|压缩|系统|通知|提醒/
const badRel  = /男朋友|女朋友|老公|老婆|亲爱的|宝贝|哥哥|姐姐|妹妹/
```

第二道是防模型自作主张写关系称谓——每个人和 bot 的关系不一样，写死了就出戏。

## 面板

- **总开关**
- **各会话用量**：每个会话当前 token、离阈值还有多少
- **提醒文案**：三档切换、试发一条
- **提醒设置**：私聊线、群聊线、冷却时间、每天最多几次
- **诊断**：服务可达性自查

阈值默认私聊 90k、群聊 70k，都能在面板里调。

## 用量怎么量

优先用 `contextPressure().pressureTokens`（提供方报告的真实提示词规模），拿不到才退回 `tokenMeter.measure()` 的估算。

实测参考（2026-11 某用户的真实环境）：

| 场景 | 提示词规模 | 窗口 |
|---|---|---|
| 私聊（长会话） | 133k | 400k |
| 群聊 | 30k | 400k~1M |

每轮增长约 3.1k token。

## 限制

- 只在**发消息前**检查，不会在对话中途打断
- 同一个会话有冷却（默认 3 小时）和每日上限（默认 4 次），防止刷屏
- 拿不到压缩服务，所以**永远不会自动压缩**——这是设计决定，不是 bug

## 兼容性

- 需要 AuraBot 1.2.0 及以上
- 读 `config.json`、写自己的 `modules-data/ctx-guard/templates.json`（`capabilities: ["filesystem","plugin-config","plugin-internals"]`）
- 不联网、不启动子进程
