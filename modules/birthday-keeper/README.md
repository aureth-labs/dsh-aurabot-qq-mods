# 生日管家 · AuraBot 模块

记住群友和好友的生日，在你能接受的作息时间里随机挑一分钟送上祝福；群聊里可以 @ 本人。

## 做什么

- **自动学习生日**：优先读个人资料里的简介 / 签名，其次听聊天里的自述。
- **记在设置页里**：学到的和手填的都在同一张表里，看得见、改得动、删得掉。
- **随机时间发送**：在设定的作息窗口内，为每个人算一个固定的随机分钟，不是整点群发。
- **群聊 @ 本人**：只往他真正在的群发；找不到共同群就退回私聊。

## 生日从哪来

**只记录群聊里公开可见的信息，私聊内容一律不读取、不记录；只存月和日，不存年份。**

优先级从高到低：

1. **设置页手填**：你改过的行不会被任何自动学习覆盖。
2. **群成员公开资料**：`get_stranger_info` 返回的简介、签名等字段里出现「生日 3-14」「出生于 2000 年 3 月 14 日」这类写法，只取月日。每人 7 天最多查一次。
3. **群聊里的自述**：只认「我生日是 3 月 14 日」「我 12 月 31 号生日」这种第一人称说法；别人说「他生日是…」不会记到发送者头上。

资料里找不到、群里也没说过的人，会一直空着，直到你手动填。

## 使用协议

**安装后默认不工作。** 必须在设置页勾选「我已阅读并同意《使用协议》」才会读取资料、记录生日和发送祝福；不勾选时模块只加载、不做任何事。

勾选即表示你确认并同意：

1. **你是数据控制者**：由你决定记录谁的生日、在哪些群使用。请只在你负责管理、且成员对机器人功能有基本了解的群里启用。
2. **收集范围最小**：只记录 QQ 号、月和日、称呼（可选），以及「是否已发送」这类状态；**不保存年份、不保存聊天原文、不保存资料原文**。私聊内容不参与学习。
3. **来源与告知**：生日只来自你手填、群内公开资料卡，或群聊里对方第一人称公开自述。自动收集不代替你向群成员告知；建议在群公告或群规里说明本机器人的用途。
4. **用途单一**：只用于生日当天发送一条祝福，不用于营销、画像、转卖或任何其他用途。
5. **不出本机**：模块不访问互联网，不向任何第三方传输数据。
6. **可撤回**：任何用户发送 `#生日 忘了我`（或「删除」「别记我」「退出」）即可删除自己的记录并永久退出自动记录与祝福；你也可以在设置页直接删行。
7. **未成年人**：不满 14 周岁的未成年人个人信息属于敏感个人信息，需要监护人同意。若群内有未成年人，请先取得监护人同意，或不要对其启用。
8. **风险自负**：资料可能被误读（例如把注册日期识别成生日），祝福也可能被平台判定为异常行为；由此产生的后果由使用者承担。

不同意以上条款请保持开关关闭或卸载模块。

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 我已阅读并同意《使用协议》 | 关 | 不勾选则完全不工作 |
| 启用 | 开 | 关掉后不学习、不发送 |
| 作息窗口开始（点） | 9 | 冬天作息晚就往后调，祝福落在这个窗口内 |
| 作息窗口结束（点） | 21 | 和开始一起决定随机范围 |
| 怎么送 | 在群里 @ 本人 | 也可以选「私聊本人」 |
| 发送的群 | 空 | 填群号，每行一个；只在本人所在的群里 @ |
| 群聊里 @ 本人 | 开 | 关掉只发文字，不提醒对方 |
| 祝福语 | 生日快乐！今天是你生日，祝你天天开心。 | 可用 `{name}` 代入称呼 |
| 生日表 | 空 | 一行一条：`QQ=月-日` 或 `QQ=月-日=称呼`；不含年份 |
| 从群成员资料里学 | 开 | 只读群内公开资料卡，私聊不读 |
| 从群聊里学 | 开 | 只认群里第一人称公开自述，私聊不记录 |

生日表直接编辑即可，例如：

```text
123456789=03-14=小明
987654321=12-31
```

删掉一行就等于忘掉这个人的生日；改过的行会被标记成手填，自动学习不再覆盖。

## 发送时间

每个人的发送分钟由「日期 + QQ 号」算出来，落在你的作息窗口里：

- 同一天重启多少次，时间点都不变；
- 不会整点集中发送；
- 机器人当天错过了窗口（比如关机），当天稍后仍会补发一次，不会跨天；
- 同一个人一天只发一次，失败后 10 分钟重试。

## 群聊与私聊

- 群聊模式：遍历「发送的群」，用 `get_group_member_info` 确认本人在群里，再发 `<at:QQ> 祝福语`。
- 所有群都查不到他，或者群聊模式没填群号，就自动改成私聊发送。
- 私聊模式：直接发到 `private:QQ`，不加 @。

## 删除与退出

任何人在群里或私聊发送下面任意一条，就会删掉自己的记录并永久退出：

```text
#生日 忘了我
#生日 删除
#生日 别记我
#生日 退出
```

删除后不再自动学习，当天也不会收到祝福；退出名单存在本机 `state.json` 里。这个命令不需要主人同意，也不受协议开关影响。

## 隐私

- 不访问任何外部网站，没有 `fetch`。
- 只调用本机 OneBot 网关的三个动作：`get_stranger_info`、`get_group_member_info`、发送消息。
- 只处理群聊里公开可见的信息：群成员公开资料卡、群消息里的第一人称自述；私聊消息不读取、不记录。
- 只把 QQ 号、月和日、称呼写进模块设置；**不存年份**。`state.json` 只存「今天发过没、资料多久前查过、这条是手填还是学来的、谁要求退出」，不存聊天内容。
- 资料查询按人 7 天节流，避免频繁请求。

## 限制

- OneBot 的 `get_stranger_info` 是否返回简介取决于网关（NapCat / Lagrange 等）和对方隐私设置，很多 QQ 资料并不公开生日；拿不到时会自动依赖聊天自述或手填。
- 「今天是我生日」这种没有日期的说法不会建档（不知道年份和日期就没法明年再发），只在当天被别的机制祝福时不适用本模块。
- 2 月 29 日的生日按闰年判断合法性，平年不会触发。
