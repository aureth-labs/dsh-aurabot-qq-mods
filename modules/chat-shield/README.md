# 聊天屏蔽（chat-shield）

给大肥鱼装一道门：黑名单里的人，群聊私聊都不接；刷屏和机器人互刷，自动闭嘴一会儿。

## 解决什么

- 群里有人反复发广告、复读同一句、带着机器人来回复述 —— 她的回复被拖进无意义的循环，既费模型又污染群。
- 有些人就是不想让她搭理。

这个模块在**消息进入她之前**就把它拦掉（`message` 事件返回 `true` 接管），所以她不会看到、不会记住、也不会回。不是"回了再撤回"。

## 怎么用

**面板里填（推荐）**：面板 → 「聊天屏蔽」，有两个输入框：

- **黑名单：人** —— 一行一个 QQ 号，后面可以跟备注
- **黑名单：群** —— 一行一个群号

```
123456789 广告号
987654321
# 井号开头是注释，空行跳过
```

保存就生效，不用重启。删掉某行，那个人立刻恢复正常对话。

**QQ 里发命令**：命令改的是同一份名单，改完面板输入框里也能看到。只有主人能生效（`api.command` 本身只认主人）。

| 命令 | 作用 |
| --- | --- |
| `/屏蔽` | 看状态：总开关、生效范围、名单人数、自动识别参数 |
| `/屏蔽 列表` | 看黑名单（人和群） |
| `/屏蔽 加 123456789 广告号` | 拉黑一个人，备注可省 |
| `/屏蔽 删 123456789` | 移出黑名单 |
| `/屏蔽 群 加 987654321 广告群` | 屏蔽整个群（她不在这个群说话） |
| `/屏蔽 群 删 987654321` | 取消群屏蔽 |
| `/屏蔽 临时` | 看自动屏蔽了谁、到几点、什么原因 |
| `/屏蔽 解除 123456789` | 提前解除某人的临时屏蔽 |
| `/屏蔽 清空 确认` | 清空名单（不带"确认"不会执行） |
| `/屏蔽 开` / `/屏蔽 关` | 总开关 |

`/屏蔽 123456789`（省略动词）也算拉黑。别名：`/blacklist`、`/bl`。

## 自动识别（默认开）

不靠名单，看行为。三个信号，命中就临时屏蔽一段时间（默认 10 分钟）：

1. **刷屏**：同一会话里，同一个人 60 秒内发到 12 条。
2. **复读**：60 秒内同一句话（归一化后完全相同）出现 3 次。
3. **回声 / 机器人互刷**：对方说的话和她刚刚发出的内容高度相似（默认相似度 ≥ 0.7，连续 2 次）。这是两个机器人互相接话最典型的形状 —— 一个说，另一个换个标点丢回来。

外加一条**自检**：她自己 90 秒内对同一个会话说两句几乎一样的话（相似度 ≥ 0.9），第二条直接不发。避免她自己也变成复读机。

临时屏蔽精确到「会话 + 人」：A 群刷屏不会连带 B 群。

主人永远放行，黑名单里就算填了主人的号也不生效。

## 设置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | 开 | 总开关，关掉后名单保留 |
| `blockUsers` | 空 | 黑名单：人。一行一个 QQ 号，可跟备注 |
| `blockGroups` | 空 | 黑名单：群。一行一个群号 |
| `blockPrivate` / `blockGroup` | 开 / 开 | 私聊、群聊分别是否生效 |
| `autoDetect` | 开 | 自动识别总开关 |
| `repeatLimit` / `windowSec` | 3 / 60 | 窗口内重复几次算复读 |
| `floodDetect` / `floodLimit` | 开 / 12 | 刷屏检测与条数阈值 |
| `echoDetect` / `echoSimilarity` / `echoHits` | 开 / 0.7 / 2 | 回声检测 |
| `selfRepeat` | 开 | 拦住她自己的复读 |
| `muteMin` | 10 | 临时屏蔽分钟数 |
| `logBlocked` | 开 | 面板「日志」页记一笔（只有 QQ 号、昵称、原因，不记正文） |

## 数据和网络

- 名单存在模块自己的设置里（就是面板那两个输入框），由插件写进配置；模块不读写任何文件。
- 临时屏蔽只在内存，带截止时间，过期自动清；插件重启就清空 —— 它本来就是"这一阵子先别理他"。
- **不联网**：没有任何 `fetch`，不访问任何网址，不上传聊天内容。
- **不外发**：消息正文只在内存里做相似度比较，不落盘、不出进程。
- 能力声明为空 `[]`：不联网、不读写文件、不启动程序、不动态执行代码、不碰插件内部对象。名单只走模块自己的设置。

## 限制

- 图片、表情、文件不参与文本判定，只有占位符的消息不触发复读 / 回声；刷屏计数仍然算。
- 相似度是双字组 Jaccard，不是语义理解。改一个字还是会被认出来，完全换一种说法就认不出。
- 只影响"她要不要处理这条消息"，不删群友消息、不禁言、不做任何 QQ 管理操作。
- 黑名单按 QQ 号全局生效；临时屏蔽按会话生效，重启后清空。
- 输入框里认不出的行（昵称、带字母的号）会被跳过，并在日志里提示一次；只认 5~12 位数字。
