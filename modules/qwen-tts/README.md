# 千问百炼语音

使用阿里云百炼的千问语音合成，支持语速、自然语言语气、长文本分段、试听和可选 ffmpeg 音频处理。

## 安装与设置

1. 安装并启用模块，在语音页的「百炼语音设置」点击「安装脚本」。已有 local/tts.mjs 时不会覆盖，请先手动备份、移走原脚本。
2. 在「本地接口」页开启语音，回到模块面板填写百炼 API Key、模型及音色并保存，然后试听。可用音色和模型取决于账号及地域。
3. 可选 ffmpeg；找不到时保留原始音频。

API Key 和设置保存在本机 `local/tts.config.json`，合成的音频和缓存保存在本机 `local/` 下。合成文本、音色和参数发送到配置的百炼服务地址（默认 `https://dashscope.aliyuncs.com`），再从服务返回的音频地址下载。使用自定义服务地址前，请确认信任该服务。试听与合成会产生请求，可能计费。

部分模型和地域提供限时免费额度，具体额度、有效期和费用以[阿里云说明](https://help.aliyun.com/zh/model-studio/new-free-quota)及账户为准。

接入百炼的思路来自抖音博主 **荣灵RONGLing**：https://v.douyin.com/DvlKVQxTpRQ/ 。
