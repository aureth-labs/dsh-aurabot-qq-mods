# 长夜如梦（Aurabot 模块）

给她一副会累的身体：会困、会睡着、会做梦，睡着以后不一定叫得醒。

夜里聊久了精力见底，会自己说要去睡；深睡时最难叫；醒来记不记得梦，看那段梦有多重。
作息、睡眠阶段、做梦、唤醒都由同一套时钟推出来 —— 不落库、不靠 tick 精度，
重启或改系统时间都不会错位。

## 装法

把整个 `night/` 文件夹放到 Aurabot 的模块目录：

```
plugins-data/aurabot/modules/night/
├── module.json
├── index.mjs
├── state.mjs
├── stages.mjs
├── energy.mjs
├── clock.mjs
├── wake.mjs
├── dream.mjs
├── close.mjs
├── lullaby.mjs
├── panel.js
└── README.md
```

放进去几秒内自动加载，不用重启。面板「已安装」页能看到 `night` 在不在跑；
它的设置和面板在单独一页「长夜如梦」。

## 她会怎么样

- **精力**：0~100。夜间疲劳时段（默认 23:30–07:00）每分钟掉 0.8、每条消息再掉 4；
  非疲劳时段每分钟回 1.5。午间 13:00–14:30 也会犯困。
- **入睡**：疲劳期精力耗尽、且至少聊过 8 轮，会先说一句道别再睡；
  到了最晚睡觉时间（默认 02:30）不管精力多少都睡。
- **睡眠阶段**：刚入睡 → 浅层 → 深度 → REM，90 分钟一个周期；前半夜深睡多，后半夜 REM 多。
  阶段是按时钟现算的，不落库，重启/改时间都不会错位。
- **做梦**：只在 REM 阶段做，入睡 60 分钟后才开始，两段梦至少隔 60 分钟，一次睡眠最多 8 段。
  梦分 1~5 级，越强记得越久（每天衰减 0.30 / 0.22 / 0.15 / 0.08 / 0.03）。
  醒来只可能记得最强的那段，而且只在私聊里说。
- **叫醒**：默认只有私聊能叫，群里要 @ 她。计数按 10 分钟窗口累计：
  第 1 条不算，第 2 条开始掷骰，到第 6 条必醒；深睡系数 0.45，刚入睡 1.3，REM 1.1。
- **收线**：对方说「晚安 / 我睡了」这类强收线，她会道别后去睡；
  「拜拜 / 先这样」默认只闭嘴 30 分钟（可改成也睡）。

## 命令（只有主人能用）

| 命令 | 作用 |
|---|---|
| `/长夜` | 看状态：醒着/睡着、精力、阶段、起床点、待爬会话 |
| `/睡` | 立刻去睡；`/睡 午` 睡午觉 |
| `/醒` | 把她叫醒 |
| `/梦` | 看还记得的梦（私聊里才给正文） |
| `/做梦` | 现在做一段梦（调试用，得先睡着） |

## 工具（她自己决定用）

- `night_status`：看现在的作息状态。
- `recall_dream`：回想最近做过的梦（只给私聊）。

## 面板

「长夜如梦」页：精力条、状态、睡眠阶段甘特条、待爬会话、梦境列表（置顶/删除）、
以及常用设置（起床点、浮动、疲劳时段、唤醒策略、阶段周期、开关）。

## 数据

- `modules-data/night/state.json`：当前状态（模式、精力、入睡/起床时间、待爬会话等）。
- `modules-data/night/dreams.json`：梦境记录（正文只留在这里，不进共享记忆）。

往记忆里只写一句「我昨晚做了一段梦」，不写内容；梦不会被当成现实。

## 几个实现上的取舍

- **爬楼只记清单**：醒来只记「哪些会话来过消息」，不生成爬楼语 —— 省 token，也不替对方编造。
- **道别零件现拼**：默认不调模型，打开「道别用模型」才走 `api.ask`。
- **梦不进共享记忆**：正文只存 `modules-data/night/dreams.json`，避免私人内容进到群聊上下文。
- **午睡不排深睡**：只排浅睡 + 少量 REM，跟真实午休对得上。
- **面板接口只认同源**：`/dreams` 会吐梦境正文、`/state` 有作息状态，所以所有面板路由
  都校验 `Origin` 和 `Sec-Fetch-Site`，跨站请求一律拒绝。DSH 默认对 GET 是放行的，
  不加这道闸等于「发个链接就能读到她的梦」。跨站拒绝、同源与非浏览器客户端放行，
  面板本身的调用不受影响。
- **作息按配置时区算**：容器一般跑在 UTC，Aurabot 进程的本地时间就是 UTC，
  直接把「08:00」当本地时间会差 8 小时（面板上会显示 16:00 才醒）。
  所以设置里有 `timeZone`（默认 `Asia/Shanghai`），所有墙上时间都走 `clock.mjs`，
  跟进程时区无关。

## 权限

| 能力 | 用途 |
|---|---|
| `filesystem` | 在 `modules-data/night/` 下读写状态和梦境记录 |
| `plugin-config` | 读插件配置里的时区、主人 QQ 等设置，决定按哪个时区算作息 |
| `plugin-internals` | 读 Aurabot 的会话清单和记忆接口，判断该不该睡、做过的梦要不要留一句 |
