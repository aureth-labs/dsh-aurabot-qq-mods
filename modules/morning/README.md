# 每日晚报

每天晚上把当天抓到的科技新闻筛成几条要点，私聊推给主人；也可以随时问「今天有什么新闻」，她会现抓一遍再答。

## 做什么

- **定时推送**：默认 20:00，抓四个科技源（IT之家 / Solidot / 爱范儿 / 少数派），去重后挑 3~6 条写成「11月8日晚报」私聊发给主人，**每条标注来源媒体**
- **随问随查**：挂一个 `qq_today_news` 工具，问「今天有什么新闻」「有没有 AI 相关的」时她自己抓一遍，返回带时间和来源的标题列表
- **/晚报 命令**：不用等到点，立刻生成一份
- **推送留痕**：推完会写一条记忆事件（`kind: seen`），第二天她本人知道推过什么，不会一问三不知

## 配置

面板「模块 → 已安装 → 每日晚报」里可以改：

| 项 | 默认 | 说明 |
|---|---|---|
| 定时推送 | 开 | 关掉只停定时推送，`/晚报` 命令仍可用 |
| 几点 / 几分 | 20 / 0 | 每天几点推 |
| 详细程度 | 常规 | 简报（3 条各一句）/ 常规（6 条，是什么 + 为什么重要）/ 详细（4 条带影响面） |
| 更关心的话题 | 空 | 逗号分隔关键词，命中的新闻会被优先挑出来；留空就不偏科 |
| 最多几条 | 6 | 仅「常规」档生效 |

## 会访问哪里

- `https://www.ithome.com/rss/`、`https://www.solidot.org/index.rss`、`https://www.ifanr.com/feed`、`https://sspai.com/feed`：只做 HTTPS GET，不登录、不带任何账号信息。某个源挂了就跳过，不影响当天推送
- 本机：`plugins-data/aurabot/modules-data/morning/state.json`，只记「今天发过没有」，不上传

除上述地址外不联网，不发任何其他请求。

## 依赖

- 插件内置的 `api.ask`（用你自己的模型配置写简报）
- 插件的主人 QQ 号（`api.config().ownerQQ`），用来决定推给谁

## 注意

- 新闻筛选靠模型，偶尔会把促销稿挑进来；不满意可以在面板里改条数，或等她学习你的口味
- 上游 RSS 挂了就当天不推，不会补发到半夜（只在到点后 3 小时内尝试）
