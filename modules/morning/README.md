# 每日晚报

每天晚上把当天抓到的科技新闻筛成几条要点，私聊推给主人；也可以随时问「今天有什么新闻」，她会现抓一遍再答。

## 做什么

- **定时推送**：默认 20:00，抓 IT之家 RSS（60 条），挑出真正值得知道的 3~6 条，写成「11月8日晚报」格式发给主人
- **随问随查**：挂一个 `qq_today_news` 工具，问「今天有什么新闻」「有没有 AI 相关的」时她自己抓一遍，返回带时间的标题列表
- **/晚报 命令**：不用等到点，立刻生成一份
- **推送留痕**：推完会写一条记忆事件（`kind: seen`），第二天她本人知道推过什么，不会一问三不知

## 配置

面板「模块 → 已安装 → 每日晚报」里可以改：

| 项 | 默认 | 说明 |
|---|---|---|
| 开关 | 开 | 关掉只停定时推送，`/晚报` 命令仍可用 |
| 小时 / 分钟 | 20 / 0 | 每天几点推 |
| 条数 | 6 | 一份晚报最多几条 |

## 会访问哪里

- `https://www.ithome.com/rss/`：科技新闻 RSS，只做 HTTPS GET，不登录、不带任何账号信息
- 本机：`plugins-data/aurabot/modules-data/morning/state.json`，只记「今天发过没有」，不上传

除上述地址外不联网，不发任何其他请求。

## 依赖

- 插件内置的 `api.ask`（用你自己的模型配置写简报）
- 插件的主人 QQ 号（`api.config().ownerQQ`），用来决定推给谁

## 注意

- 新闻筛选靠模型，偶尔会把促销稿挑进来；不满意可以在面板里改条数，或等她学习你的口味
- 上游 RSS 挂了就当天不推，不会补发到半夜（只在到点后 3 小时内尝试）
