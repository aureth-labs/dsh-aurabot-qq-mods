# 模块目录

这个文件由 `npm run catalog` 生成，不要手改。

每个模块一个文件夹：`modules/<id>/`。格式见 [模块规范](../docs/MODULE_SPEC.md)，第一次提交看 [提交教程](../docs/TUTORIAL.md)。
