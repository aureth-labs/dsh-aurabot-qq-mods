# 通话（voicecall）

打开一个网页就能跟她打电话：**不用按住说话**，开口说、停一下，她自己接话；她边想边念，第一句不到两秒就出声。用她自己的声音（本地 GPT-SoVITS），也可以换成任何一家线上语音服务。

不经过 QQ，也不占用聊天窗口；电脑上用，手机连同一个 Wi-Fi 也能用。

## 怎么用

1. 面板 →「通话」→ 点「在这里直接通话」（或「新窗口打开」）。
2. 点「开始通话」，允许麦克风。
3. 说话，停 0.7 秒左右，她会接。她说着的时候你直接开口，她会停——**能插话**。
4. 点「挂断」，她会用一句话把这通电话记进记忆（以后私聊里能想起来）。

## 需要什么

耳朵和嘴各选一个，默认都走本机、不花钱：

| | 默认 | 其它选择 |
|---|---|---|
| **耳朵**（听你说） | 本地 faster-whisper（`127.0.0.1:8000`） | 任意 OpenAI 兼容转写接口、自定义 HTTP |
| **嘴**（她说话） | 跟随插件「语音」页的引擎 | 本地 GPT-SoVITS / CosyVoice、微软 edge-tts、任意 OpenAI 兼容语音接口、自定义 HTTP |

**只想先试试**：把「嘴」设成 `edge`（微软 edge-tts，免费、不用部署），耳朵留本地或换任意线上转写，就能跑起来。要接自己的平台，看 [PROVIDERS.md](PROVIDERS.md)，里面按「三类接入形态」写了怎么填。

## 会访问哪些地址

模块只连**你在设置里填的地址**，默认全是本机：

| 用途 | 默认地址 | 可改 |
|---|---|---|
| 语音识别 | `http://127.0.0.1:8000`（`/health`、`/v1/audio/transcriptions`） | 设置里「识别接口地址」 |
| 语音合成 | `http://127.0.0.1:9880`（`/tts`，GPT-SoVITS） | 设置里「合成接口地址」，或换引擎 |
| 通话页面 / 状态 | 插件自己的端口（`127.0.0.1`） | — |
| 局域网 HTTPS | **默认关闭**；打开后监听 `0.0.0.0:8443`，只转发本模块 8 个接口 | 设置里「局域网 HTTPS（手机用）」+ 端口 |

- **会生成一张自签证书**（`modules-data/voicecall/tls/`，RSA 2048 + SHA256，SAN 覆盖当前局域网 IP 和 localhost，825 天）。手机要开麦克风必须走 https，浏览器不认没有证书的地址，所以只能自己签。**私钥只存在本机**，不上传任何地方。换网段后会自动重签。
- 不会把消息、Cookie、录音发到上面这些地址以外的任何地方。没有埋点，没有远程配置。

## 安全边界（局域网 HTTPS）

手机要在 https 上开麦克风，所以模块自己起了个反代。这一层是按「最小暴露面」做的：

| 措施 | 具体做法 |
|---|---|
| **默认关闭** | `lanHttps` 默认 `false`，新装不会自动开端口，要在设置里手动打开 |
| **路由白名单** | 只转发 8 个路径：`page` `state` `fillers` `filler` `turn` `turn/stream` `say` `hangup`。插件的其它任何 API（配置、面板、模块管理…）**一律 404，连 127.0.0.1 都不碰** |
| **会话令牌** | `dataDir/lan-token.txt` 里 64 位随机串；链接形如 `/page?t=<令牌>`，没令牌或令牌不对一律 401 |
| **HttpOnly Cookie** | 用带令牌的链接打开页面后，令牌种成 `HttpOnly; Secure; SameSite=Lax` 的 Cookie，页面里的请求自动带上，脚本读不到 |
| **令牌不落日志** | 转发前把 `t=` 从 URL 里摘掉；启动日志也不打印带令牌的完整地址 |
| **防爆破** | 令牌连续错 20 次，锁 5 分钟（429） |
| **可一键作废** | 面板「换新链接」会重新生成令牌，旧链接立即失效 |
| **只认 GET/POST** | 其它方法 405 |

**令牌等于钥匙**：手机会话地址别发到群里；怀疑泄露就点「换新链接」。

> 关于剥 `Origin`/`Referer`：手机浏览器 POST 必带 `Origin: https://<局域网IP>:<端口>`，而宿主的跨站校验只认自家 Origin，不剥就 403。现在转发范围已经被白名单限定在本模块 8 个接口内，剥掉这两个头最多只影响这 8 个接口，碰不到插件的其它能力。

### 没有中转服务器

模块里没有写死任何服务器地址，作者那台机器不参与任何环节：

- `0.0.0.0:8443` 是在**你自己这台机器**的网卡上监听，只服务你自己的局域网；
- 反代的目标写死是 `127.0.0.1`（你自己的 Aurabot 端口），不是任何远端；
- 页面里所有请求都用相对路径（`/aurabot/api/ext/voicecall/...`），指向**加载页面的那台机器**；
- 装好之后**断网也能用**（本地 faster-whisper + 本地 TTS 全在本机跑），这本身就说明没有外部依赖。

换成线上 ASR/TTS 时，唯一新增的连接就是你自己填的那个接口地址。

## 隐私

- 录音在内存里处理，落盘的音频在 `modules-data/voicecall/audio/`，**两小时后自动清理**。
- 通话内容**不写进 chatlog**（不会出现在 QQ 聊天记录里）；挂断时只把「这一通聊了什么」的一句话总结写进记忆模块，跟私聊记忆同一个池子。
- 密钥类设置（`asrKey`/`ttsKey`）在面板里不回显，日志自动打码。

## 设置

面板 →「通话」→ 设置区，常用的几项：

| 设置 | 作用 |
|---|---|
| 耳朵：语音识别 | `local` / `openai` / `http` |
| 识别接口地址 / API Key / 模型 | 选线上时要填 |
| 嘴：语音合成 | `follow`（跟随「语音」页）/ `gptsovits` / `cosyvoice` / `edge` / `openai` / `http` / `windows` |
| 合成接口地址 / API Key / 模型 / 音色 | 选线上时要填 |
| 返回格式 | `pcm` 能边合成边播（最快），平台不支持就填 `mp3` |
| 一次最多说多少字 | 默认 120，电话里话太长不像人 |
| 局域网 HTTPS / 端口 | 手机用；不用手机可以关掉 |

换引擎后垫话（「嗯？」「我在呢」这四句）会按新音色自动重做一次，第一次通话可能慢一点。

## 手机怎么用

1. 保持在同一个 Wi-Fi。
2. 面板底部有「复制手机地址」，形如 `https://192.168.x.x:8443/aurabot/api/ext/voicecall/page?t=<令牌>`。**链接里带会话令牌，别外传**；换了新链接旧的立即失效。
3. Chrome 第一次会提示「您的连接不是私密连接」→ **高级 → 继续前往**（自签证书的正常现象）。
4. 允许麦克风，点开始通话。

Windows 上如果手机连不上，多半是防火墙：需要放行入站 TCP 8443（仅本地子网即可）。

## 排错

面板里能看到两行状态：**耳朵**、**嘴**。

- 耳朵「不可用」：本地识别服务没起来，或者线上地址/密钥填错。
- 嘴「不可用」：本地合成服务没起来，或者线上配置不对。合成失败会自动降级（`edge` → Windows 语音），日志里会写原因。
- 说话没反应：确认页面是 `https://`（http 下浏览器不给麦克风），以及麦克风权限。
- 首句慢：优先选能流式的引擎（`gptsovits`、`openai` + `pcm`）。整段返回的服务会明显慢半拍。
