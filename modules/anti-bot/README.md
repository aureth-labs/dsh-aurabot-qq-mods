# 人机反面教材

从评论区里认出「一眼就是 AI」的发言，收成反面教材；同时把真人说得有意思的金句收起来当学习材料。
每轮聊天会把最近几条塞进她的上下文 —— **「这些别学」+「真人怎么说」**，比讲抽象规则管用得多。

## 它怎么认

打分制，不联网也能用。

**认人机**（够 4 分算）：

| 特征 | 分 |
|---|---|
| 客服腔 / AI 自述（`作为一个AI语言模型`、`希望对你有帮助`） | 5 |
| 列点 / 总结体（`首先…其次`、`以下几点`、`总之`） | 5 |
| 标题 / 加粗排版（`**亮点**`、`【总结】`） | 3 |
| 公文体转折（`总的来说`、`值得注意的是`） | 3 |
| 表情堆砌（三个以上 `[doge]` 或 emoji） | 2 |
| 过度客套（`感谢分享`、`如有疑问欢迎留言`） | 2 |
| 一条评论写成长文（150 字以上） | 2 |
| 排比套话（`既…又…还`） | 1 |

真人味会**减分**：口癖（草、笑死、6、破防）、第一人称自述（我也、我上次）、超短句、省略号留白、连问号。

**认金句**（够 3 分算）：
先排除人机 → 长度 4~80 字 → 有真结构才收：
反转对比 / 比喻 / 自嘲 / 夸张到好笑 / 化用古诗 / 嘴上吐槽 / 具体细节 / 口语方言 / 结尾一个表情。
纯占位符（`[图片]`、`[合并转发]`）和只有「短促有力」没有架子的碎句，一律不收。

## 怎么配置

面板里能调：门槛（认人机的分数）、每轮塞几条、在私聊还是群聊提醒、金句门槛、自动清理旧条目的天数。

## 怎么用

- 面板：左边测一句（同时告诉你像不像人机、够不够金句），右边两个库可以逐条删
- QQ 命令：`/人机` 看反例库、`/人机 加 那句话` 手动收；`/金句` 看金句库、`/金句 加 那句话`
- 工具：`mark_bot_comment`、`save_good_line`（她自己认出来时会调）
- 接口：`/ext/anti-bot/{state,test,add,add-good,remove,remove-good,harvest}`

## 会访问哪里

- **不联网**。全部判定都在本地做。
- 读写自己数据目录下的 `reverses.json`（反例库）和 `goods.json`（金句库）。

`plugins-data/aurabot/modules-data/anti-bot/`
