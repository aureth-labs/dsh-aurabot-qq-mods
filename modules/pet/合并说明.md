## 有意保留的本地差异

1. **物理键只挂一套**。上游 1.0.14 另开了 `petGravity/petRestitution`，与本地 `physicsGravity/physicsRestitution` 是同一件事。
   面板上只展示 `physics*`（否则会出现两个「重力」滑条各调一半）。
   `physicsFromSettings()` 读的时候优先 `pet*`、没有才用 `physics*`——将来上游面板真往 `ext.pet` 写 `pet*` 也认。
2. **余额走本地实现**。上游 `/balance` 是「诚实降级」永远回 `ok:false`；本地有真 API Key 查询 + 6 档动画 + 台词。
   所以本版 `/balance` 返回 `{ok, enabled, configured, result, wallet, view}`（HTTP 200），不是上游的 502。
3. **渲染页是双视频槽 `.anim-slot`**，上游是单 `<video id="anim">`。所以 `hold-squash` / `transform-origin`
   挂在 `.anim-slot` 上（同一语义，不同选择器）。
4. **版本号** `1.1.0-local.1`：比上游 1.0.16 高，社区模块市场不会提示更新、更不会被点「更新」覆盖掉本地改动。

用上游 1.0.16 的测试套件（223 项里的 200 项，另 23 项依赖上游仓库结构）跑同一份代码：

| | tests | pass | fail |
|---|---|---|---|
| 纯本地版（合并前） | 200 | 158 | 42 |
| 合并版 | 200 | 186 | 14 |

**合并引入的新失败：0 条。** 合并顺带修好 28 条。

剩余 14 条失败全部在**纯本地版里就已经存在**，且都不是功能缺失：

- 上游断言绑死了它自己的实现写法（`#anim` 单视频、`petGravity` 双键、版本号必须 `1.0.16`、`/balance` 必须 502）；
- 或断言本地故意不同的行为（会话标题格式、`--no-sandbox` 启动参数、打包流程）。
