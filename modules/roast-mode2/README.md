# 毒舌模式2（roast-mode2）

发关键字开/关某个聊天的毒舌模式。开着时不再随机抽一句语料直接发，而是把**当前档位**的语料当**风格示例**，
结合最近聊天，让模型针对对方**刚说的这句话**现编一句毒舌回复（引用回复）。

和市场上已有的 `roast-mode` 不同：那个是「语料直出」，本模块是「语料风格 + 现场生成」。两者可以共存，但别在同一个聊天里同时开，否则会抢答。

## 三档分级

| 档位 | 名字 | 攻击性 | 语料文件 | 风格 |
|---|---|---|---|---|
| 1 | 傲娇嘴硬 | 最轻 | `corpus_1.txt` | 嘴硬心软、口是心非、怼里带点在意，点到为止 |
| 2 | 损友毒舌 | 中（默认） | `corpus_2.txt` | 阴阳怪气、句句带刺、先夸后损、建议式反讽 |
| 3 | 狂暴模式 | 最强 | `corpus_3.txt` | 贴吧狂暴老哥风：短句轰炸、反问连击、歇后语黑话、往痛处怼、补刀不留情面 |

档位在设置里选，**不同档位读不同语料库、注入不同强度的提示词**。每档内置 35 条语料，可在文件里自行增删改。
第 3 档是真正的「狂暴」而非傲娇：2 到 4 句连怼、120 字以内、不用客气不用留面子，提示词里不再有 60 字上限、「你这逻辑/操作/理解/发言」模板和情绪关心软化。只怼这句话本身，别套模板句式。

## 用法

1. 先在设置里选档位（1/2/3，默认 2）。
2. 主人（默认只有主人能开关）在当前聊天发：
   - `毒舌开启` —— 开启，之后这个聊天的消息会被本模块接管
   - `毒舌关闭` —— 关闭，恢复正常
   这两个词是默认值，可在设置里改；如果你还装了别的毒舌模块，建议把其中一个的开关词改开，避免同时响应。
3. 也可以直接对她说「开毒舌模式2 / 关毒舌模式2」，她会用工具拨开关，并回报当前档位。
4. 开关词宽松匹配：`毒舌开启/关闭`、`智毒开启/关闭`、`关毒舌`、`狂暴关闭`、`关掉毒舌模式2`、`别毒舌了` 都认，带 `@机器人` 或「帮我」「了」也不影响。**关掉是安全操作，任何人都能关**（开启仍只有主人能操作）；面板里还有「全部关闭」按钮，一键清空所有聊天的开关。
5. 开启状态下冷却期内的消息会被吞掉，不回也不交给她；把冷却秒数调小可少吞消息。

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 毒舌档位 | 2 | 1 傲娇嘴硬 / 2 损友毒舌 / 3 狂暴模式 |
| 开启/关闭关键字 | 毒舌开启 / 毒舌关闭 | 可改 |
| 只有主人能开关 | 开 | 防别人乱拨 |
| 冷却秒数 | 8 | 两次毒舌最小间隔 |
| 从文本文件读语料 | 关 | 开则读数据目录里**当前档位**的 `corpus_N.txt`（每行一句，`#` 注释忽略），关则用内置语料 |
| 带上几句上下文 | 6 | 参考最近几条聊天，让吐槽贴题；0=只看当前这句 |
| 追加说话方式 | 空 | 自己补口癖/语气要求 |

语料文件的**完整路径**显示在本模块面板页的「毒舌语料 · 三档分级」卡片里：当前档位路径 + 三档文件一览，旁边有「打开语料文件夹」按钮（仅 Windows）。改完保存即可，无需重启；删掉某个 `corpus_N.txt` 会在下次触发时重新生成该档默认语料。

旧版 `corpus.txt` 若有自定义内容，升级后会自动作为 2 档语料的起点（仅当 `corpus_2.txt` 还不存在时）。

## 风格与安全

- 说话方式：短句分几条发、少标点空格断句；3 档是贴吧狂暴老哥风，短句轰炸、反问连击、歇后语黑话，2 到 4 句连怼 120 字以内，往痛处怼不收着。
- 只怼对方这句话的内容，抓漏洞往死里锤，别套「你这逻辑/操作/理解/发言」模板句式，不拿家人、祖先、身体或身份说事。**不真骂人：不吐脏字、不地域/性别/种族歧视、不诅咒、不外貌羞辱、不人身威胁；除这几条外火力不受限制**。
- 1/2 档在对方明显情绪低落或求助时会改为正常关心；3 档去掉了这条软化。
- 模型调用失败（超时/报错）时，自动回落到**当前档位**语料：3 档拼两条不重复的狂暴语料模拟连击，其他档单句，保证离线也够冲。

## 会访问的地址

**无。** 模块不自己联网、不抓取任何网页、不访问任何外部服务。
“生成回复”通过插件提供的 `api.ask` 走已配置好的模型，不额外发数据到无关地址；
用户的聊天内容只进这一次模型调用，不写文件、不外发。

唯一的本机动作：点面板上的「打开语料文件夹」会启动 Windows 资源管理器（`explorer.exe`）打开模块数据目录，只在点按钮时触发，不联网、不上传任何内容。

## 权限说明

- `filesystem`：读写自己数据目录里的 `state.json` 和三份 `corpus_N.txt`。
- `process`：仅用于面板「打开语料文件夹」按钮**启动资源管理器（`explorer.exe`）**显示数据目录；非 Windows 平台在启动前直接拒绝并提示手动访问，不会启动其他程序，也不会带任何参数执行外部命令。
- `plugin-internals`：仅用 `api.core.hub.turnSendersAllOwner(sessionId)` 判断工具调用是否本轮全是主人，防止群友借权开关。
- 不群发、不加好友、不发帖、不绕过验证码、不刷量；运行时不下载执行代码。

## 开发者

入口 `index.mjs` 导出了 `parseCorpus` / `pickSamples` / `pickLine` / `buildSystem` / `buildUser` / `cleanReply` 纯函数；
`lib/corpus.mjs` 导出 `TIERS` / `TIER_ROLE` / `TIER_STYLE` / `normLevel` / `corpusTemplate`，方便写测试。
模块 id、version、api 与 `module.json` 保持一致；改版本时两处都要升。
