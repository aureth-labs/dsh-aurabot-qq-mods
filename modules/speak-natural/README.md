# 说话自然度

让她像正常人打字一样说话，不要 AI 腔。

## 解决什么问题

常见的「AI 味」：

- 每句都挂颜文字和 ♡，一句话里堆好几个
- 冒出 `[沉默][沉默][沉默]` 这种重复标记
- 句子长、爱解释、爱总结、爱列点
- 括号里写动作，像在念剧本
- 「总之」「总的来说」「首先其次」「希望这能帮到你」

## 两层做法

**① 规则层（根上改）**
把「正常人怎么说话」写进她的规则里：
短、一条一两句、不书面语、不总结不复述、不解释自己为什么这么说、颜文字偶尔一个、不写括号动作、被问一句答一句。

**② 清理层（兜底剪）**
发出去之前真剪一刀：

```
原：总的来说，我觉得这个方案挺好的。首先，成本低。其次，时间也够。需要注意的是要提前沟通。
剪：我觉得这个方案挺好的。成本低。时间也够。要提前沟通。

原：（啪嗒啪嗒拍水花）嗯！主人你看这个♡♡ 我觉得挺好吃的呀(´･ω･`)
剪：嗯！主人你看这个♡ 我觉得挺好吃的呀(´･ω･`)

原：[沉默][沉默][沉默]
剪：[沉默]
```

## 档位

| 档 | 效果 |
|---|---|
| 不改 | 原样发 |
| 轻 | 只剪明显累赘（重复括号、书面语开头） |
| 正常 | 短句为主，少表情，去动作括号 |
| 严格 | 几乎不用颜文字和动作 |

群聊默认「正常」（人多，别太吵），私聊默认「轻」（留着她撒娇的味道）。

## 会访问哪里

- **不联网**。纯本地文本处理。
- 只读自己的设置，不写文件。

## 怎么用

面板里有个「试剪一段」的框，贴一句她的话进去，直接看剪完什么样，不会真发出去。
接口：`/ext/speak-natural/{state,try}`
