# 语音通话（callme）

让她用自己的 QQ 账号**真的拨一通 QQ 语音通话**——不是发语音条，是 QQ 里那个「语音通话」。

- **私聊**：跟她说「打个电话给我」「想听你声音」，她拨过来，手机 QQ 响铃
- **群语音**：群里 @ 她说「打个群电话」「群语音来一个」，她在群里开语音，并且**把 @ 她的那个人一起拉进来**
- **挂断**：主人随时能挂；刚要求发起通话的那个人也能挂，别人不行

> 这是 **Windows 限定**模块。原理是用 UI 自动化点 QQ NT 桌面版的按钮（`assets/call-out.ps1` / `assets/hangup.ps1` 两个 PowerShell 脚本）。

## 环境要求（必须）

| 要求 | 说明 |
|---|---|
| Windows 10 / 11 | 依赖 PowerShell 5.1 + 系统自带的 UIAutomation |
| QQ NT 桌面版 | 9.9.x，已登录、能正常收发消息 |
| 屏幕解锁 | 锁屏 / 息屏时点不到按钮，会失败 |
| QQ 窗口正常尺寸 | 群语音的「选择成员」对话框按窗口坐标定位，最大化也可以 |

Mac、手机 QQ、TIM 老版、网页版 QQ 都不行。

## 用法

1. 先在面板这个模块的设置里填**默认联系人**（QQ 里的备注或群名片，要和会话列表显示的一致），或者临时跟她说「打给花辞树」——会从这句话里取名字
2. 对她说「打个电话」「想听你声音」「打个群电话」；也可以直接 `/callme` 看设置
3. 想挂断就说「挂了」「挂断」

关键词自动拨号默认**关着**，也就是不会因为句子里出现「打电话」三个字就拨——由她自己判断你是真的想通话（`voice_call` 工具）。想让她听到关键词就拨，把「关键词自动拨号」打开。

### 群语音怎么拉人

群里开头会弹「选择成员」对话框。脚本会：搜索你的群名片 → 只剩一个人就勾选；**重名或搜不到时改用你的 QQ 号搜**（QQ 号搜出来只剩一个）；还是分不清是谁就**跳过不拉**，宁可不拉也不拉错人。然后点「确定」。

## 配置

| 设置项 | 默认 | 说明 |
|---|---|---|
| 默认联系人 | 空 | 私聊说「打电话」时打给谁；留空则用当前聊天对象 |
| 两次拨号最短间隔（秒） | 60 | 防止连拨 |
| 关键词自动拨号 | 关 | 开着才按关键词拨，否则只由她判断 |
| 群里被 @ 说「打群电话」时开群语音 | 开 | 关掉后群里不会自动开语音 |

## 会访问什么

- 不联网：模块本身不发任何 HTTP 请求，全部通过本机 QQ 界面操作
- 会 `spawn` 系统 PowerShell 跑模块自带的两个脚本（`capabilities: process`）
- 脚本会在模块目录 `assets/logs/` 下写日志（`call-out.log`、`hangup.log`），方便排查哪一步没点到
- 不读 Cookie、不改配置、不上传任何内容

## 已知限制

- 只是「拨号 / 挂断」。要真正双向说话（她说→识别→她回答→放回通话里），还得在本机另配语音桥接（虚拟声卡 + 本地识别 + TTS），那部分是独立的一套本地服务，不在这个模块里
- 群语音里没人进来时她会一直等着，需要你说「挂了」或者手动挂断
- QQ 改版把按钮改名 / 挪位置时脚本会找不到，日志里能看到卡在哪一步
