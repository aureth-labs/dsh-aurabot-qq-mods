# 自主学习（autonomy）—— 给 DSH / aurabot 用

主人不在的时候，她也能自己动起来：刷 B 站、翻网站、画画、整理笔记，做完有想法就说两句，没想法就沉默。

## 装在哪

把 `index.mjs` 丢进：

```
%USERPROFILE%\.dsh\plugins-data\aurabot\modules\autonomy\index.mjs
```

（这个目录插件升级不会动。）然后在插件管理器里重载一次 aurabot。

## 开不开

默认是**关**的。要在 `%USERPROFILE%\.dsh\plugins-data\aurabot\config.json` 里加上：

```json
"autonomy": {
  "enabled": true,
  "everyMin": 45,
  "idleMin": 40,
  "maxPerDay": 6,
  "quietFrom": 23,
  "quietTo": 8
}
```

- `enabled` 总开关
- `everyMin` 多久检查一次（分钟）
- `idleMin` 主人多久没说话才算「不在」
- `maxPerDay` 一天最多自己动几次
- `quietFrom` / `quietTo` 安静时段，支持跨午夜（23→8 就是 23:00 到次日 08:00 不动）

## 它是怎么动的

到点了就往主人私聊的会话里塞一条系统提示，让她自己开一轮。**那一轮里工具全开**，跟平时一样，
所以刷 B 站、翻网站、画画、查记忆、写笔记都能用。

## 有几个坑，我替你踩过了

1. **`api.dataDir()` 不带参数返回的是目录本身，不是文件路径。**
   要写成 `api.dataDir('state.json')`，否则报 `EISDIR`。

2. **模块拿到的 hub 是白名单副本，getter 被改成了普通属性。**
   `hub.lastOwnerChatAt` 直接读就是数字，写成 `hub.lastOwnerChatAt()` 会报 `is not a function`。
   稳妥写法：
   ```js
   const v = hub.lastOwnerChatAt
   const n = Number(typeof v === 'function' ? v.call(hub) : v) || 0
   ```

3. **`api.every` 的间隔在启动时定死。**
   所以定时器改成一分钟一跳，到没到点交给 `shouldAct()` 自己算——这样改了 `everyMin` 也能立刻生效。

4. **模块里 `api` 上只有 `defineTool`，没有 `str` / `int`。**
   要写工具的话，properties 得手写 JSON Schema。

## 手动试一次

- `POST /aurabot/api/ext/autonomy/fire` 立刻动一次
- `GET /aurabot/api/ext/autonomy/status` 看现在为什么动 / 为什么不动
- `POST /aurabot/api/ext/autonomy/tune` 临时调参数，body 给 `{"maxPerDay":8}`

## 最后一句

别把它调太勤。她的价值不在跑得多，在于跑的时候真干了点事。
