# 睡觉做梦（sleep）

## 睡眠
入睡时间与醒来时间都是随机的，会失眠（一晚上睡不着），也可能瞬间入睡。有固定作息 / 习惯 / 自由三种排程模式。

## 做梦
梦的素材来自白天真实经历（B站、抖音、日记、聊天记录等），并按「变形」规则重组：白天的事要变形、禁止清单式、必须带身体感、允许自相矛盾。

## 梦与现实分离
梦境、梦的残留、分不清真假的三类记忆分别入库，注入快照时带真实度标签，不允许把梦说成真事。

## 能力声明

- `filesystem`
- `plugin-config`
- `plugin-internals`

## 设置

- `scheduleMode` 排程模式（fixed / habit / free）
- `sleepWindow` 入睡窗口
- `wakeWindow` 醒来窗口
- `insomniaChance` 失眠概率
