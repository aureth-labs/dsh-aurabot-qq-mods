# 模拟人生5

为 Aurabot 的人格卡添加生活安排、素材设定、恋爱、拍照、相册与活动记录。同一个人设可以在聊天、照片和空间日记里沿用自己的衣柜。设定页支持从原图识别人物、服装、场景和道具，生成一张设定板，校订名称与描述后入库。

## 第一次使用

1. 在系统面板打开「模拟人生5」，选择要编辑的人格，在「生活」选预设或自定义，点右上角「保存设置」。
2. 在「设定」上传参考图。使用能读图的聊天模型、支持参考图编辑的生图服务，并先设置每日生成额度。生成请求可能产生费用。界面显示识别、绘制和待入库状态。
3. 在「拍照」选择自拍、人物生活照、环境或物件，搭配素材、关键词及画幅。「相册」可补充标题、别名、标签与画面描述。「记录」可查看任务结果及 QQ 私聊收件箱。
4. 恋爱自动结算、生活状态进入每次对话、主动配图及空间日记配图各有宿主依赖。先到模块设置检查兼容性，再启用需要的能力。恋爱记录按人格及主人身份区分。

## 官方宿主支持范围

已用官方 Aurabot 1.3.0 加载模块，验证四类设定图可经官方识图、生图接口完成转换。默认全局画风为空时可直接使用支持参考图的供应商；希望保留平时的全局画风，同时让设定板遵从参考图，可应用随附的单次画风修复。

原版仍缺少完整的按人格记忆接管、聊天与关系结算来源、DSH 请求前投影及日记配图接口，自动恋爱、见面状态进入对话、主动联系配图、空间日记和顶栏阶段联动需要配套宿主。模块设置会列出当前环境缺少的能力。[逐项说明与可选宿主补丁](docs/HOST_COMPATIBILITY.md)

## 网络、文件与设置

- 识图和制图会将所选参考图与说明发送到用户配置的聊天或生图服务。主动阅读使用本机搜索服务、所选 RSS 和公开网页。分享范围由用户设置。可保持主动阅读、私聊分享、群分享和日记配图关闭。
- 收件箱接收 QQ 网关提供的附件，默认只收主人私聊。可配置文件类型和大小上限。音视频转写可调用本机 ffmpeg 和已有转写服务，压缩包与文档按受支持格式读取。
- 素材、照片与收件箱保存于模块数据目录。恋爱沿用原有的 `modules-data/character-relation` 档案。设置、人格身份、聊天来源和模型配置通过宿主读取。自动判定使用可核实的主人私聊和实际投递回执，以免其他聊天或重复事件错误加分。
- 已有独立恋爱或收件箱的设备先备份数据、核对接管能力，再迁移。旧收件箱的附件须自行留存。更新模块应保留模块数据、人格卡、照片和原关系目录。
