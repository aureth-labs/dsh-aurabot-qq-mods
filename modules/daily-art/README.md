# daily-art · 每日推图

适用于 [Aurabot QQ](https://github.com/aureth-labs/dsh-aurabot-qq) 的 Konachan 和 Yande.re 推图模块。支持白名单定时推送和 QQ 会话按需找图。定时任务可设置推送时间和张数，不消耗模型 token。按需找图由模型理解需求，模块负责查询、筛选、下载和发送。

## 安装

需要原版 Aurabot 1.2.0 或更高版本和已连接的 QQ 网关。本模块无 npm 依赖。可选代理功能需要 Node.js 24.5 或以上。CI 使用上游提交 [`0a0ccb1`](https://github.com/aureth-labs/dsh-aurabot-qq/commit/0a0ccb1cc401dee00ce0faac2cffbf57d0efecda) 验证市场安装流程。

上架后可在 Aurabot 面板的「模块市场」点安装。手动安装可使用 [GitHub Releases](https://github.com/Reinero/aurabot-daily-art/releases) 中对应版本的 ZIP。

将 ZIP 解压到 Aurabot 数据目录的 `modules/daily-art/`，确保 `index.mjs` 和 `module.json` 直接位于该目录。Windows 默认位置为 `%USERPROFILE%\.dsh\plugins-data\aurabot\modules\daily-art\`。Docker 部署时，把模块复制到 **Aurabot 容器**对应的数据卷，确保服务运行用户可读写模块目录和模块数据目录。

加载模块后，打开「平台 → 每日推图 · 逛图站」。页面上方是共用代理设置，下方可切换 Konachan 和 Yande.re 分栏。两个图源分别保存定时、张数、白名单和筛选条件。

## 图片缓存

在「平台 → 每日推图 · 逛图站 → 图片缓存」开启「缓存图片」并保存设置。开关默认关闭。开启后，Konachan 和 Yande.re 的定时推送、按需找图都会保存成功下载的图片。同一图源的相同图片只保留一份。

缓存目录接受 Aurabot 运行环境中的绝对路径。留空时，若有 Docker 共享目录 `/workspace/AuraBotDoc`，图片会保存到其下的 `daily-art-images`。其他环境默认保存在模块数据目录的 `daily-art-images`。

## 定时推送

在「平台 → 每日推图 · 逛图站」填写群聊、私聊推送白名单，打开「开启定时推送」并保存。模块加载后默认关闭。
名单独立于 Aurabot 的聊天权限，默认留空，不会从聊天权限自动导入。号码每行一个，也可用逗号分隔。主人私聊若要接收，也要填入私聊推送白名单。
批次建立时确定接收名单，之后加入的目标从新批次开始接收。发送或重试前会重新检查名单，已移除的目标不发送。

「每日推送时间」使用北京时间和 24 小时制，如 `08:30`、`19:15`。每行填一个时间，也可用逗号分隔。默认每天 09:00、17:00 各发一批。每批可选 1–10 张，默认 5 张。启动或保存后会补发当天已过时点但尚未发送的批次，跨日不追发。改张数时，已选图的批次继续使用原张数。
每个时段使用同一批图片，逐个向白名单目标发送。网关明确失败时约 5 分钟后重试未收到的目标；网关回执不明时跳过重发。
图片永久失效时，模块用符合原筛选条件的新图替换，下次仅补发待发送的收件人。
总开关关闭或处于试运行时，任务不发送，也不消费当天的批次。

模块从图源的 `/post.json` 接口按保存的条件选图，并下载图片后交给 QQ 网关。定时任务不调用模型或视觉工具。

| 筛选项 | 用法 |
| --- | --- |
| 评分 | 默认最低 31。上下限都包含边界，最高分可留空。 |
| 包含、排除标签 | 各最多 5 个英文站点标签。包含条件全部满足，命中任一排除条件就跳过。用空格、换行或逗号分隔。 |
| 定时推送分级 | Yande.re 可多选 Safe（`s`）、Questionable（`q`）、Explicit（`e`），匹配任一勾选项即可，默认仅 Safe。当前 `konachan.net` 仅支持 Safe。 |
| 宽高与画幅 | 可填最小宽度和高度，也可选横图、竖图或方图。 |
| 排序 | 按新旧、评分或分辨率选图。默认最新优先。 |
| 高级筛选 | 接受 `id`、`width`、`height`、`mpixels`、`ratio`、`date`、`parent`、`user`、`source`、`md5`、`vote`。如 `ratio:16:9 mpixels:2.5..`。使用空格或换行分隔。高级宽高条件与相应的最小宽高只能选一种。 |

高级条件由 [Konachan API](https://konachan.net/help/cheatsheet) 执行。新筛选用于尚未选图的批次，已选好的批次仍按原记录补发。凑不齐设定张数时，模块记录原因并稍后重试。
修改分级后，旧分级的待发送批次会跳过，后续新批次按新分级选图。

## 图源、凭据和代理

在「平台 → 每日推图 · 逛图站 → 图源凭据」可以保存或清除 API Key 和代理地址。各图源分栏下方可以检测连接，普通推送设置使用页面底部的「保存设置」。

凭据管理可从本机面板访问。通过反代使用时，请配置 Aurabot 的可信反代地址和面板域名（若使用域名），让同机反代传递原始 Host 和追加真实客户端地址至 `X-Forwarded-For`。远程面板需要开启 Aurabot 的远程面板访问，并在反代层启用登录认证。
API Key 和代理地址保存在 `modules-data/daily-art/credentials.json`，请保护该文件和备份。清除密钥或代理时先点对应清除按钮，再点「保存凭据」。定时推送与按需搜索使用已保存的密钥访问 `konachan.net`，留空使用公开接口。
账号凭据不完整或认证被拒绝时，自动用同一代理设置重试公开接口。连接检测会显示回退原因。遇到 Cloudflare 验证或网络故障时，显示对应错误。

「共用代理地址」可填写 `http://` 或 `https://` 代理。Windows 上的本机代理可填写容器能访问的地址，例如 `http://host.docker.internal:7890`。未配置时直连。两个图源的 API 请求和图片下载共用此设置。在各自分栏点「检测连接」可检查 API 和样图下载。代理功能需要 Node.js 24.5 或以上。

Konachan 日常请求 `konachan.net` 的 `/post.json`、`/tag.json` 和候选图片地址，连接检测另外查询 `konachan.com/post.json`。Yande.re 请求 `yande.re` 的 API，并从 `files.yande.re` 等站内地址下载图片。单张图片下载上限为 4 MiB。

## 排查与数据

在「系统 → 日志」查看 `[Konachan]` 记录。连接检测、请求失败和公开接口回退会记录站点、阶段、HTTP 状态、耗时、代理模式及认证方式。Cloudflare 响应会附上 Ray ID（若返回），便于站点运营方查询对应事件。日志省略密钥、代理地址、查询参数和响应正文。
连接检测使用与保存凭据相同的面板访问规则，正文上限为 4 KiB，同一时刻只运行一次。

批次和已使用的来源 ID 存在 Aurabot 数据目录的 `modules-data/daily-art/delivery.json`，重启后保留。移除记录会使历史图片重新进入候选。
Yande.re 使用单独的 `modules-data/daily-art/delivery-yandere.json`，API 请求访问 `yande.re`，图片可能从 `files.yande.re` 下载。日志用 `[Yande.re]` 标记。

定时推送和按需找图共享按 QQ 会话保存的发送记录。作品 ID 或图片指纹相同的图片会跳过。首次加载会导入现存推送批次中已发出或发送结果待确认的记录。发送回执超时时，图片保留在去重记录中，避免下一次请求重复发送。

## 在 QQ 里按需找图

直接发 `yande找图` 或 `konachan找图`，会随机发送一张当前会话尚未收到的 Safe 图片，并附上一条筛选示例。

1. 在 Aurabot 已允许聊天的 QQ 会话里，用「konachan找图」开头。例如「**konachan找图** 初音未来的横图，按评分排序」。模块会在同一轮查找并发图，再附上分数、分辨率、站点标签和作品链接。没指定数量时发 1 张。
2. 想先选图时，在请求里加「先列候选」，再在同一会话发「konachan找图 发第 2 张」。
3. 候选在该会话保留 10 分钟。主人私聊需要「受限」或「完整」权限。定时推送开关及其白名单用于定时任务。
4. 非主人私聊默认不能按需找图。要开放给指定用户，先将对方加入 Aurabot「系统 → 权限」的私聊白名单，再到「平台 → 每日推图 · 逛图站」开启「允许私聊白名单用户按需找图」并保存。该开关适用于两个图源，白名单用户只可查 Safe（`s`）。

找图命令由模块接管。原版宿主通过 `api.ask` 返回结构化筛选计划，这三个操作在模块内按请求执行。

| 模块操作 | 职责 |
| --- | --- |
| `image_search_help` | 返回图源、筛选规则、排序方式。传 `tag_prefix` 可查 Konachan 的英文标签。 |
| `image_search` | 返回候选的作品 ID、评分、尺寸、标签和作品页。支持包含或排除标签、评分和尺寸下限、画幅，以及按最新、高分或分辨率排序。 |
| `image_send` | 从发起人的同一会话、图源及分级组合的候选中选图，下载并发送最多 5 张图片。 |

按需找图默认只查 Safe（`s`），与定时推送的分级勾选独立。只有主人在关键词后明确指定 `q` 或 `e`，才会查这些分级。Yande.re 支持单选和逗号分隔的多选。Konachan 只支持 Safe，所选分级中有图源不支持的选项时会提示并停止查询。

- `yande找图 初音未来的横图` 搜索 Safe 作品。
- `yande找图 rating:q 初音未来的横图` 只搜索 Questionable 作品。
- `yande找图 rating:s,q 初音未来的横图` 搜索 Safe 或 Questionable 作品，合在一起排序，张数上限按整条请求计算。
- `yande找图 rating:s,q 发第 2 张` 从先前列出的候选中选图。选图时使用同一图源和分级组合，组合顺序可以调换。
- `yande找图 鸣潮 rating:e,q 最近一周` 用站点标签 `wuthering_waves` 查过去 7 天发布的 Explicit 或 Questionable 作品。分级可写在主题前后，主人说「不限 rating」或「无限制」也按 `e,q` 查询。

省略评分条件时不限作品分数。写「30 分以上」会筛选评分至少 30 的作品。
只写筛选条件也可以找图。例如 `yande找图 最近一个月 rating:e 分数30以上` 会找过去 30 天发布、评分至少 30 的 Explicit 作品。

图片下载遇到连接重置时最多重试两次。QQ 群发回执超时后，模块会查近期群历史。查到对应图片就记为已送达，查不到时保留待确认状态，避免重复发送。
