# 画图前核对请求

启用后，机器人准备调用 QQ 绘图工具时，会用当前聊天模型核对一次用户的原话。要查资料、找现成图片或描述图片时，机器人可以继续回答或搜索。明确要画图、改图或接着画时，按原来的绘图权限执行。

普通聊天不增加模型调用。核对使用当前会话的模型服务，读取本轮文字、用于理解追问的相邻一轮文字，聊天图片的来源标记，以及即将执行的绘图描述。拟画的主体或参考图与要求不符时，机器人会收到调整绘图参数的提示。每张不同的图分别核对，会消耗少量 token。超时或无法确定时，本次绘图暂停。私聊或群里能确定唯一请求者时，核对期间收到这个人的文字补充会再判断一次；通过唤醒词或引用回复发起的请求也支持。群里其他人的插话按正常聊天顺序处理。图片交给绘图服务后，后续消息按下一步请求处理。面板直接绘图和定时任务沿用原来的流程。

依赖 DSH 的 `tools/pre-execute` 和 `Session.deriveMessages()`。只处理 Aurabot 群聊和私聊的 `qq_draw_image`。停用本模块即可恢复原来的流程。

核对拦截或判定解析失败时，插件调试日志会保留最多 2048 字符的判定输出。已配置密钥按宿主规则脱敏；不记录聊天输入或绘图参数，不进入模型上下文，也不发到群里。
