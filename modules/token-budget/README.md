# 预算管家（token-budget）

省 token 的预算管家：她每轮想事情之前，把「交给她的内容」封顶在预算内、只用本地相似度挑最相关的几条旧事带着、
把一天的用量记成账，花超了自动熔断。目标就是那句——**一天一角，能一直开着**。

## 做什么

| 手段 | 具体做法 |
| --- | --- |
| 固定窗口 | 每轮注入内容（记忆提示、背景、话题）按预算截断（默认 8.5k token），聊多久都不超 |
| 只带 16 条 | 不全量注入记忆：用**本地**中文 2-gram 相似度从记忆库里挑最相关的 top-K（默认 16 条） |
| 本地向量 | 挑记忆不打 embedding 接口，纯本地计算，零成本 |
| 预算熔断 | 估算记账，日花费达熔断线（默认 15 元）自动停：80% 先把非主人聊天换便宜模型，100% 非必回的消息不接 |

**必回的消息（被 @、主人说话）永远不拦**——省钱不能变成装死。

## 怎么用

装上即用，面板「预算管家」页改设置；QQ 里发：

- `/预算` —— 查今天花了多少、近 7 天走势
- `/预算 20` —— 把熔断线改成 20 元
- `/预算 解除` —— 今天豁免熔断（明天恢复）

## 会访问哪些网址

**一个都不访问。** 不联网、不上传任何消息、不调远程接口。

## 口径说明（重要）

- 人格、规则、会话历史**不经过**本模块，预算只封顶「交给她的内容」这一段；不是全请求预算。
- 记账是**估算**（中文按 0.6 token/字、其余按 0.3 token/字符），而且 system 轮 / 工具调用的隐形消耗
  不经过消息事件，靠「隐形消耗放大系数」（默认 1.3）补偿。数字供预算参考，不是账单。
- 记忆来源是内置「记忆」模块；它没开时只做预算封顶和熔断，不额外挑记忆。
- 软熔降级需要在设置里填「便宜模型」（如 `deepseek/deepseek-chat`）；留空则软熔只提醒、不换模型。

## 数据放哪

只写自己的数据目录 `modules-data/token-budget/ledger.json`（按日滚动的账本，保留 30 天）。
