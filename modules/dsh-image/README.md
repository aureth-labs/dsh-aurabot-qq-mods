# 生图 · DSH 已接入模型

让 Aurabot 用 **DSH 里已经接好的生图模型**画图——比如豆包插件接入的「豆包 生图（Seedream 5.0）」。
不用另外填接口地址和 API Key，也不用重复买一份额度：DSH 里能用的生图模型，这里就能用。

模型清单是**动态拉取**的：在 DSH 里新接一个生图模型，点一下「刷新模型」就能看见，不用等模块更新。

## 装好之后怎么用

1. 面板 →「生图」页 → 最下面「用 DSH 已接入的模型生图」。
2. 打开「开启」。
3. 在筛选框里输入关键词（如 `seedream`、`豆包`）缩小范围，然后在下拉框里**自己选一个模型**，保存。
4. 聊天里让她画：`@她 画一只躺在云上的橘猫`。走的是原来的 `qq_draw_image` 工具，其它玩法都不变。

**必须自己选模型**：没选就不会接管，照旧用内置生图。这是刻意的——自动挑一个等于替你决定花哪份额度。

清单是空的？那说明 DSH 里还没有接入生图模型——先去装/登录对应插件（例如豆包插件），回来点「刷新」。

## 它怎么选模型

只认**明确的生图模型**：以 DSH 模型目录里的 id 或名称为准，命中「生图 / 绘图 / 图像生成 / Seedream / DALL·E / gpt-image / flux / cogview / qwen-image / wanx / grok-imagine」这类特征才算。

- 普通聊天模型（如「豆包 2.1 Pro」）不会混进来。
- 「图片理解」类模型（能看图，但不能画）也不算。

选中模型后，请求按一轮对话发出去：提示词前面会自动拼上「生图」页里配的**风格描述**（`stylePrompt`），和原来一致。

## 与内置生图的关系

内置生图有三条路：OpenAI 兼容接口、自定义接口、Codex 订阅。这个模块是**第四条**：

- **开着且自己选了模型** → 先用 DSH 已接入的模型画。
- **没选模型 / 选的模型消失了** → 自动落回内置那三条，不报错。
- 带参考图的改画（图生图）不走这条路：对话模型通道没有统一的编辑协议，会照旧落到内置接法。
- 关掉 → 完全等同没装。

### 会消耗哪份额度

走对话模型的生图（例如豆包）消耗的是**该提供方的对话额度**，不是本插件的生图额度。面板里已写明这一点，请在选择前确认。

## 会访问哪里

- **DSH 宿主**：通过 `api.dsh` 拿 `llm` 服务（列目录、发流式请求）和 `attachments`（读回图片块）。这是插件内部接口，插件升级后可能变。
- **网络**：只在模型返回图片地址时才下载。地址必须是公网；解析到 loopback / 私有网段 / link-local / CGNAT / 组播一律拒绝，重定向逐跳重新校验。单张上限 20MB。

## 权限

模块声明了 `network`、`plugin-config`（读写自己的模块设置）、`plugin-internals`（`api.dsh`）。
它不写任何文件、不启动外部程序、不读聊天以外的数据。
