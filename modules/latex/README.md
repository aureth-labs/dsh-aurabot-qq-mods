# LaTeX 渲染

@ 她并给一段公式，她在这台机器上把公式排成图片发回来。

**不走模型**。模块在「回不回」的决定之前就接管消息，所以她不会为了一条公式去思考、去排队、去调模型——从收到消息到图发出去，几十毫秒。

```
你：@她 $\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}$
她：[图]
```

## 为什么快

| 环节 | 以前（用网络渲染服务） | 现在 |
| --- | --- | --- |
| 排版 | 一次 HTTP 请求，TTFB 270~320ms 起，还常排队/502 | MathJax 在本机排，10~40ms |
| 光栅化 + 编码 | 服务端做，图片走网络回来 | 自己算，几毫秒 |
| 模型思考 | 「@ 了她」要走一遍对话 | **完全不经过**（模块接管） |
| 发到 QQ | 网关上传 | 一样，700~900ms，这段谁都躲不掉 |

日志里会写清楚：`画了 1 张（1 条公式）：渲染 12ms，发出去 840ms`。前一个数是这个模块的，后一个数是腾讯的。

## 指令（最快的用法）

不用 @、也不用等她反应过来，直接发一条带指令的消息：

| 指令 | 干什么 |
| --- | --- |
| `\公式渲染 <latex>` | 画一张图 |
| `\公式 <latex>` `/ \渲染` `/ \latex` `/ \tex` | 同上（别名） |
| `#公式 <latex>` | 同上（`#` 也行） |
| `/公式 <latex>` | 同上（`/` 也认；同时注册成了宿主命令，主人发 `/公式` 走命令系统） |
| `\公式帮助` | 回一段用法 |
| `\公式设置` | 看当前设置（仅主人） |
| `\公式字号 60` | 改字号（仅主人） |
| `\公式留白 12` | 改四周留白 |
| `\公式配色 dark` | 白底 / 深色 / 透明 |
| `\公式字色 #1e6fd9` | 只换字色；`\公式字色 重置` 恢复 |
| `\公式布局 stack` | 多条公式拼一张；`separate` 分开 |
| `\公式排版 inline` | 行内排版；`display` 独占一行 |
| `\公式冷却 5` | 同一个人 5 秒内只画一张 |
| `\公式缓存 0` | 关掉缓存 |

配色、布局、排版这些也能写中文：`\公式配色 深色`、`\公式布局 拼一张`、`\公式排版 行内`。

指令前面的 `\` 也可以是 `#`；`/` 开头的归宿主的命令系统管（`/公式`），主人直接发就行。

**谁的权限**：画图、看帮助谁都能用；改设置只有主人（`api.isOwner` 判定），别人发会被挡一句「这个得主人来改」。

## 怎么触发


四种都行：

1. **@ 她 + 带 `$…$`** —— `@她 看看 $a^2+b^2=c^2$`
2. **@ 她 + 触发词 + 裸公式** —— `@她 把公式渲染一下 \frac{1}{2}`（`渲染`/`公式`/`latex`/`tex`/`math`/`排版` 都算触发词，可以在设置里改）
3. **引用一条公式 + @ 她** —— `@她 把这个渲染一下`，公式在她引用的那条消息里（`$$…$$`、`\[…\]`、`\(…\)`、`$…$`、或者干脆就是一串 `\int_0^1 x dx`）
4. **私聊直接发** —— 私聊不用 @，有触发词或 `$…$` 就画

## 设置项

面板「已安装」→「LaTeX 渲染」→ 设置。改完立刻生效，不用重载。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 触发词 | `latex,tex,math,公式,渲染,排版` | 逗号隔开。消息里有这些词（或 `$…$`）并且 @ 了她，就画 |
| 字号 | 40 | 1em 多少像素。40 大约和聊天里一行字差不多高 |
| 四周留白 | 8 | MathJax 排出来是贴边的，加一点才不会顶到画布边缘 |
| 配色 | 白底黑字 | 也可以选**深色底浅字**（配深色主题）、**透明底** |
| 字色覆盖 | 空 | 填 `#1e6fd9` 就只换字色、底色不变；留空按配色来 |
| 最宽 | 600 | 超过这个宽度就等比缩小，手机上不用左右滑。0 = 不限（调太小会糊，一般 500~800 合适） |
| 只有主人能用 | 关 | 默认谁都能画；打开后非主人发的公式和指令都不接管 |
| 排版方式 | 独占一行 | `display` 舒展（大运算符上下限撑开），`inline` 紧凑 |
| 多条公式 | 一张一张发 | 也可以**竖着拼成一张** |
| 一条消息最多画几个 | 3 | 1~5 |
| 单个公式最多多少字 | 300 | 20~2000，防一条超长公式吃内存 |
| 冷却 | 0（不限） | 设成 5 就是同一个人 5 秒内只画第一张 |
| 群里引用她那条消息再发图 | 开 | 关掉就是直接甩一张图 |
| 读引用的消息里的公式 | 开 | 关掉就不能用「引用 + @她」那种触发 |
| 发图时带一句话 | 空 | 比如填「画好了」，会先发文字再发图 |
| 画不出来时说一声 | 开 | 关掉就安静跳过，不打扰 |
| 缓存多少张 | 60 | 同样的公式再来一次直接复用；0 = 不缓存 |
| 也给她一个渲染工具 | 开 | 她可以自己调 `latex_render` 画别人给的公式 |

## 原理

三层，全是手写的，没有任何原生依赖、不装 TeX、不联网：

1. **排版** —— `mathjax-full` 3.2.2 把 TeX 排成 SVG。用的是它自己的 `liteAdaptor`，不碰浏览器。1000 个 SVG 单位 = 1em，所以字号可以直接换算成像素。
2. **光栅化** —— `lib/raster.mjs`：自己解 SVG，把每个 `<path>` 的贝塞尔曲线拆成折线，用**非零环绕**规则逐扫描线填充，每像素纵向 4 个子采样做抗锯齿；`<use>` 引用字形、`translate/scale` 变换、`<rect>`（分数线）、`<line>`（`\cancel` 的斜杠）都自己处理。
3. **编码** —— `lib/png.mjs`：自己写 IHDR/IDAT/IEND，RGBA 真彩色，`zlib.deflateSync` 压一下。一张常见公式 2~6 KB。

`capabilities` 是空的：不发请求、不读写文件、不调子进程、不用动态代码。

## 手打的符号也认

不用非得写 LaTeX。发 `/公式 x²+1`、`/公式 √2`、`/公式 α+β` 都行，模块会先转成 LaTeX 再排：

| 你打的 | 转成 |
| --- | --- |
| `x²` `x²³` `e⁻ˣ` | `x^{2}` `x^{23}` `e^{-x}` |
| `a₀` `H₂O` `∫₀¹` | `a_{0}` `H_{2}O` `\int_{0}^{1}` |
| `√2` `√(x+1)` `√\pi` | `\sqrt{2}` `\sqrt{x+1}` `\sqrt{\pi}` |
| `α β γ … Ω` | `\alpha` `\beta` … `\Omega` |
| `× ÷ ± ≠ ≤ ≥ ≈ ∞ ∑ ∫ ∂ ∇` | `\times` `\div` `\pm` `\neq` `\leq` `\geq` `\approx` `\infty` `\sum` `\int` `\partial` `\nabla` |
| `→ ⇒ ⇔ ∈ ⊂ ∪ ∩ ∀ ∃` | 对应的命令 |
| `°` `′` `½` `ℝ` | `^\circ` `'` `\frac{1}{2}` `\mathbb{R}` |

转换只动公式那一段，聊天正文一个字不改。已经是 LaTeX 的（`\frac{1}{2}`）原样保留，不会二次转义。

## 支持到什么程度

能画：分式、根号、求和求和积分（含多重、上下限）、矩阵/行列式/分段、希腊字母、箭头（`\overrightarrow`、`\xrightarrow`）、`\overline`、`\underline`、`\cancel`、`\color`、`\left(\right)` 自动伸缩、`\text{}` 里的英文、以及 `\ce{H2O}` 这种化学式（mathjax 的 mhchem 包）。

画不出来：

- `\text{中文}` —— MathJax 不自带中文字形。带中文的整句本来也不会被当成公式。
- `\includegraphics`、`\usepackage` 这类要外部文件的，本来就不是公式。
- 需要 LaTeX 宏包的排版功能（`tikz`、`algorithm2e` 等），MathJax 不支持。

画不出来时会说一句「公式没画出来：原因」，原因来自 MathJax 自己的报错（比如 `Missing close brace`）。

## 性能实测

在这台机器上（Node 22，MathJax 已经热过）：

| 内容 | 尺寸 | 渲染 | 文件 |
| --- | --- | --- | --- |
| 高斯积分 | 332×110 | 12ms | 5.5 KB |
| 分式 + 根号 | 341×99 | 6~14ms | 3 KB |
| 三条公式拼一张 | 320×314 | 约 20ms | 12 KB |

冷启动那次要额外几百毫秒加载 MathJax 字体，所以模块启动 5 秒后会自己**预热**一遍，之后每条都碰不到这个开销。日志里能看到 `MathJax 预热好了`。

## 常见问题

**@ 了她没反应？** 看她有没有被 @ 到（群里必须真 @），消息里有没有公式或触发词；再看面板日志有没有 `画了 N 张`。真没画的话，多半是这条被判定成「不是公式」，交给正常聊天了。

**图太小 / 太大？** 调字号。40 大约是一行字的高度，60 用于手机上看更清楚。

**深色主题里白底扎眼？** 配色换成「深色底浅字」，或者「透明底」（透明底会跟气泡背景融在一起，浅色气泡里看不出边界）。

**一条消息里好几条公式，想省图？** 多条公式设成「竖着拼成一张」。

**她说「QQ 这边不认 LaTeX 渲染」？** 那是没有这个模块（或者模块没启动）时的正常回答，装上、启动了就不会再这么说。

## 开发

```sh
npm install      # mathjax-full 3.2.2（纯 JS，跨平台）
npm test         # 解析、光栅化、PNG 的单元测试
npm run build    # esbuild 打包成 .build/index.mjs（提模块市场用）
```

`lib/` 里没有模块 API，全是纯函数，`test/` 直接 import 就能测。改完文件存一下，插件几秒内自动重载。
