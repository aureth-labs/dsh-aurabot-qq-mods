# 私聊收件箱（file-inbox）

修复「私聊发文件，插件只收到 `[文件 xxx]` 占位预览、内容拿不到」的问题：
私聊收到的文件会被**真的下载落盘**到收件箱，她（AI）能自己查、读、用、回发。

## 做什么

- 监听私聊消息，从原始 OneBot 事件里抽出 file 段，自动下载存进收件箱（`modules-data/file-inbox/inbox/`，最多留 50 份，旧的自动清理）。
- 下载地址三级兜底：消息段自带 `url` → `get_private_file_url` → `get_file`（网关在本机时直接复制本地路径）。
- 收下后回一条确认（可关），**不接管消息**——占位消息照常交给她，她知道有文件来了。

## 怎么用

- 私聊发文件即可；面板「私聊收件箱」页可设置：收谁的文件（默认只收主人私聊）、主人 QQ、单文件上限（默认 500MB）、后缀白名单、ffmpeg 路径（选填）。
- 她的两个工具（**只在主人私聊里可用**，群聊和别人私聊不出现）：
  - `inbox_files`：查清单；指定编号可「读」内容——文本读全文、zip 报完整清单（条目名+大小+是否加密）、docx/pptx/xlsx 无依赖抽正文（PDF 暂只给路径）、音频经 ffmpeg 转码后走本机 ASR 转成文字、图片/视频给路径并引导发回。
  - `inbox_send`：把收件箱里的文件发回当前聊天——图片当图发、音频当语音发、视频当视频发、压缩包/文档走私聊文件上传。
- 面板接口：`/aurabot/api/ext/file-inbox/inbox` 看清单，`/inbox/file?id=…` 预览/下载。

## 会访问哪些网址

- 只访问收到的文件自身的下载地址（QQ 网关 / 腾讯文件服务器下发的 URL），不访问任何其他地址。
- 音频转文字需要本机 ffmpeg（自动找 PATH 和 `~\.grabit\bin` 等常见位置，也可在面板手填）与插件「本地能力」里开启的 ASR；没有就如实告知读不了，不联网转写。

## 数据与隐私

- 文件只落在本机 `api.dataDir('inbox')`；收件箱工具带隐私闸门，只在主人私聊里可用，清单不显示对方 QQ 号，绝不把收到的文件带进群聊。
- 面板设置里的「主人 QQ」留空时，自动按插件配置的 `ownerQQ`/`botQQ` 认人。
