# 空闲画画

闲着没事的时候，自己把本机 ComfyUI 拉起来画一张图，画完自己检查一遍，过了才发。

## 流程

```
每 3 分钟看一眼
  ↓
没人说话满 40 分钟？在活跃时段？今天还没超额度？两次之间隔够了？
  ↓ 是
ComfyUI 没开就自己拉起来（要 1~3 分钟加载）
  ↓
出图 → 自己看一眼有没有崩坏
  ↓ 不过关就换种子重画（默认 1 次）
发主人 + 分享到白名单群
  ↓
把 ComfyUI 关掉，显存还回去（可关）
```

## 自检怎么判

用能看图的模型挑**硬伤**，只拦这些：

- 多余的肢体（三只手、多一条腿、多一只脚）
- 肢体畸形（六根完整手指、断肢、肢体长在一起）
- 严重穿模（整只手臂穿进身体、人头和躯干错位）
- 明显的水印或签名残留

**不管**：手部细节模糊、关节不清楚、米饭质感、背景小物件不规整、画风、配色、构图、好不好看。
（这些是 AI 生图常态，管了几乎每张都过不了，白画一堆）

## 工作流

工作流是**内联拼的**（不依赖保存的工作流文件），所以换模型/LoRA 只改面板上的字段就行。

**Krea-2 Turbo**（默认）：`krea2_turbo_int8_convrot` + `qwen3vl` CLIP（type=krea2）+ 多 LoRA 链 + cfg 1 / euler / simple，8 步。

**Anima**：`anima-aesthetic-v1.1` + `qwen_3_06b_base` + 28 步 / cfg 4。

> LoRA 名字会自动对齐 ComfyUI 的清单（Windows 上它要反斜杠 `Krea2\xxx`），你写 `/`、`\` 或裸名都行。

## 会访问哪里

- **联网**：只连本机 ComfyUI（默认 `http://127.0.0.1:8188`）
- **启动程序**：ComfyUI 没开时 `spawn` 你配置的 python + main.py；画完 `taskkill` 关掉
- **读写文件**：图片存在 `modules-data/idle-paint/paint/`，`state.json` 记额度
- **发消息**：主人私聊 + 白名单群

## 怎么用

- QQ 命令：`/画一张`（后面可以跟描述）
- 工具：`idle_paint_now`
- 接口：`/ext/idle-paint/{state,now,last,check}`
- 面板：「现在就画一张」、最近作品缩略图、各种参数

## 注意

ComfyUI 的路径要自己填（`pythonPath` / `mainPath`），默认是 aki 整合包的位置。填错了会在面板上报出来。
