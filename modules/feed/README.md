# 喂食（feed）

让她像有身体一样会饿、会馋、会自己找零食，也会在你喂她的时候回一句话。

不是一张「饥饿值进度条」，是把她一天里的胃口做成一条会动的曲线：起床时饿、饭后饱、干活聊得越久越饿，饭点没吃会掉下去。

## 做什么

- **按作息饿**：一天 24 小时的胃口曲线（早/午/晚三餐 + 活动量），饥饿值 0~100，越高越饿。
- **饭点**：默认 06:30 / 11:20 / 17:30，可自己改；到点没吃会额外加饿。
- **投喂**：说「喂你吃豆腐脑」「给你点了奶茶」或私聊发 `/喂食 豆腐脑 咸 一份`，她会吃掉、饱起来，并回你一句。
- **口味**：每种食物按口味（咸/甜/辣/鲜…）有偏好值，合口味的吃得更多；她爱吃的东西单独一份清单。
- **馋**：聊天里提到吃的，她会记下「现在想吃」；面板上能看到。
- **自己找零食**：饿到一定程度、又隔了一阵没吃，她会自己翻零食吃，并私聊告诉你。
- **主动喊饿**：饿得厉害又很久没吃，她会主动来找你。
- **好感度**：你喂她一次 +1（只统计主人投喂），面板上能看到。
- **记忆**：每次吃都会写进记忆模块，下次聊天她记得自己吃过什么。

## 面板

模块装在「人格」标签页底部，宽度约 420px，15 秒自动刷新：

1. **此刻的她**：大号饥饿值、状态（刚吃饱/不太饿/还行/有点饿/很饿/饿扁了）、饱食条、下一顿倒计时、今天被喂了几次/自己吃了几次。
2. **今天的胃口**：24 小时目标曲线、饭点虚线、此刻的圆点，以及早/午/晚三格（吃了什么、当时饱食多少）。
3. **喂她**：她现在馋的、她爱吃的、手填食物、口味、四档分量（一小口/半份/一份/管饱）、吃之前先看「现在 19 → 0（饱食 +19）」的预览；喂完她会说一句话。
4. **最近吃过**：时间、来源（投喂/自己吃）、食物、分量、实际涨了多少、吃前→吃后。
5. **她的味蕾**：口味偏好列表，0 讨厌、1 最爱。

面板颜色只用中性灰和继承色，浅色/深色主题都能看。

## 设置

在模块设置里改，改完不用重启：

| 设置 | 说明 |
| --- | --- |
| 食物清单 | 每行 `食物:口味1,口味2`，她认识的食物 |
| 她爱吃的 | 每行 `食物:偏爱口味` |
| 味蕾偏好 | 每行 `食物:口味=0~1`，0 讨厌、1 最爱 |
| 饭点 | `06:30, 11:20, 17:30` |
| 干活/聊天让她更饿的权重 | 聊天和干活对饥饿的加成 |
| 多久没聊会想吃零食（小时） | 闲下来的阈值 |
| 允许投喂 | 关掉后只能她自己吃 |
| 饭后加饿 / 自己找零食 / 主动喊饿 | 开关 |
| 零食阈值 / 喊饿阈值 | 饥饿到多少触发 |

## 她要访问什么

- **文件**：只读写自己的数据目录 `modules-data/feed/state.json`（当前饥饿、馋、吃过什么、好感度、口味）。
- **插件配置**：读写本模块自己的设置（`config.ext.feed`），不碰别的模块的配置，也不读账号 Cookie。
- **内部对象**：用 `api.core.hub.turnSendersAllOwner()` 判断「这次说话的是不是主人」，用 `api.core.http.body` 读请求体——插件升级后这两个位置可能变。
- **联网**：没有。不下载、不上传，所有判断都在本机。
- **依赖**：`mood`（投喂会推心情）和 `memory`（吃饭写记忆），都是插件内置模块。

## 命令

- `/喂食`：看她现在饿不饿、馋什么、好感度多少。
- `/喂食 豆腐脑 咸 一份`：直接喂。
- 也可以直接跟她说话：「喂你吃小蛋糕」「给你点了奶茶」。

## 安装

模块市场里点安装，或在面板里选「从文件安装」。装完在人格页底部出现面板，第一次加载会自动生成默认设置。

## 兼容

- 插件 1.2.0 及以上，扩展接口 `api: 1`。
- 只用了 `node:fs` / `node:path` 和插件公开的模块 API，没有原生依赖、没有构建步骤。
