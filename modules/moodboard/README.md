# 心情看板（moodboard）

桌面固定小窗，只读展示「大肥鱼」的内心状态，三块内容：

1. **心情**（心情模块）：当前心情值 / 标签 / 原因，以及最近 12 条心情起伏历史（什么时候、因为什么、涨了多少）。
2. **目的引擎**：9 维驱力条（玩 / 学 / 装 / 陪 / 关心 / 分享 / 自我 / 创作 / 体验）与 10 种心情向量条（好奇 / 兴奋 / 寂寞……），附上次主动行为摘要与下次可能主动的时间。
3. **记忆**：按人 / 群归类的相处经验，以及说话方式。

## 怎么用

1. 装好模块后，打开插件面板 → 最顶上的**「概览」页**，往下一点就是「心情看板」卡片 → 点**「打开看板窗口」**。（面板对独立模块页的分组是白名单 + 正则兜底，会被埋进「系统」组末尾，所以挂在概览页最显眼。）
2. 模块会用**系统默认浏览器**开出一个看板窗口，大小随意拉、页面自适应；数据默认每 5 秒自动刷新（可在设置里改）。

## 数据来源

只读调用插件内置模块的导出接口，不联网、不写文件、不发消息：

- `mood.state()`：心情值与起伏历史
- `purpose.state()`：驱力向量（drives）、心情向量（moods）、上次情绪与主动摘要
- `memory.insights()` / `memory.styles()`：相处经验与说话方式

对应模块关着时，看板里那块显示「没在跑」，不影响其他块。

## 接口

- `GET /aurabot/api/ext/moodboard/state` — 三块数据的聚合 JSON（含中文标签）
- `GET /aurabot/api/ext/moodboard/board` — 看板页面（HTML）

## 隐私与安全

- 页面与数据接口只允许本机访问（走插件的管理面闸）；页面渲染全部用 `textContent`，不拼 HTML。
- 只访问本机插件自己的接口（页面轮询）；`capabilities` 里的 `network` 即为此项，`plugin-internals` 是用 `api.core.http` 自回 HTML 页面。
