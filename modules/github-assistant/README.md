# GitHub 助手 · AuraBot 模块

私聊替你盯 GitHub：CI 失败、等你审的 PR、有人 @ 你，攒成一条提醒发过来；群里发 `#项目` 看仓库近况，显示多少由你决定。

## 做什么

### 私聊提醒（只发给主人）

每 `检查间隔` 分钟看一次你在设置里填的仓库：

- **CI 失败**：默认分支上最近完成的 workflow，结论是失败 / 超时 / 启动失败时提醒，带运行链接。
- **等你审**：开放 PR 里点名 `requested_reviewers` 有你的，提醒一次。
- **@ 你**：开放 issue / PR 里出现 `@你的用户名`，提醒一次。

同一条只会提醒一次（按 run id / PR id / issue id 去重，状态存在模块数据目录）。
第一次巡检只记录现状不提醒，免得一装上去就被历史消息刷屏。

### 群聊查状态

在配置里填「群里能查的仓库」（可写 `别名=owner/repo`），群里发：

```text
#项目            # 只有一个仓库时直接查；多个时列出可查的别名
#项目 aurabot    # 查别名对应的仓库
#项目 owner/repo # 也可以直接写全名
```

支持 `#项目`、`/项目`、`/repo`、`#gh` 等写法，只认白名单群；同一个群有冷却时间，避免刷屏。

### 显示细项

设置里的「群状态详细程度」三档：

| 档位 | 内容 |
|---|---|
| `brief` | 仓库名、描述、默认分支最新 CI 结论、更新时间 |
| `normal` | 再加最新提交（sha、标题、作者、时间）、开放 PR / Issue 数、Star |
| `detail` | 再加最近 3 条待合并 PR、最近 3 次 CI、最新 Release 版本 |

## 设置

| 项 | 说明 |
|---|---|
| GitHub Token | 只看公开仓库可以留空；私有仓库要填。填完重载模块，会自动移到数据目录并清空这一栏。建议用 fine-grained token，只给 `Contents: Read`，不要管理权限 |
| 私聊盯的仓库 | 每行一个 `owner/repo`，最多 10 个 |
| 群里能查的仓库 | 每行一个，可写 `别名=owner/repo`。留空 = 群里不让查 |
| 检查间隔 | 1~60 分钟，改完要重载模块 |
| CI 失败 / PR 待审 / @ 提醒 | 三个独立开关 |
| 免打扰 | 两个整点；开始和结束相同 = 不启用。免打扰期间不巡检，恢复后照常 |
| 群查询冷却 | 秒，默认 15 |

## 权限与隐私

- 「主人」只认 Aurabot 配置里的 `ownerQQ`，用 `api.isOwner` 判断；提醒只发到 `private:主人QQ`。
- 群里只查「群里能查的仓库」这一份清单，和私聊的清单分开，避免把私有仓库带到群里。
- **Token 不留在配置里**：读取顺序是环境变量 `GITHUB_TOKEN` → 数据目录的 `token` 文件；设置页里的密码框只当一次性入口，模块加载时会写到 `token` 文件（POSIX 上 `chmod 600`）并清空那一栏。日志和消息里都不会输出它。
- 这是**隔离**而不是加密：文件本身仍是明文，只是不再随 `config.json` 出现在面板、备份或同步里。需要更强保护就只用环境变量，并给它最小权限（fine-grained、只读）。
- 只访问 `api.github.com`，不发往别的域名；不读聊天记录，不写 GitHub（全部是 GET）。

## 能力声明

- `network`：访问 GitHub REST API。
- `filesystem`：在模块数据目录写 `state.json`（已提醒过的 id）和 `token` 文件。
- `plugin-config`：只读 Aurabot 配置里的 `ownerQQ`、群白名单和 `dryRun`，不写；同时读写本模块自己的设置。

## 安装

模块市场安装，或把整个 `github-assistant/` 文件夹放进：

```text
~/.dsh/plugins-data/aurabot/modules/github-assistant/
```

保存后几秒内自动加载。

## 文件

- `index.mjs`：入口，巡检与 `#项目`
- `module.json`：模块信息
- `test/index.test.mjs`：本地测试（不进发布包）
