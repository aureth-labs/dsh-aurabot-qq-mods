# 补回错过的@

电脑不会 24 小时开机，她也不可能一直在线。这个模块负责**把断线期间没人接的 @ 补上**。

## 什么时候补

- 开机 / DSH 重启后 20 秒
- QQ 网关一重连，等 8 秒
- 每 30 分钟兜底看一眼

## 怎么算「漏掉的」

同时满足四条：

1. 消息里有 @ 机器人号
2. 那条之后她没说过话（回过的不算）
3. 已经过了至少 8 分钟（太新的可能在回，不抢）
4. 不超过 24 小时（更老的就不翻出来了，免得尴尬）

## 怎么补

不逐条复读（那样很吵），而是攒着补一句：

```
（刚看到——2 小时前 @ 我了，之前电脑没开，补一句）
云信晚来秋：你是虎鲸吗
这个我刚补上，还接着说吗
```

一次最多补 3 处，群与群之间隔 2 秒，绝不刷屏。

## 怎么配置

| 项 | 默认 | 说明 |
|---|---|---|
| 只在哪些群补 | 白名单全部 | 一行一个群号 |
| 只补多久以内的 | 24 小时 | |
| 至少隔多久才算错过 | 8 分钟 | |
| 每个群往回拉多少条 | 80 | |
| 一次最多补几处 | 3 | |
| 补之前先说一句 | 开 | |

## 会访问哪里

- **通过 QQ 网关调 OneBot 接口**：`get_group_msg_history`（拉群历史消息）
- 发消息走插件正常的 `api.send`
- 写自己数据目录的 `state.json`（记已处理的消息 id，防重复补）

## 怎么用

- 面板里有个 **「只检查不发」** 按钮：只列出来给你看，一个字都不发 —— 想先过一眼用这个
- QQ 命令：`/补` 立刻检查并补
- 接口：`/ext/mentions-catchup/{state,scan,now}`

## 注意

只在白名单里的群工作。不是白名单的群，就算有人 @ 也不会去翻。
