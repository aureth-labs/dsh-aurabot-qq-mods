# 群管

主人（和群管白名单里的人）要求时管群：禁言、解禁、踢人、改头衔、发群公告、全体禁言 / 关闭全体禁言（`qq_group_admin`），并让她知道自己在每个群是什么身份。

## 1.1.0 新增

- **全体禁言**：`全体禁言` / `关闭全体禁言`，工具里对应 `wholeban` / `wholeoff`。
- **群管自己的白名单**：默认只有主人，面板里「群管白名单（额外）」可以加人，和 aurabot 的主白名单完全分开。
- **群里直接发指令**：白名单里的人不用等大肥鱼答应，直接在群里说一句就执行：

  ```
  全体禁言            关闭全体禁言
  禁言 群名片 10       解禁 群名片
  踢人 群名片          改头衔 群名片 内容
  发公告 内容
  添加白名单 @某人 / QQ号    移除白名单 @某人 / QQ号    查看白名单
  ```

  别人发的这些一概不触发。
- **`/群管功能`**：列出全部能用的一句话指令。

## 说明

- 只通过 OneBot 调用 QQ，不访问其他网络地址。
- 不认识的群、不在白名单里的群一律不动手；也永远不能对主人禁言或踢人。
- 原是 Aurabot 内置模块，1.2.0 起搬到社区模块库。老用户升级时，在用的会自动装回来，配置和登录状态不变。
