# SnowLuma 状态（sl-status）

群友发一句 `#sl`，机器人回一张「SnowLuma 状态」卡：

```
SnowLuma 状态
版本: 2.4.2
平台: MS-DOS
运行时长: 56秒
```

版本、平台、运行时长都按这个格式显示；**平台可以在设置页换任何文字**，触发词也能改。

纯本地回复：不连 SnowLuma、不联网、不读文件，也不调用模型。

## 用法

装好就生效，默认触发词是 `#sl`，要跟消息**完全一致**才算（`#sl 你好` 不会触发，避免误伤别的指令）。

## 配置

面板 → 这个模块的设置页：

| 设置项 | 说明 |
|---|---|
| 启用 | 关掉后触发词不再有反应 |
| 触发指令 | 默认 `#sl`。多个用空格或逗号隔开，比如 `#sl, #状态`；改完直接群里发新词即可 |
| 版本号 | 第二行「版本:」后面的内容，默认 `2.4.2` |
| 平台 | 预设 MS-DOS / Windows 98 / Windows XP / Windows 7 / Linux / Android / macOS，最后一个「自定义」 |
| 自定义平台文字 | 「平台」选自定义时显示这行；留空按 MS-DOS 显示 |

**在哪里改 `#sl`**：就是上面这个「触发指令」一栏。它管的是**本模块**什么时候回状态卡；不需要重装，改完立刻生效。

运行时长取的是插件进程启动至今的时间，和「机器人跑了多久」对得上。

## 和 SnowLuma 自己的 `#sl` 的关系

本模块和 SnowLuma 没有任何连接，回的是本地拼出来的一张卡，所以：

- SnowLuma 没开、没连上，本模块照样能回
- 你在 SnowLuma 那边改什么，不会影响这里；反过来也一样
- 如果群里同时有 SnowLuma 自己的 `#sl` 状态，会出现两条回复，想避开发挥可以把触发词改成 `#状态` 之类

SnowLuma 本身是 OneBot 网关，`#sl` 这类状态卡通常由接在它上面的机器人 / 插件发出。要改 SnowLuma 那条，得去对应机器人的指令配置里改，不在本模块的设置页里；SnowLuma 的配置入口在它的 WebUI（默认 `http://localhost:5099`），不同版本页面叫法不一样。

## 和「自动接待」的 `#sl` 不冲突

「自动接待」模块的 `#sl 内容` 是让机器人私聊，需要带内容；本模块只认**单独一条** `#sl`。两个都装时，单独 `#sl` 回状态卡，`#sl 你好` 走自动接待。

## 不联网、不写文件

能力清单为空：不发请求、不读本机文件、不往磁盘写东西。设置由插件自己保存。
