# 自动接待 · AuraBot 模块

自动通过好友申请和群邀请，并把通过的人 / 群写进 Aurabot 白名单；`#sl` 只有主人能触发。

**装好之后默认什么都不做**：所有自动通过开关、写白名单开关都是关的，`#sl` 也不响应。需要你在设置页里逐项打开，才会开始接待。

## 做什么

- **好友申请**：收到好友申请后用 `set_friend_add_request` 通过；可另外打开「写入白名单」把对方 QQ 加进 `allow.private`。
- **群邀请**：别人邀请机器人进群时用 `set_group_add_request` 通过；可把群号加进 `allow.groups`。
- **加群申请**：机器人在群里当管理员、有人申请进群时通过。这是独立开关、**默认关**——打开等于替群主自动放人。
- **`#sl` 私聊**：只有主人能用。没通过的人发 `#sl` 只会收到「只有主人能触发」的拒绝。

## 用法

在 QQ 里由主人发送：

```text
#sl                 # 让机器人私聊主人自己
#sl 你好            # 把「你好」私聊发给主人自己
#sl 123456789 你好  # 把「你好」私聊发给白名单里的 QQ 123456789
```

- 目标必须是主人自己或私聊白名单里的 QQ；否则不会发送。
- 机器人在试运行时只写日志，不会真的通过申请或发私聊。
- 没写内容时按设置里填的默认句发送，默认是「在的，找你。」。

## 设置

面板「已安装」里点本模块的设置页：

| 项 | 默认 | 说明 |
|---|---|---|
| 启用 | **关** | 总开关；关着时申请和 `#sl` 都不响应 |
| 自动通过好友申请 | **关** | 打开后任何好友申请都会被通过 |
| 自动通过邀请机器人的群 | **关** | 只处理邀请机器人本身的群邀请 |
| 自动通过别人的加群申请 | **关** | 机器人在群里当管理员时，会替群主放行任何申请进群的人，风险较高 |
| 群邀请只认邀请机器人 | 开 | 关掉后，别人被邀请的群也一并同意 |
| 通过后写入白名单 | **关** | 打开后会把通过的 QQ / 群写进 `allow.private` / `allow.groups` |
| `#sl` 不带内容时发什么 | 在的，找你。 | 留空则用默认这句 |

建议的打开顺序：先开「启用」和「#sl 私聊」，确认主人能用；需要接待时再逐个打开好友、群邀请；「别人的加群申请」和「写入白名单」最后按需开。

## 权限

- 「主人」只认 Aurabot 配置里的 `ownerQQ`，用 `api.isOwner(msg.userId)` 判断；不会相信消息里的自称，也不会因为对方在白名单里就当成主人。
- `#sl` 的目标会再核对一次私聊白名单，避免替陌生人发起私聊。
- 自动通过申请不受白名单限制（申请通过前对方还不在白名单里）。
- 写入白名单是独立开关：不开就只通过申请，不扩大她的搭理范围。

## 安装

模块市场安装，或把整个 `auto-contact/` 文件夹放进：

```text
~/.dsh/plugins-data/aurabot/modules/auto-contact/
```

保存后几秒内自动加载，不需要重启。

## 网络与隐私

- 不访问任何外部网站，没有 `fetch`、WebSocket 或第三方接口。
- 只通过本机 OneBot（SnowLuma）网关调用 `set_friend_add_request`、`set_group_add_request` 两个动作。
- 只修改 Aurabot 自己的配置 `allow.private` / `allow.groups`；不会读取或外传账号 Cookie、聊天记录。

## 注意

- 自动同意意味着任何加好友 / 邀请进群的人都可能进入白名单，之后机器人会正常搭理他们。不想要这个行为时请关闭或卸载本模块。
- 加群申请通过需要机器人在该群有管理权限；没有权限时会失败，并在 Aurabot 日志里留下警告。
- 模块自带的 Aurabot「好友申请与白名单」仍会给主人发申请提醒；申请已经被本模块自动通过时，忽略那条提醒即可。
