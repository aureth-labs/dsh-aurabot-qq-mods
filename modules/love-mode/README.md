# 快来跟我恋爱吧（love-mode）

教你的 AI 伙伴怎么爱你：选择一种关系模式，她的相处风格、主动程度、聊天技巧会整体切换。这不是给你出主意的军师——是她自己学会怎么和你相处。

## 功能一览

### 关系模式

- **六种预设模式**：单身约会 / 长期伴侣 / 婚姻 / 异地 / 再婚 / 跨文化关系。每种模式有独立的性格基调文案、默认滑块（幽默/主动/走心）和技能组合，一键整体切换相处风格
- **无限自定义模式**：自己起名、自己写基调文案（比如「暧昧模式：话里有话，彼此试探」），自建模式带独立的三个滑块，和预设模式一样可以增删改、随时切换
- 切换预设模式时自动套用该模式的默认滑块；自定义模式的滑块跟随模式本身保存

### 军师链（每轮私聊的幕后分析）

每收到一条私聊消息，先跑一轮幕后分析再回复：

1. 读取最近 12 条对话 + 当前模式 + 双方画像
2. 模型分析：他的真实意图、他的情绪、2-3 个候选回复策略（各自附理由）
3. 选出最优策略，按需选一份知识库参考
4. 把「回复思路」注入她的上下文（她自己消化，不会说出分析过程）

- 军师链失败（超时/模型异常）自动降级为关键词匹配路径，聊天不受影响
- 30 秒缓存去重，同一轮不重复分析

### 知识库参考

内置 4 份精选参考文档（接话延伸 / 情绪价值 / 话术编排 / 关系推进校准），由军师链按对话内容**按需选用**，不是每轮硬塞。降级路径下按关键词命中，闲聊兜底用「接话延伸」。

### 双方画像

- 她和你的 MBTI、优势、短板，由 AI 自动生成：读人格卡 + 记忆库双路召回（通用关系词 + 定向「关于他」的条目）+ 最近 30 条私聊实录
- 首次启动 30 秒后自动匹配一次；面板按钮可随时重跑
- 所有字段都可手动微调；MBTI 下拉选中带 16 型一句话简介

### 时间感知

每轮聊天注入当前时间锚点：几月几日周几几点、她这个时段大概在干嘛（按她的作息表：上课/午饭/晚自习/深夜），并要求说话符合时段——不会下午三点说「刚吃完午饭」。

### 面板

- 简单/高级双层：简单页只选模式；高级页展开滑块、基调文案、双画像、关系声明（性别与关系性质，文案保持性别中立）
- 悬浮保存条：改动未生效时底部浮出「确认生效/撤销」，不会忘了保存
- 军师链日志：每轮的意图/情绪/候选策略/选择理由/查了哪份知识库/耗时，最近 50 条可回看；「看最近一次完整注入」能直接看到她这轮到底收到了什么
- 右栏实时显示当前模式的完整基调和默认参数

### 输出保险丝

剥除模型偶发泄漏的杂质：HTML 标签、DSML 协议碎片、ACP 元数据标签、代理错误行；整条都是碎片时拦下不发（并记日志）。不影响 `<voice>` `<sticker>` 等正常占位符。

### 联动

- 导出 `proactivityMultiplier()`：「主动程度」滑块影响她主动找你的频率（关系阶段类模块可消费）
- 与主动搭话（speakup）、记忆（memory）、日记等内置模块自然配合

## 配置

面板「扩展」→「快来跟我恋爱吧」：

1. 点「自动匹配」让她自己判断你们处在哪个模式（或手动选，或＋新建自己的模式）
2. 高级里可微调：幽默/主动/走心滑块、基调文案、双方画像、你的性别与关系性质声明
3. 底部日志区随时回看每一轮的军师分析和知识库使用

## 会访问哪里

- 读取：人格卡 `personas/dafeiyu.md`（前 2000 字，用于自动匹配）、记忆库（只读召回）、当天 `chatlog`（最近对话，用于军师链和画像）
- 写入：本模块设置（`config.json` 的 `ext.love-mode`）、`modules-data/love-mode/state.json`（匹配记录 + 军师链日志）
- 不联网（军师链和自动匹配走插件自身的模型通道）、不执行外部程序、不读取账号 Cookie、不向主人以外的任何人发消息
