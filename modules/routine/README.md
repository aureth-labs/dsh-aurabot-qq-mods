# 作息 · routine

她一天里的骨架：上班/上学、通勤、在家休息、请假调休，由这张作息表判定。**只有「在家休息」的时段才让过日子（livin）醒来**——上班时间她不会自己找乐子，到家了才过自己的日子。

## 她自己拿主意（v1.2.1）

作息表只回答「她现在在哪」，但这个模块现在还顺手管一件事：**在处境里她自己怎么安排**。

- **上班：干活还是摸鱼**。每 `planIntervalMin`（默认 30）分钟做一次决定。心情差、压力大更容易摸鱼；手上有活卡着点就不敢摸；午饭后和收工前最容易走神。摸鱼有概率被看见（老师/医生/护士/餐饮/保安/工厂/骑手这类管得严的职业概率更高），被抓心情 -6，没被抓心情 +2。
- **放假：出门还是在家**。心情好、白天更愿意出门；心情差、压力大、太早太晚更想窝着。出门会随机一个去处（24 个：商场/公园/咖啡馆/电影/超市/书店/河边/美术馆/花市/猫咖/游泳馆/夜市…），时长 1–3.5 小时；**出门期间把过日子关掉**（在外面没法刷抖音），回来再开回来，心情 +3。
- **上班的活**。按职业随机生成（`taskOn`，默认每天 2 条），有过期时间（默认 3 小时，按班段剩余时间收缩）。干一次活推进 25%–45%，两三次能做完；**到期没做完会被主管说一顿**（称呼按职业：护士长/主任/店长/班长/班主任），心情 -8，并写进长期记忆。
  - 每个职业 16 条活（合计 176 条）、摸鱼 20 种：**同一天抽到的几条活不会撞，摸鱼和去处也会避开最近 6 次**，池子用尽才允许重样，不会连着几天说同一句。
- **行动日志**：每个决定都记一条（时间 + 类型 + 一句人话），面板最下方「她今天自己做了什么」里能看到，也带进度条和剩余时间。
- **主动说一声**：决定完按 `planShareChance`（默认 25%）发到主人私聊，两次之间至少隔 45 分钟，避免刷屏。说的话是第一人称短句（「「把接口文档补完」终于弄完了」）。
- **进记忆**：做完活、拖过期、出门、回家这几个关键时刻走 `memory.addEvent`，以后聊天能想起来。

原理上这是**权重驱动**而不是每次问模型：决定依据心情值、压力、任务紧迫度、时段和职业，全部可在测试里复现；不发请求，不额外消耗 token。想说归她说的部分（内容生成）才用模板池。

## 职业（v1.1.1）

十一种常见职业/学生，每种一套贴近现实的周班表，面板下拉或 QQ 发 `/作息 职业` 切换：

| 职业 | 班表 | 特点 |
|---|---|---|
| 行政文员 | 周一到五 9:00–18:00 | 默认，朝九晚五双休 |
| 程序员 | 周一到五 10:00–19:00 | 弹性打卡 |
| 中小学教师 | 周一到五 7:30–17:30 | 盯早读到放学 |
| 门诊医生 | 周一到五 上午门诊+下午门诊，周六半天 | **周三连值夜班到次日 8 点，周四补休** |
| 护士 | 三班倒按周轮：白班 8–16 / 小夜 16–24 / 大夜 0–8 | 大夜周凌晨 3 点在班上（压过睡觉时段），早上下班补觉 |
| 餐饮服务员 | 午市 10–14 + 晚市 16:30–21，**周二轮休** | 两班之间回家歇一会儿（班间休息，livin 开） |
| 门店销售 | 周一到五 9–18，**隔周周六上班**；卖什么随机（手机/房子/汽车/保险/化妆品/家电/家具/网课），当天稳定 | 注入里她会说「在卖 X」 |
| 外卖骑手 | 午高峰 10–14 + 晚高峰 16:30–20:30，周二休 | 周末照跑 |
| 小区保安 | 三班倒做六休一：早 7–15 / 中 15–23 / 夜 23–7 | 夜班跨午夜，次日清晨算前一天的班 |
| 工厂普工 | 两班倒：白 8–20 / 夜 20–8 按周轮，周日休 | 夜班周凌晨算上班 |
| 高中生 | 周一到五 早读 7:30–12:00 + 下午课 14:00–17:30 + 晚自习 19:00–21:30，周六上午补课，周日休 | **校园用语**：上课中/放学到家/课间休息/临时补课；寒暑假还没排（先在面板手动改班表） |

机制：

- **轮班**按「周序号」轮（锚点 2024-01-01 周一）：每到新的一周，tick 自动把轮班职业的下一套班写进底座班表
- **跨午夜夜班**：结束时间 < 开始时间（如 `23:00-07:00`），凌晨那几小时判定为上班而不是睡觉；前一天的夜班延续到次日也会被认出来
- **手动班表优先**：在面板里改过班表后（`weekSource=custom`）职业轮换暂停，直到再切一次职业（重排会覆盖手动班表）
- **职业用语**：所有处境描述默认是上班语境（上班中/下班到家/班间休息/临时加班/调休），学生这类非上班职业用 `w` 字段覆盖成校园语境（上课中/放学到家/课间休息/临时补课/临时调课）
- 切职业后托管开着的话会立刻对一次表，livin 跟着新处境走

## 它管什么

- **状态机**：`睡觉 / 通勤 / 上班中 / 在家`，每 5 分钟对一次表，状态切换沿才动作
- **三层日程**（上层覆盖下层）：
  1. `overrides`：请假日（压力攒满自动挂，或面板手动加）
  2. `disturb`：每周日自动生成的下周扰动——临时加班（休息日变上班）、调休（上班日变休息），一周最多两条
  3. `self`：她自己用 `life_schedule` 工具记的日程（「周三要值班」「明天下午开会」）
  4. 底座：每周固定班表（面板里编辑，默认周一到五 9:00–18:00）
- **压力值**：工作日 +10、休息日 -15、请假 -25（可调），攒到阈值第二天自动请假，并顺手给心情记一笔（`nudge`，原因不含聊天内容）
- **注入【此刻·作息】**：≤100 字，只描述处境不下指令（「现在是上班时间…只能偶尔偷偷看下手机」），末尾固定带画图免责——别把「上班」画进画里
- **注入【今天·我做的】**：今天最后三条行动 + 现在是不是在外面 + 手头压着的活，上限很短，并注明「不用一条条汇报，聊到的时候自然提一句」
- **控制 livin**：只在状态沿拨 `ext.livin.enabled`，深合并只改这一个键；同一个状态内你在 livin 面板手动开关不会被抢回，到下一个状态沿才纠正。出门期间临时关掉、回来开回来

## 存储

- `modules-data/routine/schedule.json`：每周班表
- `modules-data/routine/routine.json`：压力值 + 自记日程 + 扰动 + 判定历史（7 天）+ `plan`（今天的活、出门、行动日志，日志留 3 天）

## 面板

「已安装 → 作息」：托管开关、当前处境、压力条、接下来的安排（可取消）、每周班表编辑、判定痕迹（每次翻日结账、状态切换、开关拨动都留痕），**最下方「她今天自己做了什么」**：在外的状态、手头的活（进度条 + 剩余时间）、行动日志（按类型上色，说过话的标「说了」），以及「自己拿主意 / 上班有具体的活 / 间隔 / 说一声」四个设置和「让她现在决定一次」按钮。
