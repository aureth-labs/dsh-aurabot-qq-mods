# 今日运势（fortune）

发「运势」抽一签。

## 怎么用

在私聊或群里发下面任意一个词：

```
运势
抽签
今日运势
求签
```

她会回一签，四种结果：大吉 / 中吉 / 小吉 / 末吉，每种配一句当天建议。

**每人每天一签** —— 同一天再发，会回你原来那一签，并提示「今天已经抽过啦」，不会刷出新的。

## 行为细节

- 签和提示语都是本地随机，不联网、不调模型。
- 抽签记录存在 `modules-data/fortune/draws.json`，按 `chatId|userId` 分开；超过 7 天的旧记录在下次抽签时自动清掉。
- 对主人用更亲切的说法（「抽到了「大吉」～」），对别人用中性说法（「今日签：大吉」）。
- 接了这条消息就不再交给主模型，省一次模型调用。

## 会访问什么

- **不联网**，没有任何外部请求。
- **只写本地文件**：`modules-data/fortune/draws.json`（模块自己的数据目录）。
