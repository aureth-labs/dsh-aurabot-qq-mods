# 衣柜

给角色一套能换的衣服，并且按穿搭生成她的画像。

## 一套衣服是什么

- **参考图**（可选）：一张衣服/整套穿搭的照片
- **描述**：一段文字，写清颜色、版型、材质、配饰
- **名字**（可选）

上传参考图时会自动调用看图模型写描述，也可以完全手写（不传图）。

## 用它做什么

1. 第一次跑会自动放一套默认女仆装；也可以在面板里继续加衣服。
2. 选一套「当前穿搭」。
3. 挑一个姿势（站姿 / 坐姿 / 回眸 / 托腮 / 比耶 / 对镜自拍），生成预览。
4. 生成过的图进「历史预览」，可以点开看大图、删除、打开文件夹。
5. 「基础外观描述」和「画风」就在生成预览里，改完点别处自动保存。

## 生图时怎么用参考图

| 生图服务 | 行为 |
|---|---|
| 支持参考图（OpenAI 兼容 / 自定义接口） | 用当前这套的参考图，失败自动退回文字 |
| 不支持参考图（Codex 订阅） | 直接用文字描述 |

所以有没有参考图都不影响出图，只影响像不像。

## 需要什么

- 插件内置的 **生图** 模块（`imagegen`）开着，并配好一个能出图的服务。
- 一张参考图想自动写描述的话，需要一个**能看图的模型**（设置里留空 = 用当前聊天模型）。

## 设置

| 项 | 说明 |
|---|---|
| 启用 | |
| 看图模型 | 留空 = 用当前聊天模型；也可以填 `provider/model` 强制指定 |
| 基础外观描述 | 在面板「生成预览」里，生图时拼在最前面 |
| 画风 | 同上 |

## 网络与文件

- 不额外联网，只调用内置生图模块和当前的模型服务。
- 数据写在 `modules-data/wardrobe/`：`wardrobe.json`、`images/`（参考图）、`preview/`（生成的图）。

## 注意

- 生成一张图会消耗你的生图额度（Codex 订阅按张计费）。
- 参考图和生成的图都存在本机，不会上传到别的服务，除了生图那一次请求本身。
