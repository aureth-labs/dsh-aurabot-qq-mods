# 家人代办（family-tasks）

在不改变私聊权限的情况下，把设置的家人 QQ 吩咐给大肥鱼的任务转交给主人私聊来做。主人点头后，做完向家人 QQ 反馈结果。

实现上：模块用插件的 `activity` 钩子接家人消息，判断是不是托付的活；能自己办的（读表格做统计）直接办了发回，办不了的叫醒主人。不用再挂 Python 看守脚本和计划任务。

## 装好先做

去面板「扩展」→ 家人代办，或在模块设置里填：

- **familyQQ**：一行一个家人 QQ。只有这些私聊的消息会被当成"家人托付"
- **ownerQQ**：主人 QQ，办不了的活用来叫醒你。主人自己的话不会当成待办
- **tablePath**（可选）：供统计的表格路径（xlsx）。填了才能自己办"算合计/最贵"这类活；不填就只会叫醒你
- **pythonPath**（可选）：留空自动从当前 Node 安装推导同环境下的 bundled python

## 判断活还是闲聊

纯本地规则，不调模型（模型走系统会话会冷却、会漏）。用真实家人消息校准过：

- 明显的活（帮我查、算合计、最贵、找一下…）直接认
- 明显的闲聊（嗯、好的、表情、陈述近况）直接丢，不写库
- 主人自己的话排除

宁可漏报也不误报——误报会乱叫醒主人，比漏报烦。

## 自己能办什么

需要开 `tablePath` 指向一份 xlsx，且运行环境有 openpyxl（DSH 自带的 bundled Python 有）。能办：最贵、最便宜、台数、合计、平均、中位数、哪家公司最多。办不了的（改文件、查错别字、模糊需求）叫醒主人。

## 兼容

正式版 1.2.0+ 与测试版 1.3.0-rc.1 都验证过接口一致（API_VERSION=1）。只用两版都有的接口，不用任何补丁。

东西全在自己机器上，不联网、不外传。
