# 拓竹打印机（bambu-print）

这是一个 QQ 机器人插件，用来在聊天里看拓竹（Bambu Lab）3D 打印机，也能做几个基本操作：暂停、继续、停止、开灯、调速、调温，还能要一张打印仓的照片。

它支持多人各用各的打印机：每个人的云端 token 或局域网访问码分开加密保存，默认谁也看不到别人的。想把打印机临时借给别人，用「授权」，按 QQ 限时共享，到期或撤销就收回。

它不切片、不上传模型、不发起打印，也不替你做 Bambu 账号的第三方授权登录（OAuth）。用 Google / Apple 等 OAuth 注册的账号，要先去 Bambu 手机 App 里设一个密码，才能在这里登录。

适用版本：1.1.1。

## 先说清楚几个词

- **绑定**：把一台打印机的访问权存进你的账号。一个云端账号算一条凭据，可以带多台打印机。
- **凭据**：云端 token（登录后拿到的通行证）或局域网访问码。拿到它就能控制打印机。
- **授权**：你把自己的打印机临时借给另一个 QQ。按 QQ 限时、可撤销，对方拿不到你的凭据。
- **主人**：机器人主人（owner），只有一个人，没有「管理员」这一级。
- **信封**：登录网页生成的那串 `BBX1.` 开头的加密文本，只能用一次。
- **抓帧桥**：`assets/tutk-bridge/` 下那个小 C 程序，云端画面靠它取一帧。

## 5 分钟上手

**第 1 步：打开总开关。** 打开机器人后台的「拓竹」面板（在「平台」分组里），把页面顶部右上角的总开关打开，再点页面底部的「保存设置」。开关关着时，命令不会执行，只会回一句提示，也不会去连打印机。

**第 2 步：登录 Bambu 账号。** 私聊机器人发 `/打印机 登录`。你会拿到一条网页链接，面板的「登录信封」页也能复制同一条。

1. 打开链接，先核对页面上的「公钥指纹」和机器人回复里那串是否一致。
2. 填 Bambu 账号、密码和区域，点「生成加密文本」。账号密码只在你的浏览器里加密，不经过聊天。
3. 把生成的 `BBX1.…` 整段贴回私聊，或者点网页上的「复制整条命令」再粘贴。机器人解开后就去云端登录，成功后会把这个账号下的打印机自动带出来。

云端要验证码时发 `/打印机 验证码`，收到邮件或短信后发 `/打印机 验证码 <6位>`；要两步验证时发 `/打印机 两步验证 <6位>`。这两个会话都只保留 5 分钟，超时要重新登录。

**第 3 步：发一条状态。** 私聊或群聊发 `/打印机 状态`。只有一台就直接出结果；有多台会列编号，回「1」或「第二台」即可，默认 10 分钟内不用重复选。

> 如果你要用局域网直连（只有主人能绑）：面板「局域网绑定」页点「搜索局域网打印机」，点一台自动填序列号和 IP，再补上打印机屏幕上的访问码，提交即可。搜索不会带出访问码，这个必须手输。

## 聊天命令

命令都以 `/打印机` 开头，中文命令后面不用加空格。`[打印机]` 可以写编号、名字或序列号；只有一台时可以省略。多台又没指定时，会先列编号让你选。

| 命令 | 在哪发 | 做什么 |
|---|---|---|
| `/打印机` 或 `/打印机 帮助 [页码]` | 哪都行 | 看命令帮助。帮助用合并转发发 6 页，主人多第 7 页 |
| `/打印机 登录` | 私聊 | 不带参数给登录网页链接；带 `BBX1.…` 就当场解开并登录 |
| `/打印机 验证码` | 私聊 | 让云端把验证码发到账号的邮箱或手机 |
| `/打印机 验证码 <6位>` | 私聊 | 提交验证码，完成登录 |
| `/打印机 两步验证 <6位>` | 私聊 | 提交两步验证码，完成登录 |
| `/打印机 同步` | 私聊 | 重新拉一次云端设备列表；本地凭据不用同步 |
| `/打印机 列表` | 哪都行 | 看自己的打印机、编号、打码序列号，以及别人授权给你的 |
| `/打印机 状态 [打印机]` | 哪都行 | 看进度、层数、已打印 / 剩余、预计完成、喷嘴和热床温度 |
| `/打印机 暂停 [打印机]` | 私聊；群要控制 | 暂停当前打印 |
| `/打印机 继续 [打印机]` | 私聊；群要控制 | 继续打印 |
| `/打印机 停止 [打印机]` | 私聊；群要控制 | 先发一次，1 分钟内再发一次带「确认」的才真正停止；不可撤销 |
| `/打印机 灯 开\|关 [打印机]` | 私聊；群要控制 | 打印仓灯。开和关必须写一个 |
| `/打印机 速度 1-4 [打印机]` | 私聊；群要控制 | 4 最快（狂暴），1 最慢（静音） |
| `/打印机 温度 喷嘴=220 热床=60 [打印机]` | 私聊；群要控制 | 至少给一个温度；0 表示关加热。喷嘴 0~300，热床 0~120 |
| `/打印机 拍照 [打印机]` | 哪都行；群要允许拍照 | 先试局域网，失败再试云端；两种都不通会如实说缺什么 |
| `/打印机 授权 <对方QQ> [分钟] [status,control,photo]` | 私聊 | 把自己的凭据限时共享给对方；默认 30 分钟、默认 `status,control`，最长 1440 分钟 |
| `/打印机 撤销 <授权编号>` | 私聊 | 提前收回授权；授权人和被授权人都能撤 |
| `/打印机 群权限 …` | 私聊 | 查看或修改自己打印机在群里的表现，不影响别人的 |
| `/打印机 审计 [条数]` | 哪都行 | 看自己的操作记录，默认 10 条，最多 50 条 |
| `/打印机 接口 云端\|本地\|自动` | 私聊 | 切换自己走哪条接口；只有主人能切本地，非主人始终云端 |
| `/打印机 证书 [序号]` | 私聊；仅主人 | 看局域网打印机的 8883 / 6000 / 322 三个证书指纹；`证书 信任` 重新固定控制面证书 |
| `/打印机 绑定 本地 <序列号> <IP> <访问码> [名称]` | 私聊；仅主人 | 新建一条局域网凭据；第一次查状态时会学这台打印机的证书 |
| `/打印机 绑定 追加 <序列号> <IP> [访问码] [名称]` | 私聊；仅主人 | 把一台打印机加进你最近那条局域网凭据 |
| `/打印机 绑定`（不带参数） | 私聊；仅主人 | 看自己有几条凭据和编号；普通用户会被告知直接去登录 |
| `/打印机 解绑 <编号>` | 私聊 | 删掉自己的一条绑定；删了要重新登录或重新绑定才能恢复 |
| `/打印机 锁定` | 私聊 | 清掉内存里缓存的密钥。不是退出登录：下次发命令（或让模型用工具）会自动恢复，不用重新登录 |

普通用户不需要用 `绑定` 命令：`/打印机 登录` 成功后会把这个云端账号下的打印机自动带出来。旧教程里把账号密码直接跟在 `登录` 后面、或者先设一个码再解锁的写法都已经取消，现在发过去只会收到一段说明，不会再收账号密码或码。

### 帮助分 6 页，主人 7 页

`/打印机 帮助` 会把所有页放进一张合并转发的折叠卡片，不刷屏。宿主不支持合并转发时退回普通文本，用 `/打印机 帮助 2` 翻页，页码超出会夹到第一页或最后一页。

1. 风险
2. 数据存在哪
3. 看状态与简单控制
4. 登录云端账号
5. 列表、授权、群权限
6. 凭据怎么保管
7. 主人专用（局域网），只有主人能看到

## 群聊里怎么用

群聊先看两条门槛：这个群必须在 Aurabot 的群白名单里；发消息的人必须已经绑了打印机，或者拿到了别人的授权。插件不再单独维护群号名单，私聊白名单和群白名单都跟着 Aurabot 自己的设置走。

默认群模式是「只读」：能看状态、进度、温度，控制类动作不行。能不能要照片由 `groupPhoto` 和打印机主人的群权限另外决定，默认允许。要控制，得由这台打印机的主人把群权限调到「控制」。全局设置项是 `groupMode`，绑定者可以在私聊用 `/打印机 群权限` 对自己的那台再收紧或放宽，优先于全局。授权来的打印机按原主人的设置，不按受权人的。

默认脱敏：群里状态里的文件名显示「已脱敏」，项目名永远不显示。只有三个条件同时满足才显示文件名：你是这台打印机的绑定者、你自己开了「群权限 文件名 开」、机器人主人也把 `allowGroupName` 打开了。

暂停、继续、开灯、调速、调温在群控制模式下可以用。默认群只读时，停止只能在私聊；只有在群模式被放到「控制」（全局设置，或绑定者自己的群权限）之后，群里才发得动停止，而且仍然要隔一条消息再确认。模型工具不会替你按停止。

绑定、解绑、登录、验证码、两步验证、同步、授权、撤销、群权限、接口、证书、锁定都只能在私聊做；群里发会被直接告知去私聊。自然语言提问（不带 `/打印机`）一分钟最多 20 次，私聊和群聊都算；明确发 `/打印机` 命令不走这条限流。

多用户模式关掉后，只服务主人一个人。其他人（包括已经绑定过的）发什么都不回，模型工具也不提供；这是故意的，避免暴露「这里有个只服务主人的机器人」。

## 面板的 6 个页签

面板是给管理这台机器人的人用的，代码里没有再单独做一次登录；能打开 Aurabot 后台面板的人就能看到这些内容（秘密仍然打码）。别把后台地址给不信任的人。

页首有一条风险横幅，点「我知道」会记在这台浏览器里，之后不再出现；完整说明在「帮助」页。总开关只有页顶那一个，和左侧「拓竹」标签上的小圆点是同一个值。

| 页签 | 谁能用 | 点了会发生什么 |
|---|---|---|
| 总览 | 能打开面板的人，只读 | 加载用户数、凭据数、打印机数、谁已解锁、生效中的授权。点一行展开看这条凭据和打印机（序列号打码、token 打码）；「只看已绑定」只是本页筛选 |
| 登录信封 | 能打开面板的人；链接是给要登录的用户 | 「刷新」读取登录链接、公钥指纹、建议 / 最大生存时间和已用段数；「复制链接」；把一段 `BBX1.…` 贴进来点「解析」，只看摘要，不消费、不执行 |
| 局域网绑定 | 只有主人；提交还要求主人账号已建立 | 看主人是否解锁；「建立账号，直接开始」，或者点「解锁」重新开一次会话（输入框可以留空）；「搜索局域网打印机」会向同网段发发现请求，点一台自动填序列号和 IP；补访问码后提交，绑完固定证书并试连一次；下面列出已绑的局域网凭据 |
| 设置 | 改的是整台机器人的设置 | 14 项设置（总开关在页顶）。改完点页面底部「保存设置」才生效。另有证书说明、「检查云端画面组件」和「下载 BambuSource 库」（云端画面要用的库）；下载需要已解锁的主人 |
| 审计 | 能打开面板的人，只读 | 点「读取最近 50 条」，每行显示时间、完整 QQ、动作、成功 / 失败、备注。备注里没有密码、访问码或 token |
| 帮助 | 谁都能看 | 风险告知、本地安全策略、两种接口、命令速查；风险横幅收起后，完整内容也在这里 |

「局域网绑定」页的「建立账号」不需要你填任何东西，点一下就能用；代价写在下一节。「检查云端画面组件」只读文件，不连打印机。

## 登录、凭据和隐私

### 登录网页和信封

登录链接的格式是 `<网页地址>#k=<87 个字符的公钥>`。默认网页是 `https://cdcp998.github.io/dsh-aurabot-qq-mods/`，主人可以把设置项 `enrollBaseUrl` 换成自己部署的那份。

网页只做一件事：用这把公钥在你的浏览器里加密账号和密码。它不会上传，也不保存；页面加载完后不再连外部域名。机器人用本机的私钥解开，私钥在数据目录的 `bbx-key.json` 里，不会出现在聊天、面板或日志里。

每段信封只能用一次，用过就作废；过期也打不开。当前内置网页固定生成 10 分钟有效的信封，服务端最多接受 `enrollMaxTtlMinutes` 分钟（默认 1440）。重放、过期、格式不对都会被拒绝。

**这里有一条必须说清楚的边界**：指纹只能证明「网页里用的公钥是这台机器人的」，不能证明「网页本身没被人改过」。网页是在你的浏览器里拿到明文的，谁控制这个网页，谁就能偷看。所以请用你信任的页面；如果是别人 fork 的机器人，最好把 `enrollBaseUrl` 改成自己部署的地址，不要一直用仓库维护者的页面。

用 OAuth（Google / Apple 等）注册的 Bambu 账号，要先去 Bambu 手机 App 的 Account Security 里设一个密码，才能用账号 + 密码登录。手机号账号会按中国站处理；国际站账号要在网页里把区域改成「国际」。

### 数据存在哪

数据在 `modules-data/bambu-print/`：

- `vault.json`：用户、加密后的绑定、偏好，以及一份明文元数据索引（QQ、凭据名、打印机名字 / 型号 / 序列号 / IP、时间）。
- `grants.json`：授权记录，只有「谁授权给谁、哪几条绑定、什么范围、到什么时候」，没有秘密。
- `audit.jsonl`、`audit.1.jsonl`：操作记录，超过 2MB 轮转，不含密码、访问码或 token。
- `host-key.bin`：本机主密钥，32 字节随机数，权限 0600。
- `bbx-key.json`：登录网页的私钥；`bbx-used.json`：用过的信封编号，防止重放。
- `bambusource/`：你点「下载 BambuSource 库」后放进去的库文件（BambuSource 是负责收云画面的库）。

绑定里的 token、访问码和证书是加密的：每个 QQ 一把独立的数据密钥（AES-256-GCM，一种加密算法），这把密钥再由 `host-key.bin` 包住。目录权限 0700，文件 0600，写入用临时文件加原子替换。

**代价是**：没有第二个密码，也没有「主人后门」；能读到这个数据目录的人（本机管理员、备份、同步盘）可以解开这里所有人的凭据，也能看到那份明文元数据。机器本身要可信。删掉这个目录等于永久删除，要重新登录 / 绑定，没有恢复按钮。

### 授权怎么共享

授权不是把 token 发出去，而是把你的凭据限时借给对方用。对方操作时，秘密从你的保险箱里现解现用，对方拿不到 token 或访问码，也碰不到你没有授权的绑定。

- 按 QQ 共享，立即生效，没有兑换码，也没有「导出 token」的接口。
- 默认 30 分钟，最长 1440 分钟（24 小时）；范围是 `status`、`control`、`photo`，命令默认给 `status,control`。只想让对方看，就写 `status`。
- 到期自动失效；你或对方都能用 `/打印机 撤销 <授权编号>` 提前收回。
- 授权编号只在授权成功的那条回复里出现。列表和审计目前不显示编号，最好当场记下来；这是现有的小缺点。
- 你这边锁了、或者太久没用导致会话过期，对方会暂时用不了。对方发一条自己的打印机命令就会自动恢复（聊天命令和模型工具都会自动补会话）。
- 没有「管理员」这一级。主人想用别人的打印机，也得让对方授权。

群聊里的授权还要再受群权限和脱敏规则约束，不是授权了就什么都能发。

## 局域网连接和证书

云端接口默认给所有人用：Bambu 账号登录换 token，走云端 MQTT（打印机和云端之间传状态、下命令的协议）看状态、下命令，打印机在哪都行。本地接口要求打印机和这台电脑在同一个网段，用打印机屏幕上的访问码直连，只有主人自己的绑定，或别人授权给你的绑定能用；普通用户自己不能绑局域网。

局域网这条链路分三个端口，保护方式不完全一样：

- **MQTT 8883（状态和控制）**：打印机用的是自己签的证书。第一次连接只握手读证书，一个字节都不发；记住之后（TOFU = 第一次连接时记住打印机证书，以后只认这一张），每次连接都拿它严格校验。没固定过证书就失败，不会把访问码发出去。
- **MJPEG 6000（A1 / A1 mini / P1P / P1S 的画面）**：MJPEG 就是一张张图片拼成的视频流；同样先学后固定，没有锚点就拒绝抓拍，不会「先连上试试」。
- **RTSPS 322（X1 / H2 / P2S / X2D 的画面）**：RTSPS 是加密的视频流。本机 `ffmpeg`（把视频解成一帧图片的小工具）的 RTSP 输入不支持自定义 CA 和指纹校验，所以做法是：启动 `ffmpeg` 之前先自己对 `:322` 握手取证书，和固定过的指纹比对；不一致、没固定或握手失败就不启动，访问码连 `ffmpeg` 的 stdin 都不会进。首次固定仍然是 TOFU 语义。

抓图超时：局域网抓一帧最多等 15 秒；第一次学摄像头证书最多等 8 秒；云端铸码 12 秒。

云端 MQTT 走系统根证书 + 主机名校验，不会因为配置里有自签锚点就降级成不校验。

`/打印机 证书 [序号]` 会列出三行指纹：局域网 8883、摄像头 6000、画面 322。确认是自己重刷了固件，可以用 `/打印机 证书 信任` 重新固定控制面（8883）的证书；不写序号时处理列表第一台。摄像头和 322 画面证书目前没有单独的重信任命令，证书变了会继续拒绝，通常要重新绑定或重新同步那台打印机。

**RTSPS 的边界**：首次固定那一刻如果局域网里已经有人在主动冒充，恶意证书会被记住；要彻底排除，只能在首次连接前带外核对指纹。日常看进度、暂停、调温完全不走 322，只有要 X1 系列那张图时才会用到。

## 设置项

下面这张表就是 `lib/settings.mjs` 的规则表。默认值、范围和键名都以它为准；面板里的表单、服务端的夹取和运行时的回落用的是同一份。

| 键 | 默认 | 范围 / 可选值 | 人话说明 |
|---|---|---|---|
| `active` | 关 | 开关 | 总开关。关掉后命令只回一句「总开关关着」的提示，不连打印机，帮助也不展开 |
| `multiUser` | 开 | 开关 | 开着每个人各用各的；关掉只服务主人，其他人静默不响应，工具也不给 |
| `groupMode` | `status` | `off` / `status` / `control` | 群里的默认权限：不响应 / 只看 / 允许控制。只作用于发起人自己的绑定 |
| `groupPhoto` | 开 | 开关 | 群里能不能要画面；还受打印机主人的群权限影响 |
| `allowGroupName` | 关 | 开关 | 群里是否显示文件名；默认连文件名都不显示，项目名永远不显示 |
| `defaultInterface` | `cloud` | `cloud` / `lan` | 主人默认走云端还是本地；非主人始终云端 |
| `ownerInterface` | 空 | 空 / `cloud` / `lan` | 主人的接口覆盖。留空跟随默认；填了会盖过 `/打印机 接口` 的个人选择 |
| `ownerLocalAllowed` | 开 | 开关 | 本地接口总闸。关掉后主人和授权用户都只能走云端 |
| `ownerNoCode` | 开 | 开关 | 旧版遗留开关。现在所有人都不需要输码，它只影响面板上显示的账号状态，不影响实际功能 |
| `unlockDays` | 7 | 1~30 天 | 解密后的密钥在内存里缓存多久；到期自动清掉，下次用会自动打开（聊天和模型工具都会自动补会话） |
| `maxBindings` | 5 | 1~20 条 | 一个人最多几条凭据；一个云端账号算一条，可以含多台打印机 |
| `requestTimeoutMs` | 6000 | 2000~20000 毫秒 | 等打印机回执最长多久 |
| `selectedTtlMinutes` | 10 | 1~60 分钟 | 多台时选过哪台之后，多久内不用再说 |
| `tutkBridgePath` | 空 | 文本 | 抓帧桥路径。留空用模块自带的 `assets/tutk-bridge/` 里的程序 |
| `tutkLibPath` | 空 | 文本 | BambuSource 库文件路径。留空先看环境变量 `BAMBU_SOURCE_LIB`，再看桥同目录 |
| `tutkTimeoutMs` | 20000 | 3000~60000 毫秒 | 云端抓一帧最长等多久；桥实际抓 2~60 秒 |
| `enrollBaseUrl` | 空 | 文本 | 登录网页地址前缀。留空用内置 GitHub Pages；必须以 http(s) 开头，少于 300 个字符 |
| `enrollTtlMinutes` | 60 | 1~1440 分钟 | 历史设置：面板仍会显示这个建议值；内置网页固定 10 分钟，所以它不影响实际有效期 |
| `enrollMaxTtlMinutes` | 1440 | 1~1440 分钟 | 服务端只接受不超过这个值的信封；小于建议值时会自动抬到建议值 |

面板里能改的是 `active`（页顶开关）和「设置」页的 14 项。`ownerNoCode`、`enrollBaseUrl`、`enrollTtlMinutes`、`enrollMaxTtlMinutes` 目前没有表单输入框；后两项只在「登录信封」页显示当前值，要改只能直接改模块配置。

## 会访问哪些地址

除了下面这些，不会主动连别的地方。下载那一条只有你点按钮才会发生；其余都是你发命令、开面板或拍照时按需连接。

| 地址 | 什么时候连 | 传什么 |
|---|---|---|
| `api.bambulab.com`、`api.bambulab.cn` | 登录、验证码、同步设备、铸云端画面凭据 | 账号密码只在登录那一次；之后是 token 和设备序列号 |
| `bambulab.com`、`bambulab.cn` | 只有两步验证时：取 CSRF 令牌（防跨站请求的令牌）、提交两步验证 | 登录会话 cookie 和那一次的 6 位码 |
| `us.mqtt.bambulab.com`、`eu.mqtt.bambulab.com`、`cn.mqtt.bambulab.com`（8883） | 走云端接口看状态、控制 | 该用户的云端 token |
| 打印机局域网 IP 的 8883 / 6000 / 322 | 主人绑定局域网，或你拿到带本地权限的授权 | 局域网访问码；画面交给本机 `ffmpeg` |
| `239.255.255.250` 的 UDP 1990，以及各网段广播的 UDP 2021 | 面板点「搜索局域网打印机」 | 一个发现请求，不带凭据；访问码不会广播 |
| TUTK（拓竹云画面的传输方案）的公网 rendezvous / 中继（`docs/TUTK.md` 记为 UDP 3478） | 云端画面抓帧 | 云端铸的 ttcode，经 0600 临时文件交给抓帧桥 |
| `api.github.com`、`github.com`、`release-assets.githubusercontent.com` | 只有你点「下载 BambuSource 库」 | 匿名 GET，不带你的账号信息 |
| `githubproxy.cc`、`ghfast.top`、`ghproxy.net`、`gh-proxy.com` | 同上，但只在国内网络或直连失败时 | 同一个 GitHub 文件地址，经代理转一次 |
| `https://cdcp998.github.io/dsh-aurabot-qq-mods/` | 你打开登录链接时，由你的浏览器加载 | 页面本身由 GitHub Pages 提供；填的账号密码只在浏览器本地加密，不上传 |

TUTK 不是纯局域网：打洞失败时会走 ThroughTek 的公网 rendezvous 或中继，画面数据到底走哪条路取决于网络，模块只把 ttcode 交给抓帧桥。下载 BambuSource 时，默认先落到 `modules-data/bambu-print/bambusource/`，不写进模块目录，免得热重载把内存里的会话清掉。

## 已知限制

- 只做状态、暂停继续停止、灯、速度、温度、拍照；切片、上传模型、发起打印都没有入口。AMS 的换料 / 加载这类操作也没有入口；状态数据会解析 AMS 上报的内容，但聊天状态里没有单独展示 AMS 明细。
- 本地接口要求打印机和这台电脑在同一网段；普通用户自己不能绑局域网，只能由主人绑，或由主人授权给你。
- X1 / H2 / P2S / X2D 的画面需要本机装 `ffmpeg`（在 `PATH` 里）。云端画面还需要一份 BambuSource 库；抓帧桥只预编译了 Windows x64 和 Linux x64，其他平台要自己编。
- 局域网证书是「先学后固定」，首次连接那一刻的中间人挡不住；RTSPS 首次固定也一样。要彻底排除只能带外核对指纹。
- 摄像头和 322 画面证书变了以后没有单独的「重新信任」命令，通常要重新绑定或重新同步那台打印机；控制面 8883 可以用 `/打印机 证书 信任`。
- 授权编号只在授权成功的回复里出现，列表和审计不显示；撤销时找不到编号就是个麻烦，最好当场记下。
- 云端 token 会过期，过期要重新登录；OAuth 账号要先在 Bambu App 设密码；账号区域选错会登录失败。
- `ownerNoCode` 目前不改变行为；`enrollTtlMinutes` 目前只影响面板显示，内置网页固定 10 分钟；这 4 项设置没有面板输入框。
- 数据目录里的元数据是明文，秘密是密文；能读目录的人两样都能拿到。删除目录不可恢复。
- 面板本身没有再登录一次，能打开 Aurabot 后台面板的人就能看到里面的内容；秘密仍然打码。
- 群里默认只读；要控制得把群模式放到「控制」（全局设置，或绑定者自己的群权限）。停止还多一道二次确认，模型工具不会代按。
- 自然语言提问一分钟最多 20 次（私聊和群聊都算）；停止确认窗口 1 分钟；登录验证码会话 5 分钟；这些是防误触和防刷屏，不是安全认证。
