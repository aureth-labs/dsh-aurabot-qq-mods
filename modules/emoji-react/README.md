# 表情回应拓展 · AuraBot 模块

偶尔给一条消息贴一个表情回应——相当于长按消息、在「表情回应」里选一个，**不发消息、不插话**。不掷骰子，由模型自己看这条消息适不适合回应。

## 做什么

- 每收到一条消息，交给模型判断：适不适合贴、贴哪个。早安晚安、生日祝福、好消息、道谢、分享好玩的事这类会贴；正经讨论、吵架、求助提问、纯链接不贴。
- 适合才从你配置的候选表情里挑一个；模型觉得没合适的就输出 0，什么都不做。
- 用 OneBot 的 `set_msg_emoji_like` 给那条消息贴表情，失败只写调试日志，不会在聊天里报错。
- 同一个群 / 私聊有冷却（默认 20 分钟），避免连着贴、显得刷屏。

范围：

- 群：只在她被允许的群里贴（Aurabot 的群白名单）。
- 私聊：主人和白名单里的私聊对象。
- 跳过：自己发的消息、空消息、以 `#` `/` 开头的命令。

## 设置

| 项 | 说明 |
|---|---|
| 启用 | 总开关 |
| 同一个会话冷却 | 分钟，默认 20 |
| 只回应主人 | 打开后群友的消息不贴，只给主人贴 |
| 可选表情 | 每行 `名字=表情ID`，模型只能从这里挑，最多 30 个 |

因为判断完全交给模型，所以白名单里的消息都会调一次模型；刚贴过的会话在冷却期内会直接跳过、连模型都不调。想省 token 可以把冷却调长，或打开「只回应主人」。

默认候选：赞、笑哭、爱心、吃瓜、鼓掌、捂脸、思考、哭、玫瑰、鱼（大肥鱼）。

## 表情 ID

`emoji_id` 是 QQ 表情的数字 ID，网关原样接收，常见写法是按 Unicode 码点：

| 表情 | ID |
|---|---|
| 👍 赞 | 128077 |
| 😂 笑哭 | 128514 |
| ❤ 爱心 | 10084 |
| 🍉 吃瓜 | 127817 |
| 👏 鼓掌 | 128079 |
| 😅 捂脸 | 128517 |
| 🤔 思考 | 129300 |
| 😭 哭 | 128557 |
| 🌹 玫瑰 | 127801 |
| 🐟 鱼 | 128031 |

不同网关对 ID 的取值可能不一样：如果贴出来的不是你想要的表情，把设置里对应那行的数字换成网关认的值即可。少数老网关不支持 `set_msg_emoji_like`，这时模块只会记日志、不会报错。

## 权限与隐私

- 只读 Aurabot 配置里的群 / 私聊白名单、`botQQ`、`ownerQQ` 和 `dryRun`，不改配置。
- 只把当前这一条消息的文字交给模型挑表情，不带聊天记录、不带昵称和 QQ 号。
- 不访问任何外部网站；不发消息、不发表情包图片，只调用本机 OneBot 的一个动作。

## 能力声明

- `plugin-config`：读取 Aurabot 的 `allow.private` / `allow.groups` / `ownerQQ` / `botQQ` / `dryRun`。

## 安装

模块市场安装，或把整个 `emoji-react/` 文件夹放进：

```text
~/.dsh/plugins-data/aurabot/modules/emoji-react/
```

保存后几秒内自动加载。

## 文件

- `index.mjs`：入口，掷骰子、挑表情、贴回应
- `module.json`：模块信息
- `test/index.test.mjs`：本地测试（不进发布包）
