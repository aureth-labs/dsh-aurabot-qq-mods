# 记忆总库

自己的记忆，自己存。

存记忆、判密级、盖三档章，还能顺手标八卦。
**东西全在自己机器上**——不联网、不上传、不调用任何外部服务。

它包含三块：

| 块 | 干什么 |
| --- | --- |
| 存储 | 把记忆存在一个 JSON 文件里，增删改查、关键词检索 |
| 密级 | 判断一句话能不能往外说，盖机密 / 内部 / 公开的章 |
| 八卦 | 用乾坤震巽坎离艮兑八个字，标「是什么」和「怎么用」，可关 |

## 装好之后先做这件事

每个人的「不能说出去的事」都不一样，所以这个模块**不预设**任何人的名字。

第一次装上时，机密判断是残缺的——只认「保密」「别告诉」「家里人」这种通用词。
打开面板里这个模块的标签页，把这几项填上：

| 设置项 | 填什么 | 重不重要 |
| --- | --- | --- |
| 她自己的名字 | AI 角色的名字 | 可选 |
| 家里人的名字 | 一行一个，或用 \| 隔开 | **最重要** |
| 主人的 QQ 号 | 多个用 \| 隔开 | 重要 |
| 还想加哪些机密词 | 公司名、项目代号 | 按需 |
| 哪些词是安全的 | 免责名单，一般不用填 | 可选 |
| 没填名字时提醒我 | 开关 | 建议开 |
| 顺便标个八卦 | 开关 | 默认关 |

没填的时候启动会打一条提醒，不会静默跑。

## 怎么存、怎么找

```js
const mem = api.use('memory-grade')

// 记一条：密级和卦位自动补
mem.remember('以后每次改代码前都要先备份', { tags: ['规矩'], importance: 0.9 })

// 找：按关键词打分
const hits = mem.recall('备份')
// -> [{ text, cls, gua, _score, ... }]

// 最近记的
mem.recent(10)

// 有多少条
mem.stats()
// -> { total, pinned, byCls: { secret, internal, public }, byTag }
```

想自己操作库的话，`mem.store` 里有全套：`add / get / update / remove / list / search / pin / touch / stats / all`。

## 存在哪

`api.dataDir()` 下面一个 `memory.json`。

- 每次改完立刻落盘，先写 `.tmp` 再改名，半路断电不会写坏
- 文件坏了会自动改名备份，用空库启动，不会把插件拖死
- 几千条完全够用，不需要装任何原生模块

## 判断规则

按这个顺序走，命中就停：

1. 出现设置里的 QQ 号 -> **机密**（按数字边界判，`1234567890` 不会误中 `123456789`）
2. 命中「安全词」 -> **公开**。比如 `保密协议` 是在聊工作，不该算秘密
3. 出现机密词 -> **机密**
4. 其余 -> 不机密

机密词包括：设置里填的名字 + 通用词（家里人 / 咱家 / 保密 / 机密 / 别告诉 / 不能说 / 我爸爸 / 我妈 ……）

## 盖章规则

按这个顺序：

1. 记忆带 `pin: true`（置顶）-> `secret`
2. tags 里有「家人」-> `secret`
3. 判定成机密 -> `secret`
4. tags 里有「知识」-> `public`
5. tags 里有「群聊」-> `public`（群里说的话本来就有人听见）
6. 其他 -> `internal`

## 装好了怎么用

```js
export default {
  id: 'my-memory-helper',
  name: '我的记忆助手',
  api: 1,
  setup(api) {
    const grade = api.use('memory-grade')
    if (!grade) {
      api.log?.warn?.('memory-grade 没装，跳过密级判断')
      return
    }

    // 判断一句话
    const r = grade.judge('我妈让我周末回家')
    // -> { secret: true, reason: '出现了机密词：我妈' }

    // 给一条记忆盖章
    const cls = grade.classify({ text: '...', tags: ['知识'] })
    // -> 'public'
  },
}
```

三个函数：`judge(text)`、`classify(item)`、`ready()`。

`ready()` 返回设置填全了没有，可以在自己的模块里据此决定要不要提醒用户。


## 顺便标个八卦（可选）

设置里有个「顺便标个八卦」开关，默认关。

打开之后，每条记忆会多两个字段：

```js
{ gua: '艮乾', guaUpper: '艮', guaLower: '乾' }
```

八个字的意思：

**上卦（这条在说什么）**

| 卦 | 意思 | 什么时候归到这 |
| --- | --- | --- |
| 艮 | 边界 | 红线、隐私、家庭身份、不能对外说 |
| 乾 | 规则 | 约定、规矩、以后都要怎么怎么样 |
| 坎 | 技术 | 报错、路径、配置、踩过的坑 |
| 兑 | 人物 | 某人的性格、习惯、关系 |
| 巽 | 偏好 | 喜好、口味、审美 |
| 离 | 情感 | 心情、感受 |
| 坤 | 事实 | 知识、资料、从视频里学到的 |
| 震 | 事件 | 某天做了件具体的事 |

**下卦（怎么用）**

| 卦 | 意思 |
| --- | --- |
| 乾 | 立规矩：每次都要生效 |
| 坎 | 提醒：下次别踩 |
| 艮 | 封存：已经作废了 |
| 震 | 立刻用：马上就要 |
| 巽 | 慢慢渗：影响语气口味 |
| 兑 | 对人说：只对某人有用 |
| 离 | 主动说：可以拿来聊 |
| 坤 | 存着：平时备查 |

**它不参与检索。** 只是给记忆贴个标签，整理的时候方便按类看。
纯本地关键词规则，不联网、不花钱。想更准的，可以在你自己的模块里接模型覆盖掉。

注意：这是关键词规则版，判得不算精细。你要是用它，建议先自己抽几十条看看对不对味。



## 遗忘：两种模式，自己挑

记忆不会一直堆着。久了没用到、又不重要的，会先**休眠**（不占默认检索，但还在库里），
再**归档**（正文压成一行摘要）。

**置顶的和机密的一律不动。** 只降级，不删库。

### 模式一：按强度（默认）

看重要度 + 多久没想起，算一个 0~1 的强度。

- importance 0 的，7 天掉一半
- importance 0.5 的，30 天掉一半
- importance 1 的，90 天掉一半

每被想起一次（`touch`）就加点分量，最多加 0.4。

面板里能调「休眠阈值」（默认 0.12）和「归档阈值」（默认 0.04）。**数字越小，忘得越慢。**

### 模式二：按天数

打开「按天数忘，而不是按强度」，就只看多久没想起，不管重要度。

- 填 90，就是 **90 天没想起 -> 休眠**，**180 天 -> 归档**
- 适合想要一个简单固定规则的人

两种模式都受「置顶 / 机密不动」保护。

### 自动清理

「每隔几小时自动清一次」，默认 24 小时。填 0 就关掉，全靠自己调 `decay()`。

## 汇总：把各会话的话收进总库

这个是解决"精神分裂"的——不同会话各记各的，人就不连贯了。

打开「自动收各会话的话」，再在「收哪些会话」里填会话 id（一行一个）：

```
private:123456789
group:987654321
```

留空就收全部。默认每 30 分钟收一次，能改。

**它收什么：**

- 只收装了模块之后**新发生**的消息，不翻历史
- 太短的（4 个字以下）、纯占位符（`[图片]` 这种）会跳过
- 收进来会自动判密级，开了八卦就一起标

**重要提醒：** 想一次把老聊天灌进来，得自己写代码调 `remember()`，见下面「迁移」。

## 手动控制

```js
mem.decay()                    // 算一下，不改
mem.decay({ apply: true })     // 真降级
mem.collect()                  // 立刻收一次会话
mem.purgeArchived({ olderThanDays: 180 })   // 删掉长期归档的，不可逆
mem.state(id)                  // 'active' / 'sleeping' / 'archived'
mem.strength(id)               // 0~1
```

## 注意事项（**装之前先看这一段**）

### 一、这是个**空库**，不带任何人的记忆

装完是 0 条。它不会读你现有的记忆，也不会把你的记忆传出去。

**它不会接管、覆盖或修改插件原本的记忆模块。** 两边是两套东西：

- 插件原本的记忆模块继续干它自己的活
- 这个模块只管你自己调 `remember()` 记进来的东西

想让它管你现有的记忆，得你自己写代码去搬（见下面「迁移」）。

### 二、别让两个 AI 共用一份数据

如果你在同一台机器上跑了多个角色（比如两个 QQ 号），**每个角色要用自己的数据目录**。

`api.dataDir()` 是按模块 id 分的，同一个插件里只有一个。所以：

- 一个插件只跑一个角色：没问题，直接用
- 一个插件跑多个角色：你得在外面再分一层目录，别让 B 角色的记忆读到 A 角色的

不分开的后果：B 角色会"记得"A 角色的事，说话会串味。

### 三、密级判断是"辅助"，不是"保险"

它靠关键词匹配，会漏，也会误判。

- 家里人换了昵称、用了简称 -> 认不出来
- 说了从没填过的词 -> 认不出来
- 「保密协议」这种固定说法 -> 需要你手动加安全词

**判断为 `internal` 不等于安全**，只是说"没匹配到已知的机密词"。
真正要紧的东西，别指望它拦得住，你自己得盯着。

### 四、八卦是关键词规则版，判得不细

打开「顺便标个八卦」之后，分类是按关键词猜的，跟人工判的有差距。

- 「今天被夸了心里挺暖」会归到离（情感），这个对
- 「这个方案作废了」会归到艮（封存），这个也对
- 但稍微绕一点的说法就猜不准了

**它不参与检索**，只是给个标签方便你按类看。别拿它当准确分类用。

### 五、数据在自己机器上，不会同步

换了电脑、重装了插件，数据**不会自动跟过去**。

要备份就把 `api.dataDir()` 下的 `memory.json` 复制走。删模块的时候，`api.dataDir()` 默认会留着（插件不删模块数据），但你自己确认一下。

### 六、几千条以内没问题，别拿它存几百万条

JSON 文件整份读进内存。三千条以内很轻松，几万条开始吃力，几十万条会卡。

要存很多，自己换 SQLite。

## 迁移：把现有记忆搬进来

它**不会自动搬**。要搬的话，在你自己的模块里写一段：

```js
const mem = api.use('memory-grade')
const old = api.use('memory')      // 插件原本的记忆模块，函数名看它的文档

for (const item of old.listAll()) {
  mem.remember(item.text, {
    tags: item.tags,
    importance: item.importance,
    cls: item.cls,          // 已经有了就直接用
    at: item.at,
  })
}
```

搬之前把原库备份一份。搬完自己抽查几十条，确认密级没被重新判歪。

## 会访问什么

- 读：`api.settings()`（面板里你填的设置）
- 写：`api.dataDir()` 下的 `memory.json`（你的记忆）
- 联网：**不联网**
- 执行程序：不执行

能力声明：`filesystem`（读写自己那个数据文件）。除此之外不碰任何东西。

## 编码

所有文件都是 UTF-8（不带 BOM）。如果你的系统读到了乱码，检查是不是被别的工具转成了带 BOM 的格式。
