# 人格素材库（persona-corpus）

群里有人说「你这句太人机了，收进反面素材」，她以前只能回一句「好我记下了」，然后什么都没留下，下次照样犯。
这个模块给她一本真能写、真能翻、别的模块也能用的素材本：**原话 + 为什么不对 + 换成她会怎么说**，落在主人指定的目录里。

跟 `/素材` 一起用：群里被点名就收，主人私聊里翻出来看，人格实验室做自我反思时就能照着这些反例改。

## 一条素材长什么样

| 字段 | 说明 |
|---|---|
| 原话 `text` | 照抄，不改写。反面素材的价值全在「它原样长这样」 |
| 类型 `kind` | `negative` 反面（别这么说）、`positive` 正面（像她、值得学）、`note` 观察（实验记录） |
| 为什么 `note` | 人机味出在哪，或者好在哪 |
| 换成 `fix` | 换成她会怎么说。反面素材填了这个，下次才真用得上 |
| 标签 `tags` | 最多 5 个，逗号或空格分开 |
| 出处 `source` | 哪个聊天、谁要求收的（主人 / 群友 / 她自己） |

id 由「类型 + 原话」算出来（`c-` 加 12 位），所以同一句话收两遍只留一条，群里几个人同时喊「收了」也不会变成三条。

## 怎么用

### 聊天里

- 被点名收录（群里、私聊都行）：她自己调 `corpus_save`，把那句原话抄进去。
  - **主人要收的** → 直接入库
  - **群里别人要收的** → 先进「待审」，主人过了才算入库（默认开，可在设置里关）
- 「就刚才那句」也行：给 `messageId`，或者 `fromLast: true`，从最近消息里把原文捞回来 —— 不用她整句复述。
- 收完她会照工具返回的说法讲（「收了，反面第 3 条」），工具没成功就照实说 —— 这条写在模块规则里，免得又变成口头敷衍。

### 工具

| 工具 | 谁能用 | 做什么 |
|---|---|---|
| `corpus_save` | 她（任何聊天） | 收一条：`text` / `kind` / `note` / `fix` / `tags`，可给 `messageId`、`fromLast` |
| `corpus_list` | 主人 | 翻库：按类型、关键词（原话/为什么/换成/标签）找，最多 50 条 |
| `corpus_review` | 主人 | 待审队列：`list` / `approve` / `drop`，`ids` 写 `all` 表示全部 |

### QQ 命令（只有主人可用）

| 命令 | 作用 |
|---|---|
| `/素材` | 统计 + 最近 3 条 + 待审提示 |
| `/素材 过 all` | 待审全部通过 |
| `/素材 过 c-xxx,c-yyy` | 通过指定几条 |
| `/素材 删 c-xxx` | 删一条（库里和待审里都找） |
| `/素材 列出 反面` | 看最近 10 条（也可以写 `正面` / `观察` / `negative`） |
| `/素材 目录` | 素材存在哪、三个文件各多少条 / 多大 |
| `/素材 导出` | 重新生成 `corpus.md` 镜像 |

### 给别的模块用

`api.use('persona-corpus')` 之后可以拿：`list()`、`recent(n)`、`digest(n)`、`summary()`、`save(entry)`、`info()`。
人格实验室做反思时用 `list({ kind: 'negative' })` 就够了；这里不碰别的模块的文件。

## 素材落在哪

- 默认：`plugins-data/aurabot/modules-data/persona-corpus/`
- 设置里填**绝对路径**（比如 `D:\aurabot-corpus`）就写到那儿，目录不存在会自动建
- 填相对路径、或者指到一个文件上，会回落到插件数据目录，`/素材 目录` 里会说明为什么

| 文件 | 是什么 |
|---|---|
| `corpus.jsonl` | 正本，一行一条。想批量改就改这个 |
| `corpus.md` | 给人看的镜像，每次改动后重写。**改它不生效** |
| `pending.json` | 待审队列（群友要求收录的），最多攒 30 条 |

## 设置

| 设置 | 默认 | 说明 |
|---|---|---|
| 素材库 | 开 | 关掉以后工具只回「没开」，不写盘 |
| 素材目录 | 空 | 空 = 插件数据目录；填绝对路径就写到那儿 |
| 最多保留几条 | 200 | 超了从最旧的开始丢（20~2000） |
| 群友也能要求收录 | 开 | 关掉后只有主人能收；开着时群友的要求先进待审 |
| 每轮带素材提要 | 开 | 只塞给主人那一轮，带最近几条反面素材和待审数 |
| 提要里列几条 | 3 | 0 = 只报数字 |

## 跟别的模块什么关系

- **`anti-bot`（人机反面教材）**：它自动认出「一眼就是 AI」的评论，自己攒库、每轮提醒别那么说话。这个模块是**被人点名**时把原话收下，收成「原话 / 为什么 / 换成什么」三件套，可以写到主人指定的目录里拿走用。两个库不互相读写。
- **`persona-lab`（人格实验室）**：它负责「观察口癖 + 定期自我反思」。反思的时候用 `corpus_list` 翻这本库，反例比抽象规则管用。
- **`slop`（去套话）**：它改的是发给模型的历史，不落盘；这里落的是素材本身。

## 会访问哪里

**不联网。** 没有任何 `fetch`，不连网关以外的服务，也不在运行时下载或执行任何代码。只读写上面那几个本地文件。

## 能力声明

- `filesystem`：写 `corpus.jsonl` / `corpus.md` / `pending.json`（默认在插件数据目录，也可以在主人指定的目录）。
- `plugin-config`：读插件配置里的演练模式开关（`api.config().dryRun`）。演练时不落盘，免得模拟测试的假消息混进真素材。
- `plugin-internals`：用 `api.core.hub.turnSendersAllOwner(sessionId)` 区分「主人这一轮」和「群友这一轮」——决定直接入库还是先进待审，也决定提要只塞给主人。
- 不用 `network` / `process` / `dynamic-code`，所以没声明。

## 隐私

- 素材是原话，可能带着群友的话。所以群聊里不塞提要、不外发到任何地方。
- 群友只能往待审里写，主人 `/素材 过` 之后才进库；不想留就 `/素材 删`，正本里真的会删掉。
- `corpus.md` 是纯文本镜像，主人随时可以自己看、自己备份。

## 安装

把 `persona-corpus/` 放进 Aurabot 数据目录的 `modules/persona-corpus/`，在面板「扩展」页启用即可。设置项在模块的设置页里。
