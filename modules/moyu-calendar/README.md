# 摸鱼人日历（moyu-calendar）

每天从微信公众号「摸鱼人日历」当天的文章里取出日历图，发到指定的 QQ 聊天。安装后「每天自动发送」默认开着：次日北京时间 08:00 起发给主人私聊。不想自动发，把这个开关关掉。

## 做什么

| 能力 | 说明 |
|---|---|
| 每日自动 | 默认北京时间 08:00 开始找今天的图，找到就发。没找到每 30 分钟再试，12:00 仍没有就记为今日无更新 |
| 手动获取 | `/moyu` 把今天的图发到当前聊天。`/moyu 状态` 看任务，不列出具体聊天号 |
| 当天缓存 | 同一天只下载一次，命令和定时任务共用这张图 |
| 来源 | 填了 RSS 就优先用；没填或 RSS 失败时，用搜狗微信搜索定位文章，再经逛网页打开文章取图 |

公众号不是每天都发。到截止时间还没有当天文章，当天就不再重试。已经下到的图如果有聊天没发出去，过了截止时间仍会补发。

首次安装时如果已经过了开始时间，自动发送从明天开始。当天仍可以用 `/moyu` 手动取。

## 依赖

文章页对普通 HTTP 请求会返回「环境异常」。这个模块不破解验证码，也不去点验证。

要走搜狗这条路，需要另装并打开 [逛网页（browser-ops）](../browser-ops/)：

1. 面板里打开逛网页的总开关。
2. 如果填了站点白名单，加入 `mp.weixin.qq.com`，或者把白名单留空。
3. 搜狗搜到文章后，本模块用 `api.use('browser-ops')` 打开那一篇，读出第一张竖版日历图。打不开或仍是验证页，这次算失败，等下一轮。

只使用 RSS 时可以不装逛网页。RSS 用自建的 [we-mp-rss](https://github.com/rachelos/we-mp-rss) 或 [wechat2rss](https://github.com/ttttmr/wechat2rss)，订阅公众号「摸鱼人日历」，把订阅地址填到「RSS 地址」。填了就优先用，失败再走搜狗。

`requires` 留空，没装逛网页也能安装。不配 RSS、又没打开逛网页时，取图会直接说明：请安装并打开「逛网页」，或改填 RSS 地址。

## 怎么用

1. 安装后在模块设置里确认开始时间、截止时间，以及私聊、群聊接收号码。
2. 私聊、群聊分开填，只写数字。私聊留空发给主人；群号留空则不发到群。手动命令仍回复发出命令的那个聊天。
3. 自动发送只在插件启用、不是演练模式、并且「每天自动发送」开着时进行。
4. 在聊天里发 `/moyu`，或直接发设置里的触发词。默认整句 `摸鱼人日历`、`摸鱼日历`、`摸鱼` 都可以，前面的斜杠可有可无。发出图片后不再另回一句确认；失败时仍会说明原因。后面加「状态」只看任务。只有主人能这样发。

## 用到的网络地址

| 地址 | 谁去访问 | 目的 |
|---|---|---|
| `weixin.sogou.com` | 本模块 | 按「摸鱼人日历 + 当天日期」搜索文章。请求头使用浏览器标识，否则搜狗经常不返回结果页 |
| `mp.weixin.qq.com` | 逛网页，不是本模块直接请求 | 打开搜狗给出的文章临时链接 |
| `mmbiz.qpic.cn` | 本模块 | 下载日历图。地址里的 `/640` 会换成 `/0` 以取原图 |
| 设置里的 RSS 地址 | 本模块 | 仅当填写了才访问。拒绝本机、内网和带账号密码的地址 |

发给这些地址的只有搜索词或 RSS 请求，没有聊天内容、QQ 号或插件 Cookie。搜狗当次下发的 Cookie 只放在内存里跟完这一次跳转，不写入数据目录。日志里不记录 Cookie 和带签名的文章地址。

## 数据存放

写在插件分配的数据目录（`plugins-data/aurabot/modules-data/moyu-calendar/`）：

- `daily-state.json`：今天试了几次、哪些聊天已经发过、是否完成或无更新
- `YYYY-MM-DD.png`（或 `.jpg` / `.webp`）：当天的日历图，保留 14 天

这些都不随模块分发。

## 版权

日历图的版权属于公众号「摸鱼人日历」。模块不打包、不修改这些图片，只在用户自己的机器上转发，并默认附上一句「来源：公众号 摸鱼人日历」。附言可以改掉或留空。

## 权限说明

`module.json` 的 `capabilities`：

- `network`：访问上面列出的地址
- `filesystem`：读写自己的任务记录和图片缓存
- `plugin-config`：读取插件是否启用、是否演练模式、主人 QQ，用来决定要不要自动发、发给谁。不修改插件配置，也不读取账号 Cookie

没有 `process` / `dynamic-code`。不启动外部程序；文章页里执行的是一段固定的只读脚本，由逛网页模块跑在页面里，不在本模块里 `eval`。

## 安装

面板「模块市场」搜索「摸鱼人日历」，或把这个文件夹放进 `plugins-data/aurabot/modules/moyu-calendar/`。
