# 摸鱼人日历（moyu-calendar）

每天从微信公众号「摸鱼人日历」当天的文章里取出日历图，发到指定的 QQ 聊天。安装后「每天自动发送」默认开着：次日北京时间 08:00 起发给主人私聊。不想自动发，把这个开关关掉。

## 做什么

| 能力 | 说明 |
|---|---|
| 每日自动 | 默认北京时间 08:00 开始找今天的图，找到就发。没找到每 30 分钟再试，12:00 仍没有就记为今日无更新 |
| 手动获取 | `/moyu` 把今天的图发到当前聊天。`/moyu 状态` 看任务，不列出具体聊天号；其中「实际来源」是最近一次取图用的是哪一路 |
| 当天缓存 | 同一天只下载一次，命令和定时任务共用这张图。同一天再发 `/moyu` 用的是缓存，不会重新取 |
| 面板 | 显示今天从哪一路取的图。「清除已获取」删掉今天缓存的图，定时任务会重新取图并发送 |
| 来源 | 填了 RSS 就优先用；没填或 RSS 失败时，读公众号合集里当天的文章并直接取图；合集读不到再用搜狗微信搜索定位文章，经逛网页打开文章取图 |

每次真正取图都会在日志里记一条来源，并按顺序写明前面几路为什么没用上，例如 `摸鱼日历取到图 来源：合集 RSS：没有今天的文章 → 合集：成功`。手动命令用缓存时记的是「用的是缓存里的图，最初来源：…」。取不到时定时任务和手动命令都会记一条，同样带每一试过的来源。RSS 超过 10MB 时只保留末尾 10MB，并在来源里写成「RSS：成功（超过 10MB，只保留末尾 10MB）」；末尾 10MB 里没有今天的文章时算 RSS 失败，接着试合集。

公众号不是每天都发。到截止时间还没有当天文章，当天就不再重试。已经下到的图如果有聊天没发出去，过了截止时间仍会补发。

首次安装时如果已经过了开始时间，自动发送从明天开始。当天仍可以用 `/moyu` 手动取。

## 依赖

模块不破解验证码，也不去点验证。来源按下面的顺序试，前一条失败就走下一条：

1. **RSS 地址**（可选）：填了就优先用。默认只接受公网地址，本机和局域网地址会被拒绝；RSS 跑在本机或局域网时，打开「允许内网 RSS」。
2. **合集**：公众号把每期日历放进同一个合集。模块直接读合集的文章列表，找到当天的文章后请求文章页取图。这一条不用登录，也不用逛网页。
3. **搜狗**：用搜狗微信搜索定位文章，再经逛网页打开文章。要走这一条，需要另装并打开 [逛网页（browser-ops）](../browser-ops/)：

   1. 面板里打开逛网页的总开关。
   2. 如果填了站点白名单，加入 `mp.weixin.qq.com` 和 `weixin.sogou.com`，或者把白名单留空。
   3. 搜狗的普通请求若被验证页拦住，就用逛网页打开同一个搜索地址，不填写验证码。搜到文章后再打开那一篇，读出第一张竖版日历图。打不开或仍是验证页，这次算失败，等下一轮。

RSS 和合集都不需要逛网页。RSS 用自建的 [we-mp-rss](https://github.com/rachelos/we-mp-rss) 或 [wechat2rss](https://github.com/ttttmr/wechat2rss)，订阅公众号「摸鱼人日历」，把订阅地址填到「RSS 地址」。填了就优先用，失败再走合集和搜狗。

合集接口是微信内部用的，没有公开文档。号主换了合集，或者微信改了这个接口，这一条会读不到，这时自动退回搜狗。

`requires` 留空，没装逛网页也能安装。合集和 RSS 都没取到、又没打开逛网页时，取图会直接说明：请安装并打开「逛网页」，或改填 RSS 地址。

## 怎么用

1. 安装后在模块设置里确认开始时间、截止时间，以及私聊、群聊接收号码。
2. 私聊、群聊分开填，只写数字。私聊留空发给主人；群号留空则不发到群。手动命令仍回复发出命令的那个聊天。
3. 自动发送只在插件启用、不是演练模式、并且「每天自动发送」开着时进行。
4. 在聊天里发 `/moyu`，或直接发设置里的触发词。默认整句 `摸鱼人日历`、`摸鱼日历`、`摸鱼` 都可以，前面的斜杠可有可无。发出图片后不再另回一句确认；失败时仍会说明原因。后面加「状态」只看任务。只有主人能这样发。

## 用到的网络地址

| 地址 | 谁去访问 | 目的 |
|---|---|---|
| `weixin.sogou.com` | 本模块 | 按「摸鱼人日历 + 当天日期」搜索文章。请求头使用浏览器标识，否则搜狗经常不返回结果页 |
| `mp.weixin.qq.com/mp/appmsgalbum` | 本模块 | 读「摸鱼人日历」合集的文章列表。请求里只有账号标识和合集编号，不需要登录 |
| `mp.weixin.qq.com/s` | 本模块（合集给的文章页），或逛网页（搜狗给的临时链接） | 打开当天的文章 |
| `mmbiz.qpic.cn` | 本模块 | 下载日历图。地址里的 `/640` 会换成 `/0` 以取原图 |
| 设置里的 RSS 地址 | 本模块 | 仅当填写了才访问。默认拒绝本机、内网和带账号密码的地址；打开「允许内网 RSS」后放行本机和内网。RSS 正文最多保留末尾 10MB（新的文章排在后面），全部读到 50MB 还没完就不再读 |
| RSS 地址所在的服务器 | 本模块，仅当 RSS 把图片改成自己服务器上的地址时（we-mp-rss 默认这样） | 下载日历图。只认和 RSS 地址同一个来源的图片地址，别的站点不要 |

发给这些地址的只有搜索词、合集编号或 RSS 请求，没有聊天内容、QQ 号或插件 Cookie。搜狗当次下发的 Cookie 只放在内存里跟完这一次跳转，不写入数据目录。日志里不记录 Cookie 和带签名的文章地址。

## 数据存放

写在插件分配的数据目录（`plugins-data/aurabot/modules-data/moyu-calendar/`）：

- `daily-state.json`：今天试了几次、哪些聊天已经发过、是否完成或无更新，以及最近一次取图的日期和来源
- `YYYY-MM-DD.png`（或 `.jpg` / `.webp`）：当天的日历图，保留 14 天

这些都不随模块分发。

## 版权

日历图的版权属于公众号「摸鱼人日历」。模块不打包、不修改这些图片，只在用户自己的机器上转发，并默认附上一句「来源：公众号 摸鱼人日历」。附言可以改掉或留空。

## 权限说明

`module.json` 的 `capabilities`：

- `network`：访问上面列出的地址
- `filesystem`：读写自己的任务记录和图片缓存
- `plugin-config`：读取插件是否启用、是否演练模式、主人 QQ，用来决定要不要自动发、发给谁。不修改插件配置，也不读取账号 Cookie

没有 `process` / `dynamic-code`。不启动外部程序；文章页里执行的是一段固定的只读脚本，由逛网页模块跑在页面里，不在本模块里 `eval`。

面板用到两个本机接口：`/status` 只读；`/clear` 只收同源的 POST，并且请求体要带 `confirm: true`，别的网页借不到。清除只删今天的缓存图和今天的进度记录，不动其他日期的图。

## 安装

面板「模块市场」搜索「摸鱼人日历」，或把这个文件夹放进 `plugins-data/aurabot/modules/moyu-calendar/`。
