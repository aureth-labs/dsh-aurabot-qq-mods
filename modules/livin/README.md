# 过日子 · livin

给 [Aurabot](https://github.com/aureth-labs/dsh-aurabot-qq) 用的模块：**她自己的一整天**。无聊了从乐子清单里自己挑一件事做——刷抖音、玩一局小游戏、逛B站、写小说、发呆都行；做完看心情分享给你；下次什么时候醒，也她自己定。不是任务清单，是生活。

## 她怎么"醒"

15 分钟看一眼，依次过五道闸（每道闸的判定都留痕，面板能回答"她今天为什么没醒"）：

1. **空档**：距你私聊她最后一条消息 ≥20 分钟才可能醒（群聊热闹不算）
2. **自排程**：没到她自己定的下次时间就继续待着；她定得不靠谱（<30 分钟或 >3 小时没醒）才兜底接管
3. **概率**：空档到了也只有 40% 真的醒——有时候无聊就发发呆
4. **额度**：每天上限 8 次（可调），只算真正完成的
5. **睡觉时段**：默认 01:00–08:00 不醒

醒来后 `api.think` 把乐子清单（带兴趣权重）+ 上次进度给她，**她自己挑**，明确允许"今天不想动"。

## 兴趣权重（时间衰减，不是禁令）

刚做过的乐子兴趣打折，随时间自然回升：<1 小时 ×0.5 → 1–3 小时 ×0.7 → 3–6 小时 ×0.85 → >6 小时满血。连着刷抖音会被自然压住，睡一觉起来又想刷了——不禁止任何事。

## 分享

做完 70% 概率主动说一句（她的语气），30% 自己偷偷乐；两次分享至少隔 90 分钟，同一乐子一天最多主动说 2 次。发送三态分开记：sent / failed（重试一次）/ 被治理拦（不计数不重试）。

## 乐子池

| 乐子 | 执行方式 | 依赖 |
|---|---|---|
| 刷会儿抖音 | 本机触发 douyin 模块的自治刷流（她看完自己决定分享） | douyin 模块 |
| 玩一局小游戏 | `play()`，成绩自动进心情 | minigame 模块 |
| 去B站逛逛 | `run({force:true})` | 内置 bili |
| 写小说 | `api.think` 连载，存档续写（`《书名》`自动提取） | 无 |
| 喝口水 / 发呆 | 纯生活小事 | 无 |

缺哪个模块就少一种玩法，程序照常跑。面板里每项可以单独"歇了"。

## 给她的工具

- `joy_list`：看看自己现在有哪些乐子、对什么最有兴趣
- `joy_do`：自己来一次（额度闸仍生效）

## 面板

「已安装 → 过日子」：顶部有**总开关**（▶ 让她自己过日子 / ⏸ 暂停），开了她才会在空档自己找乐子；下面是今天玩了几次、下次几点醒、连载写哪了、乐子开关，以及**她这一天的完整痕迹**（每道闸的判定都在——"她今天为什么没醒"一眼看穿）。总开关和模块设置里的「让她自己过日子」是同一个值，两边改都生效。

## 存储

- `modules-data/livin/livin.json`：乐子池 + 调度状态 + 历史（保留 7 天）
- **小说全部存 Word**（`modules-data/livin/novel/`）：
  - **短篇**：一整个《书名》.docx，每轮续写后重写全档
  - **长篇**：一章一个《书名》第N章 章节名.docx——她每轮动笔前先**检索书架**（列出写过的章节文档、读最新一章的结尾），接得上剧情才往下写
  - 模式在面板「小说」卡片或设置页「小说模式」切换，随时可换，已写的文档都在书架上

## 设置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | 关 | 装上不动，面板手动开 |
| idleMinutes | 20 | 主人多久没找她才可能醒 |
| wakeChance | 40 | 空档到了真醒的概率 % |
| dailyMax | 8 | 每天自己玩几次上限 |
| quietStart/quietEnd | 1/8 | 睡觉时段 |
| shareGapMin | 90 | 两次主动分享最小间隔 |
| shareChance | 70 | 做完主动分享的概率 % |

## 测试

`test/index.test.mjs`（node:test）：五道闸逐道、权重衰减曲线、自排程钳制、分享三态、额度语义、四个执行器、面板接口。模块导出 `{ tick, wake, st, set }` 供测试直调。
