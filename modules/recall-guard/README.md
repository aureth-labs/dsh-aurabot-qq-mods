# 撤回守卫（recall-guard）

三条防线一起守：**进来**的消息先等几秒，撤回了就不回；**出去**的话说错了，机器人自己能收回来；对方**打错字**时，按同音猜他本来想说什么。

版本：1.2.2。

## 功能一览

- **撤回拦截**：消息到达后先缓冲 0.5–6 秒（默认 3 秒），期间收到好友撤回或群撤回，就不把这条消息交给对话。
- **主动撤回**：机器人发现自己说错、答错人、发错对象时，可以调用 `recall_msg` 收回；主人引用它的消息说“撤回/收回去/刚刚那条不对”，也会撤被引用的那条。
- **手动兜底**：主人可以引用消息发 `/撤回`，或直接发 `/撤回 消息ID`。
- **权限分层**：撤自己受开关控制；撤别人必须主人开口并打开对应开关，群里还要求机器人是管理员。
- **同音纠错**：对方用拼音输入法打错字（“我门”“以经”“晚尚”）时，按 2–3 字片段查词库，找到一字之差、同音的常用词就提示本意。
- **本地词库**：内置 52864 条 2–3 字词、500 词频阈值，运行时不联网；同一句最多提示 3 处，每处最多 3 个候选。
- **面板可调**：等待秒数、自身撤回开关、他人撤回开关、同音开关、提示方式、候选数量都能在面板改；还能试一句话看提示、看累计触发和最近记录。
- **隐私克制**：只在内存保留最近消息 ID 和引用 ID，不保存正文；落盘只有本机 `homophone-stats.json` 统计。

## 一、挡住“回了已撤回的消息”

群里和私聊都常见这样的场面：有人发了一句又撤回，机器人刚好在这个空档回了话，读起来像在自言自语。这个模块在消息到达和进入对话之间插一小段缓冲，期间收到撤回事件就把这条消息撤掉。

- 只处理**好友撤回**和**群撤回**两种通知，其他通知放行。
- 撤回记录只在内存里留 10 秒，不写盘、不堆积。
- 判断靠 `message_id` 精确匹配，不同会话同 id 也不会误伤。
- 等待期间的新消息互不影响，各自计时。

## 二、机器人能把说错的话收回来

模块提供一个 `recall_msg` 工具：

- 自己说错了、答错人、把不该说的说出去了 → 自己撤。
- 主人引用机器人某条消息说“撤回/收回去/刚刚那条不对” → 撤被引用的那条。
- 主人也可以手动兜底：引用那条消息发 `/撤回`，或者 `/撤回 消息ID`。

权限：

| 撤谁 | 需要什么 |
|---|---|
| 机器人自己发的 | 受「机器人能撤回自己发的消息」开关控制 |
| 别人的消息 | 必须主人开口，且打开「主人可以让机器人撤回别人的消息」；群里还要求机器人是管理员 |

## 三、错字按同音理解

对方用拼音输入法打错字时（「我门」「以经」「晚尚」这类），机器人收到的内容里会多一句同音提示，让它按发音理解，而不是照着错字硬读。

判断方式：语句里每 2~3 个字取一段，如果这一段**不成词**，但换成**一字之差、同音**的组合能成一个常用词，就提示“大概是另一个词”。

- 词库来自 jieba 的 `dict.txt`，只保留 2~3 字的词（词频 ≥ 30，共 52864 条），另建“拼音 → 常见词”索引（词频 ≥ 500）。
- 词库压成 `homophone-data.json`（约 890KB），随模块提供，运行时不联网。
- 同一句最多提示 3 处，每处最多 3 个候选（可调）。
- 提示只加在机器人**这次**收到的内容里，不改对方原话、不改聊天记录。

实测：`我门→我们`、`以经→已经`、`晚尚→晚上`、`他门→他们`、`这见→这件`、`在说→再说`、`被字→被子` 都能命中；正常句子（如“你在干嘛”“这件事我记下了”）不触发。极少数低频词仍可能被误提示（如“锅吧→锅巴”），提示措辞是“大概是”，机器人可以自己判断。

## 安装

把整个 `recall-guard` 目录放进 Aurabot 的 `modules/`，启用即可，不需要命令，也不需要 `npm install`。拼音库已内嵌在 `lib/pinyin`，词库在 `lib/homophone-data.json`。

要求：Aurabot API 1，`minPluginVersion` 1.2.0；平台为 QQ（OneBot 11）。

## 设置

- **等待撤回时间（秒）**：默认 3，范围 0.5–6，步进 0.5。等得越久拦得越准，但机器人开口也越慢。
- **机器人能撤回自己发的消息**：默认开。关掉后只剩拦截能力。
- **主人可以让机器人撤回别人的消息**：默认关。要撤别人说的话才打开。
- **错字按同音理解**：默认开。关掉后不再加任何同音提示。
- **同音提示方式**：默认「只在可疑时提示」；改成「每条都提醒」则每条文字消息都附一句通用提示。
- **每个错字给几个候选**：默认 3，范围 1–5。

面板「总览」页最下面有本模块的卡片，可以直接开关、粘一句话试效果、查看累计触发次数和最近十条记录。

## 权限与数据

- 能力声明：`filesystem`。不联网。
- 读取：模块自带的 `lib/homophone-data.json`、`lib/pinyin`。
- 写入：只写插件数据目录下的 `homophone-stats.json`（触发统计）。
- 内存中只保留最近消息的 `message_id` / 引用 ID，不保存消息正文；最多 300 个会话，退出即清空。

## 已知限制

- QQ 只允许撤回**两分钟**内的消息，超过就撤不动了，模块会把失败原因返回。
- 群里撤别人的消息要求机器人是管理员；不是管理员时会明确拒绝，不会假装成功。
- 对方如果撤回得比等待时间更慢，这条消息已经进入对话，模块拦不住。
- 每条消息都会额外延迟设定的秒数，长对话里会感觉机器人反应慢半个拍子；这是设计取舍，不是故障。
- 同音判断依赖词库：词库里没有的口语词（比如“干麻→干嘛”当“干嘛”词频很低）可能漏判；也不要指望它纠正语法错误或整句胡说。
