# fish-draw-prompt · 生图提示词（三步走）

> ⚠️ **这是给别的模块用的源代码模块，不是给用户直接开的。**
>
> 从市场装上之后，**面板里不会多出一个「生图提示词」页面** —— 它没有 UI，也没有设置项。
> 它做的事只有一件：让多个生图入口共用同一份提示词。
>
> 如果你想要的是「能画图的功能」，那不是这个模块 —— 那是插件自带的 `imagegen`。
> 这个模块是给**写模块的人**用的：`api.use('fish-draw-prompt')` 拿到拼提示词的方法。

**不自己画图，也不碰任何 API** —— 纯函数，`capabilities: []`。

## 它解决什么问题

同一个角色、同一个画图需求，往往有几个入口（聊天里画、换头像、说说配图、发帖配图）。
如果每个入口各写一份提示词：

```
qq_draw_image   → 104 行
换头像          → 110 行（几乎一样的字，抄一遍）
说说配图        →  41 行（又抄一遍）
发帖配图        →  手抄一份关键特征（第四遍）
                    ↑
              改一处，漏三处
```

这个模块把公共部分收成**一份源代码**，各入口只传自己那点差异。

## 三步走是什么

让 AI 角色画「有她自己」的图时，直接说「画个我」是画不准的。所以分三步：

```
① 这张画里有你自己吗？
     A. 有 → 第二步
     B. 没有 → 直接写描述（画猫、画风景、画物件都行）
     答一行：`这张画：有我自己` / `这张画：没有我自己`

② （只有 A 才做）用哪张参考图
     self:1 ~ self:4（同一个角色的四种画风）
     答一行：`参考图：self:2`

③ 写画面描述
     22 类可选元素（动作/视线/手部/表情/服饰/光/构图/画风…）
     挑着写，不用全上
```

## 「用途」要排在三步走前面

她得先知道**这张图是拿来干什么的**（换头像？说说配图？随手画？），再决定画什么。

```
avatar → 换头像：会被缩得很小，所以主体要清楚、别太小
                 画人就让脸占大点，画猫画物件就把主体放中间
chat   → 聊天里画：换头像/说说配图/发给他看/表情包/随手画，五种都说
qzone  → 说说配图：要跟文字搭，构图宽一点、有场景
```

注意 `avatar` 那句：**不规定主体是什么**。她头像可以是一只猫。

## 用法

```js
const dp = api.use('fish-draw-prompt')

// ① 拼提示词
const prompt = dp.buildDrawPrompt({
  scene: 'avatar',              // avatar / chat / qzone
  context: ['你要给自己换个头像。', '心情 70 分'],   // 这个入口独有的上下文
  wantParseFormat: true,        // 要不要她按三行回
})

// ② 解析她回的三行
const { hasSelf, ref, prompt: body } = dp.parseDrawAnswer(text)
//   hasSelf  这张画里有没有她自己
//   ref      她自己选的参考图（self:1~4 / null）
//   prompt   摘掉标记行之后的画面描述

// ③ 关键特征（代码生成 prompt 的场景直接用）
console.log(dp.ANCHOR)
// → 深海蓝渐变长发（深蓝到发梢浅蓝）、头顶呆毛、鲸鱼鳍状耳朵、鲸鱼大尾巴、蓝色大眼睛
```

## 为什么「关键特征必须写」

实测过两组对照：

```
A（带参考图 + 提示词写「长相不用写」）→ 两张都没有尾巴
B（同样参考图 + 关键特征写全）        → 尾巴都回来了
```

**参考图是弱提示，文字是强指令。** 一句「不用写」能压掉一条大尾巴。

但也不能反过来把衣服和画风写死 —— 那两样该由「这一张」决定。
所以分两类：

```
关键特征（她是谁）→ 必须写
衣服、画风        → 这一张自己定
```

## 换画风时的写法

```
「把参考图里这个角色转成 <目标画风>，保留她的深海蓝渐变长发、头顶呆毛、
鲸鱼鳍状耳朵、鲸鱼大尾巴、蓝眼睛和整体配色，只换画风。」
```

**只写「变成油画/写实」不够** —— 会把角色一起改掉。说清保留什么才稳。

不用保留原图的姿态和构图，那些由这一张自己写。

## 画非人物时

写清楚**主体是什么**（毛色、材质、大小、摆在哪），别让人误解成「有人站在旁边」。

但**不需要专门喊「没有人物」** —— 实测不写也不会无端塞人。
（早先那条「必须写『画面里没有人物』」是错误归因：
真正让人物出现的是 `stylePrompt` 把固定长相强制注入到每张图前面，不是因为没写这句。）

