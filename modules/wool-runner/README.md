# 薅羊毛任务中心

Aurabot 用户扩展模块，参考青龙面板的订阅、环境变量、定时任务和日志模型，让用户在 Aurabot 里管理第三方签到脚本。

## 内置订阅

- https://github.com/cyuni1996/jdpro
- https://github.com/hex-ci/smzdm_script
- https://github.com/smallfawn/QLScriptPublic

可以添加、编辑、切换 Git 源和分支、同步、删除订阅，并浏览其中的脚本。

**同步会直接写入定时任务。** 点「立即同步」后，订阅中识别到 Cron 的脚本会自动登记为定时任务，立刻出现在「定时任务」页签（新增订阅时保存后也会自动同步一次）。同步是幂等的：已存在的任务不会重复添加；脚本里的 Cron 变化会更新任务表达式。新任务仍**默认停用、未审批、不注入凭据**，需要逐条确认后才运行——自动建任务不等于自动执行，这条安全边界不变。若不想自动写入，在订阅编辑里关闭「同步后自动写入定时任务」即可。

## 安全模型（重要）

这个模块会用 node/python/bash 执行来自外部 Git 仓库的代码，属于高权限操作。为了把风险控制到最小：

1. **执行总开关默认关闭。** 关闭时任何任务（手动或定时）都拒绝运行，只能管理订阅、环境变量和扫码。
2. **任务默认停用、未审批、不注入任何凭据。** 添加任务不等于授权执行。
3. **执行前必须逐次确认。** 手动运行和启用定时都会弹出确认，展示仓库地址、分支、commit 和脚本路径。
4. **审批绑定来源与内容指纹。** 审批记录 `{url, branch, commit, file, sha256}` 的指纹；同步后 commit 变化、源码被改、订阅地址或分支变化，都会自动撤销审批并停用任务，必须重新确认。这防止「订阅源被篡改后自动执行」：即使上游推送了恶意更新，旧审批也会因 commit/sha256 不匹配而失效，定时任务不会带着旧授权跑新代码。
5. **凭据按任务授权。** 环境变量不会全量注入子进程；只有用户在「变量授权」里明确勾选的变量名才会传给该任务。未授权的任务拿到的是干净的系统环境。
6. **宿主机环境隔离。** 子进程不继承 DSH/Electron 的完整环境（API Key、账号配置等），只注入白名单系统变量（PATH、TEMP、HOME 等）加授权凭据。
7. **资源限制。** 单任务超时（默认 30 分钟）、最大并发（默认 2）、Node.js 堆内存上限（`--max-old-space-size`，默认 256 MiB）、日志 1 MiB 截断。
8. **路径边界。** 脚本路径经 `realpathSync` 解析后必须位于订阅仓库目录内，拒绝符号链接逃逸；非普通文件拒绝执行。
9. **订阅地址不允许内嵌凭据。** 带用户名/密码/令牌的 URL 会被拒绝，防止令牌泄露到状态文件。
10. **同步不执行任何代码。** 只做 `git clone/pull`，不运行 `sub_after`、不安装依赖、不执行脚本。
11. **日志脱敏。** 写入和读取日志时隐藏所有已保存的环境变量值及常见 Cookie/Token 字段。
12. **QQ 侧只读。** `/羊毛` 命令和 `wool_tasks` 工具只能查看任务状态，不能运行脚本、修改定时或读取环境变量；执行只能在面板里由主人确认。

## 使用

1. 在面板打开「允许执行脚本（总开关）」（确认风险后）。
2. 在「订阅源」中同步仓库。同步只下载源码；识别到 Cron 的脚本会自动登记为定时任务（默认停用）。
3. 在「定时任务」中确认审批并启用需要跑的任务，或在需要时手动添加脚本（默认停用）。
4. 用「变量授权」给任务勾选需要的环境变量（默认不注入任何凭据）。
5. 点「确认并运行」手动执行一次，检查日志。
6. 确认无误后打开定时开关（会再次确认并记录审批）。

支持 JS/MJS/CJS、Python、Shell；支持 5 字段和 6 字段 Cron。

## 运行环境

- Git 必须可用，用于订阅同步。
- Node.js 默认使用 DSH 当前运行时（`process.execPath` + `ELECTRON_RUN_AS_NODE=1`），也可在设置里指定本机 node 路径。
- Python 和 Bash 默认从 PATH 查找，也可在设置里指定绝对路径。
- 第三方仓库的依赖需要在对应 `modules-data/wool-runner/repos/<订阅>` 目录中按上游说明手动安装。模块不会自动执行依赖安装脚本。

## 联网目标

- `github.com`：用户主动同步时，通过 Git 下载所选订阅源码。
- `qr.m.jd.com`：京东官方二维码生成与扫码状态查询。
- `passport.jd.com`：京东官方扫码票据校验；仅允许继续访问 `*.jd.com` 的官方 HTTPS 跳转。
- 用户手动运行或启用定时后，第三方脚本可能访问其各自服务；这些域名以脚本源码为准，需在添加任务前审查。

扫码凭据只写入本机环境变量，不会发送到上述官方登录域名之外的服务。

## 数据存储

所有数据在 `modules-data/wool-runner/`：

- `state.json`：订阅、任务与审批记录（不含凭据值）
- `env.json`：环境变量（0600 权限，仅当前用户）
- `runs.json`：运行记录元数据
- `repos/<id>/`：订阅源码
- `logs/<taskId>/`：运行日志（已脱敏）

## QQ 命令

- `/羊毛 列表`：查看任务状态（只读）

模块也提供仅主人私聊可用的 `wool_tasks` 工具，只能列出任务状态，不能运行脚本、新增任务、修改定时或读取环境变量。
