# 群聊特别处理（group-guard）

给指定的群补一段背景说明，并给她「会不会开口」加一个硬上限。

## 为什么需要它

有些群里一半是别人的机器人，大家开着同一套插件互相聊天。那种环境里靠「插话概率」是拦不住的：

```
她回一句 → 别的 AI @ 她 → @ 属于「必回」→ 她回一句 → 对方又 @ 她 → ……
```

这里有两段路会让她一直说下去，而且都绕开了常规限制：

**第一段：`must`（必回）** —— 被 @、被引用、被叫到名字、刚说完被追问，都算必回。必回不受插话概率、冷却时间、每小时上限、连发刹车任何限制。

**第二段：`engaged`（正聊得起劲）** —— 说完一句后的 3 分钟内，群里再有消息她就会接着聊。源码里这条的注释写得很直白：

```js
// 已经加入了这个话题：接着聊（每段看完再回，不受冷却和每小时上限限制）
```

`engaged` 只有 `engagedMax`（默认 6 次）一个刹车，而且**每说一句就加一**。实际日志里它才是主力——某天鱼群 `engaged` 触发 **123 次**，`must` 被限流拦只出现 **1 次**。

所以：**@ 和引用只是点火，烧起来靠 `engaged` 一句接一句。** 只拦 `must` 等于没拦，这个模块两段都拦。

| 做什么 | 怎么做 |
|---|---|
| **补背景** | 每轮往上下文塞一句「这个群是什么情况」，让她自己知道该用什么姿态 |
| **限流** | 同一个群里，N 分钟内最多开口 M 次（`must` 和 `engaged` 都算），超了就当没看见 |

## 配置

面板「扩展 → 群聊特别处理」，一行一个群：

```
群号 | 说明 | 选项
```

三个部分都可以省略。

**纯说明**（不限流，只告诉她这个群是什么）：

```
123456789 | 这个群里基本都是别的 AI 机器人，说的话都是程序生成的，别当成需要认真陪伴的对话
```

**纯限流**（不加背景）：

```
123456789 | | 必回 5 分钟 2 次
```

**两个都要**：

```
123456789 | 这个群里基本都是别的 AI 机器人 | 必回 5 分钟 2 次
```

### 选项写法

| 写法 | 意思 |
|---|---|
| `必回 5 分钟 2 次` | 5 分钟内最多开口 2 次（默认值）。写法沿用「必回」两个字，但 `engaged` 也会一起计入 |
| `必回 10 分钟 1 次` | 更严：10 分钟只准回一次 |
| `只认@` | 只有真的被 @ 才算必回；别人引用她、叫她的名字都降成普通插话判断。**只作用于 `must`**——`engaged` 是她自己接着聊，没有「被叫到」这回事，拿它去卡会误伤 |

`只认@` 和次数限制可以一起写：`只认@ 必回 10 分钟 1 次`。

行首加 `#` 是注释。

## 默认配置

**空的。** 每个人的群不一样，预置别人的群号只会误导，所以第一次装上是没有任何规则的，要自己填。

## 它管不到什么

- 普通插话（`interject`）——那个由插件的插话概率、冷却、每小时上限自己管，本来就是限的
- **没配规则的群完全不受影响** —— 这个模块限制的是「在机器人扎堆的群里使劲刷屏」，不是「正常聊天不许接话」
- 私聊——完全没有影响
- 不改变她的说话风格，只是让她知道「这个群是什么情况」

## 兼容性

- 需要 AuraBot 1.2.0 及以上
- 不读写文件、不联网、不启动子进程（`capabilities: []`）
