# 小游戏合集（minigame）

她自己会玩小游戏——2048、贪吃蛇、扫雷。自己定时来一局，输赢影响心情；主人在面板里能实时看她下棋。

## 她会玩什么

| 游戏 | 要点 |
|---|---|
| **2048** | 标准 4×4，贪心策略；分数进战绩 |
| **贪吃蛇** | 12×12 场地，会绕圈找食物 |
| **扫雷** | 9×9 / 10 雷，按数字推理，会标旗 |

每走一步记一帧，面板可以**实时看**她下棋，也可以**回放上一局**（2048/蛇 40ms 一帧，扫雷 120ms 一帧，扫雷慢一点看得清）。

## 自动玩

默认每 30 分钟自己挑一局（间隔可调 10–720 分钟）。玩完：

- 成绩记进战绩（每个游戏单独记总局数 / 赢的次数 / 最好成绩）
- 输赢通过内置 `mood` 模块**给她加减心情**（"自己玩2048赢了"）
- 2 小时内会给她一句轻量上下文，想提就自然提一句，不想提就不提

**总开关**：面板「已安装 → 小游戏合集」顶部的「▶ 让她自己玩 / ⏸ 暂停」，和设置页的「让她自己玩」是同一个值。关掉只停自动玩，手动叫她玩不受影响（面板按钮、工具、命令都还能用）。

> 装了 [过日子（livin）](../../../) 的话，建议把这个自动玩关掉，交给 livin 的乐子清单统一调度——不然两套定时器都在让她玩游戏。

## 怎么叫她玩

- **面板**：点「玩 2048 / 玩贪吃蛇 / 玩扫雷 / 随便玩一局」
- **工具**：`mini_game_play`（她能自己在聊天中调用，比如你说"你玩会儿游戏吧"）
- **命令**：`/游戏`、`/游戏 蛇`、`/游戏 扫雷`、`/玩一局`

## 面板接口

| 路由 | 用途 |
|---|---|
| `GET /state` | 总局数、胜负、每游戏战绩、最近 10 局、间隔与开关 |
| `GET /live` | 当前对局帧序列（面板 500ms 轮询看现场） |
| `GET /play?game=2048\|snake\|minesweeper` | 让她当场玩一局 |
| `POST /enabled` `{ on }` | 总开关 |

## 存储

`modules-data/minigame/stats.json`：总局数、胜场、每游戏战绩、最近几局（保留条数可配 5–100）。

## 能力与安全

- `capabilities`: `filesystem`（自己的数据目录）、`plugin-config`（设置）、`plugin-internals`（调内置 `mood` 模块加心情）
- **不联网**、不发消息、不上传任何数据
- 默认「让她自己玩」开着；不想要就面板一键关

## 测试

`test/index.test.mjs`（node:test，mock api，零联网）：三个游戏都能下完并给出结果、战绩累计、开关路由、自动玩的间隔闸。
