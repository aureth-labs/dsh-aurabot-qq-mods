# 抖音看直播（kanzhibo）

用一台**独立浏览器**（Edge / Chrome，独立登录资料）经 CDP 挂在抖音直播间：进房、发一条定制评论、续粉丝团灯牌、在 QQ 私聊里命令她发弹幕、开播主动提醒。
所有会动页面/花钱的动作都先验面板、动作前可截图确认、动作后回读验证。

- 版本：**1.3.0**
- 分类：`platform`（逛平台）
- 能力：`network` / `filesystem` / `process` / `plugin-config` / `plugin-internals`
- 许可：MIT

---

## 1. 它做什么

1. **进直播间**：用一台专用浏览器（自己的 profile，不动你日常浏览器）通过 CDP 挂进直播间；给直播间地址最稳（`live.douyin.com/<房间号>`、`www.douyin.com/follow/live/<房间号>` 都认），给主播主页会自己找「直播中」点进去。
2. **进房评论**：页面真正渲染出评论框后再发一条你定的评论，一天一次（全局每天最多一条）。
3. **续粉丝团灯牌**：先读面板判断今天送没送；没送才点「送灯牌 / 赠送 / 点亮」。**半自动**时先把要点的位置截图发你私聊，等你回 `/看直播 确认` 才点；点完按面板 `今日任务 X/3`、`今日第 N 位送灯牌`、聊天播报验证。
4. **私信命令发弹幕**：`/看直播 说 要说的话`（评论/弹幕/发 同义）→ 在当前直播间原样发出；只认主人本人的 QQ 私聊；50 字上限、10 秒冷却；发完回读聊天区做二次验证。
5. **开播提醒 / 日报**：目标是主播主页时，主播一开播主动私聊说一声并进房挂着；收工时和每天第一次进房后私聊一条日报。
6. **操作记录**：每一步写本地 `modules-data/kanzhibo/worklog/YYYY-MM-DD.jsonl`，面板「操作记录」卡可看最近几步，`/看直播 记录` 也能看。

> 1.3.0 起不再写「工作间」会话（`opsSession` 已停用，不再每 15 秒跑模型回合）。

---

## 2. 运行要求

- Windows（浏览器路径默认找 Edge/Chrome；也可在面板手填）。
- 已安装 Edge 或 Chrome。
- 一台能登录抖音的账号（专用 profile 里登录一次，之后 Cookie 持久保存）。
- Aurabot 插件 **1.2.0+**；Node **22.2+**（模块自带 `engines: node>=22`）。

---

## 3. 安装与启用

1. 把 `kanzhibo/` 放进 Aurabot 数据目录的 `modules/` 下（或从模块市场安装）。
2. 打开 Aurabot 面板 →「平台」→「抖音看直播」。
3. 首次用：填直播间地址 → 点「扫码登录」在专用浏览器里登录抖音 → 打开「总开关」。

## 4. 配置项

| 键 | 名称 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | 总开关 | 关 | 关掉后什么都不做：不进房、不评论、不送灯牌、不送礼，浏览器也关掉 |
| `target` | 直播间或主页 | 空 | 直播间链接最稳；主播主页会找「直播中」进 |
| `schedule` | 按时间段挂 | 关 | 开着 = 只在时段内挂；关 = 不限时段 |
| `startTime` / `endTime` | 开始/结束时间 | 20:00 / 23:30 | 24 小时制，可跨午夜 |
| `checkSec` | 多久看一次（秒） | 120 | 30–1800；改完立即生效，不用重载 |
| `liveCommentOn` | 进房发评论 | 关 | 打开后全局每天最多一条 |
| `liveComment` | 评论内容 | 空 | 多行只发第一行 |
| `commentDelaySec` | 等几秒再发 | 8 | 等画面/评论框出来 |
| `renewBadge` | 续粉丝团灯牌 | 关 | 真会去点左上角；半自动先截图确认 |
| `badgeDelaySec` | 等几秒再续 | 30 | 越早越容易点偏，宁晚不早 |
| `badgeNickname` | 自己的直播间昵称 | 蔚 | 用来在聊天区认出「自己送出了灯牌」那条播报 |
| `badgeJudgeV2` | 灯牌判据 v2（实验） | 关 | 按面板结构判断已送/可送；未覆盖的状态会拒绝自动点。默认关，确认稳定再开 |
| `giftByDm` | QQ 私信送礼 | 关 | 打开后你在私聊里明说「送个小心心」她才会真送；群里永远不送。**送礼永远半自动（必须你确认），无人值守也不会自动送礼；无人值守只允许灯牌自动** |
| `semiAuto` | 动作前先问我 | 开 | 开 = 续灯牌/送礼前截图发你，回 `/看直播 确认` 才点；关 = 直接点（仍过命中校验） |
| `confirmSec` | 等你多少秒 | 90 | 到点没收到「确认」就自动撤销，不点 |
| `browserPath` | 浏览器路径 | 空 | 留空自动找 Edge/Chrome |
| `minuteReport` | 进房时通知我 | 关 | 进房后私聊说一声 |

## 5. 命令（/看直播）

`/看直播`（别名 `/kanzhibo`）

| 命令 | 作用 |
|---|---|
| `/看直播 开` / `关` | 打开/关闭总开关（关＝停定时器、撤待确认、关浏览器） |
| `/看直播 状态` | 看开没开、时段、模式、目标、进房评论、当前地址、待确认、最近一条（今日灯牌/弹幕冷却看「自检」） |
| `/看直播 进` | 立刻进房 |
| `/看直播 收工` | 撤待确认、关浏览器，半小时内不再自己进 |
| `/看直播 灯牌` | 手动续一次灯牌（清「今天已放弃」标记；若本房今天点过未确认会拒绝，确认没送后改发 `灯牌 强制`） |
| `/看直播 灯牌 强制` | 恢复入口：先判今天已送则拒绝，未送才清 attempt 重点一次（半自动仍问确认） |
| `/看直播 换 <房间号或链接>` | 快捷换目标主播 |
| `/看直播 说 <内容>` | 在当前直播间原样发一条弹幕（评论/弹幕/发 同义） |
| `/看直播 记录` | 看最近 20 步操作记录 |
| `/看直播 确认` / `取消` | 半自动：确认/撤销待点击的动作 |
| `/看直播 自检` | 体检单：浏览器、profile、CDP、视口、时段、今日评论/灯牌、打法、待确认、最近日志 |

## 6. 她自己的工具（QQ 里自动用）

| 工具 | 权限 | 用途 |
|---|---|---|
| `kanzhibo_status` | 任何人（群里只给状态） | 看现在挂没挂、在看谁（群里不露在看谁） |
| `kanzhibo_enter` | 主人私聊 | 进某人的直播间挂着 |
| `kanzhibo_stop` | 主人私聊 | 不看了，退出并关浏览器 |
| `kanzhibo_badge` | 主人私聊 | 续一次粉丝团灯牌（走本模块确认/命中/日志链路） |
| `kanzhibo_gift` | 主人私聊 + 面板「QQ 私信送礼」开着 | 送一个礼物（花抖币，不撤回） |
| `kanzhibo_say` | 主人私聊 | 把主人给的原话原样发到直播间 |

> 灯牌不算礼物：续灯牌用 `kanzhibo_badge`，不要用 `kanzhibo_gift`。
> 禁止用其它浏览器/电脑操作工具（ego/browser/pwsh/远程桌面）直接去点抖音页面——会绕过日志和确认。

## 7. 灯牌判据（结构化骨架，默认关；真机样本部分已抓）

面板里：
- **可送（未送）**：出现「送灯牌」按钮 / `1钻，可得100亲密度` / `送1个"灯牌"`；
- **已送**：出现 `今日第 N 位送灯牌，连续 N 天`（按钮消失），`今日任务 X/3` 会涨；
- **恢复勋章**：出现「点亮粉丝团恢复勋章 / 点亮 (1钻)」（此态 AX 里没有"灯牌"二字，判据已兼容）；
- **未加入**：出现「1 钻石加入粉丝团」（此时不自动送）。

辅助证据：聊天区「<自己昵称>：送出了 …」播报（`badgeNickname`）。

`badgeJudgeV2` 默认**关闭**；结构化判据仍是骨架（代码 `verified=false`，仅部分真机样本），未覆盖态不自动点。该项以 `type:switch` 登记在 settingsSchema，自定义 panel.js 未渲染，可在设置页/配置文件打开试用。

## 8. 面板

「平台 → 抖音看直播」里是卡片式：总开关、抖音账号（扫码登录/检查登录）、浏览器窗口（显示/收起）、运行状态、进房评论、粉丝团灯牌、送礼、私信发弹幕、操作记录、风险提示。

---

## 9. 会访问哪里 / 能力说明

- **访问的网络目标**：抖音直播页面（`live.douyin.com`、`www.douyin.com`）；本机回环的 CDP 调试口（`127.0.0.1`）。不向无关地址发送 Cookie、消息等数据。
- **本机文件**：`modules-data/kanzhibo/`（专用浏览器 profile、`state.json`、`shots/` 截图、`worklog/` 记录）。
- **启动程序**：启动专用 Edge/Chrome 进程。
- **能力声明**（与源码扫描一致）：
  - `network`（联网）、`filesystem`（读写本机文件）、`process`（启动浏览器进程）、`plugin-config`（读写插件配置，含账号 Cookie）、`plugin-internals`（使用 `api.core` 等内部对象）。

## 11. 已知限制

- **主动私聊可能被宿主「出站策略」拦下**（只记 debug，不影响挂直播）。
- 半自动「等你确认」是**内存态**：模块重载/重启会让这次确认作废，她会私聊告诉你重发 `/看直播 灯牌`。
- 粉丝团面板是抖音 Lynx canvas，**部分文字只有无障碍树能读到**；判据依赖 AX。
- 浏览器窗口需要最大化/大视口才能完整显示面板（模块会自动最大化到当前屏幕）。
- 评论是**全局每天最多一条**（不是每个直播间一条）。
- 抖音改版可能导致定位失效；出问题先看 `/看直播 自检` 和日志。

## 12. 数据与文件

`modules-data/kanzhibo/`
- `live-profile/`：专用浏览器资料（登录态；不要手动删）
- `state.json`：今日评论/灯牌/attempt/ask/giveup、badgeRooms、sayLog、lastSayAt、tickAnchor、quietUntil、lastTarget、roomsToday 等；**待确认只在内存、重载即作废**
- `shots/`：动作截图（7 天滚动清理）
- `worklog/*.jsonl`：每步操作记录
