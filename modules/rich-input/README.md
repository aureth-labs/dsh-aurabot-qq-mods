# 看得见的东西 (rich-input)

让 Aurabot（大肥鱼）真正「看得见」聊天里的图片，不再只回一句「我这边看不清楚」。

她用的聊天模型如果是纯文本模型（或者插件没判出它能不能看图），图片原本只会变成一个「[图片]」占位；合并转发也常常只展开触发回复的那一条。本模块在**不改插件核心**的前提下，用公开的扩展接口补上这两块：

- **图片**：目标模型能看图就直接把图片交给它；看不了就先交给一个**能看图的模型**转成文字，再把文字交给她；主看图模型失败（报错 / 超时 / 没真看到图）会自动换**回退模型**再试一次。
- **合并转发**：收到就先把正文拉下来存好，之后不管隔多久、有没有被叫到，都能在她下次真的说话时展开或补给她看。

## 功能

- 私聊 / 群聊里别人发的图片、表情包（收藏表情 / 商城表情）都能处理。
- 引用里带图的消息，连引用的图一起看。
- 转发渲染成 `{昵称(QQ):内容;…}`；群里没被叫到、后来才补看的转发也能追上。
- 面板可挑「看图模型」和「回退模型」（下拉从 DSH 里能看图的模型动态生成），可自定义看图提示词、超时、每次最多几张图。
- 面板「试一下 / 体检」：逐个把能看图的模型试一遍，挑出真能用的；失败过的模型会记下来，自动挑选时先躲开。

## 设置

在模块的自动表单里：

| 设置 | 说明 |
| --- | --- |
| 图片交给模型 / 最多几张图 | 关掉就只剩「[图片]」占位；默认最多 4 张 |
| 展开合并转发 / 补上她没看到的转发 | 转发展开与「补课」开关 |
| 用哪个模型看图 | 只负责把图片转成文字，不参与她的对话；留空自动挑第一个能看图的 |
| 看图失败时换这个模型 | 主模型失败时再试一次；留空自动挑一个和主模型不同的 |
| 每个模型最多等几秒 | 超时就换下一个，默认 30 秒 |
| 看图时给模型的提示词 | 留空用内置的「尽量完整转成文字，只描述看到的」 |

看图模型是**逐版本审核**的：面板里手动换模型会立刻清掉它之前的失败记录；超时过的模型躲久一点（30 分钟），普通失败躲 10 分钟；同一张图的描述结果会缓存，不会每轮重复调用。

## 会访问哪里（隐私）

本模块**不直接连接任何外部网址**，所有对外交互都走插件已有的接口：

- **看图模型服务商**：把图片字节 + 你设置的看图提示词，通过插件的 `api.ask`（带 `images`）发给你在面板里选的模型。也就是说，**图片内容会发送给你所选模型对应的服务商**——请只用你信任的模型。文字描述会在提示词里注明「是转成的文字，不是原图」，让她按文字理解。
- **QQ 网关**：通过 `onebot.get_forward_msg` 按转发 id 拉取聊天记录正文（本地 / 你自建的 QQ 网关，不经过第三方）。
- 不读取聊天以外的文件、不联网下载代码、不启动外部程序、不群发消息或加好友。

## 与上游内建转发展开的关系

插件从 **1.3.0-beta.1 起**才内建了合并转发展开（`forward.expandEarly` / `forward.expandHistory`，两个开关默认都关）；更早的 **1.2.x 没有这个能力**，转发在她那里通常只剩一个「[合并转发]」占位符。

本模块的转发展开**作用于 1.2.x 及更早版本**，并向下兼容更新版本：

- **1.2.x**：上游无内建展开，本模块是唯一补上转发达内容的路。
- **1.3.0-beta.1+ 且内建开关关着**（默认）：本模块照常展开，行为不变。
- **1.3.0-beta.1+ 且主人手动开了内建展开**：上游会先把正文替换成 `[合并转发]{昵称(QQ):内容;…}`，本模块只认「裸」占位符（后面不跟 `{` 的），于是自动跳过已经展开过的那段，**不会重复展开、也不会互相覆盖**；看图部分照常工作。

相对上游内建实现，本模块多做了两件事：收到转发的**那一刻就预拉并缓存正文**（转发 id 会过期，上游只在展开时才拉），以及面板可见的「待补课转发」列表。两者叠加时按占位符格式自动去重，不需要二选一。

## 兼容性

- 支持插件 **1.2.1 及以上**（用到 `api.lib`、`api.ask`、`prompt` 钩子、`hub.canSeeImages`）。
- 面板测试接口在 1.3.0+ 会加 `access: 'panel'` 闸；1.2.x 会忽略该参数，功能不受影响。
- 与插件内置的图片处理是叠加关系：本模块只在「她看不见」时才接手，不影响本来就能看到图的会话。

## 权限

模块声明 `plugin-internals`（用 `api.lib` 读插件的内部源码、`api.core.hub` / `api.core.onebot`）。除此之外不碰文件系统、不启动进程、不执行动态代码。
