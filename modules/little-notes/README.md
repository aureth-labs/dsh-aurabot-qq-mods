# 小本本（little-notes）

她想到就记一笔的小本本——不是每天一篇的日记。

- **记什么**：他说过的话（said）、她答应的事（promise）、关于他的事（fact）、随手记（note）
- **怎么翻**：按人（about）、按事（关键词 / 标签）、按日子都能翻
- **主动权在她**：和被动沉淀的「记忆」不同，这是她**自己决定**什么值得记、自己动手翻的本子

## 给她的工具

| 工具 | 用途 |
|---|---|
| `note_add` | 记一笔：内容、类型、关于谁、标签、重要、日子 |
| `note_search` | 按关键词 / 人 / 类型 / 日期翻 |
| `note_recent` | 看最近记了什么 |
| `note_forget` | 删掉记错或过时的（仅主人） |

## 她怎么"主动"

- **当场记**：系统规则告诉她什么时机该记——他讲了喜好/计划/烦恼、她答应了什么、聊到日期生日、他说"你记住"
- **每晚整理**：23 点后（可在面板改）扫一遍当天聊天记录，让她自己挑值得记的补进本子，每本最多补 5 条，明显重复的跳过；凌晨 0–5 点会把"昨晚"补上
- **日子提醒**：记了 `due` 的事，当天早上 8 点后她会用自己语气主动提一句（只提一次）

## 主人命令

- `/本子 [N]` — 看最近的 N 条
- `/记 内容` — 手动记一笔
- `/翻 关键词` — 翻一翻

## 面板

「已安装 → 小本本」：一本**真的手账**——摊开的双页纸、装订孔、手写字（霞鹜文楷，离线回退楷体）、左右翻页（点页角或按钮）。点任意一条可以**划掉**（红色涂改线留在纸上，可恢复）或**标星**。下面还能替她补一笔。

## 存储

`modules-data/little-notes/notes.json`，按 `chatId` 分本（私聊一本、每个群各一本），每本默认最多 500 条，超了丢最旧的。**标了星（⭐）的条目不会被丢**——只有整本全是星标实在放不下时才丢最旧的星标；刚记下的那条永远不会被丢。**锁定的（🔒）绝对不丢**：就算本子超上限也保着，宁可暂时多几条；在手账页点条目 → 「🔒 锁死这条」即可。

## 安全

- `note_forget` 只在**本轮说话者全是主人**时放行（`turnSendersAllOwner`，防群友借权）
- 每个聊天独立一本，互相看不到；群里的本子只记群里的对话
