# 更新记录

## 1.0.0

- 从内置实现迁为可选社区模块，自带「手机端」面板，沿用原设备数据和独立监听端口。
- 保留网页版 DSH 风格、主角卡片、聊天/DSH/设置、历史、图片/表情/语音、扫码和通知 Service Worker。界面和功能设计来自 Emotionana 的安卓 App。
- 通过 Aurabot 1.3.0 的通用流水事件、主人输入、媒体 API 和面板路由保护访问本体，不直接导入本体源码。
- 提供局域网地址选择、一次性二维码、设备撤销、HTTPS 路径配置与 Tailscale 使用说明。
- 迁移协议和网页交互测试到 `test/`，用模块库的 `scripts/plugin-env.mjs` 运行；本轮未执行测试。
