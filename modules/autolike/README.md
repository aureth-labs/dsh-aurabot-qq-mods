# 自动回赞（autolike）

有人给「大肥鱼」的 QQ 资料卡点赞，她就顺手给那个人也点几下。纯 OneBot 的 `notice` 事件 + `send_like`，不联网、不进聊天。

## 用法

- **自动**：收到「XX 赞了你的资料卡」这类 `notify/like` 事件，按设置回赞（默认每次 10 下）
- **主人说「赞我」「给我点赞」「点满」**：立刻给主人点赞，然后她照常回话（不拦消息）
- 主人发 `/回赞` 看状态：开着还是关着、一次几 下、今天已回多少人
- 主人发 `/回赞 20` 改每次点几下（1–50）

## 配置

| 设置项 | 默认 | 说明 |
|---|---|---|
| 开启自动回赞 | 开 | 关掉后只有「赞我」还会点 |
| 每次点几下 | 10 | 电脑端最多 50 下，超了自动截断 |
| 每天最多回赞多少人 | 200 | 按自然日重置 |
| 同一个人多少分钟内不重复回赞 | 30 | 防同一个人连点刷屏 |
| 只回爸爸的赞 | 关 | 打开后只给主人回赞 |

## 安全边界

- 只在**别人先赞她**之后回赞，不主动到处点赞
- 有每人冷却、每日上限，不会变成批量刷赞
- `target_id` 不是她自己的赞会直接忽略
- 不读 Cookie、不联网、不发消息（「赞我」那条也只是点赞，不额外发言）

## 会访问的网址

没有。只调本机 OneBot 网关的 `send_like`。
