# 自动回赞

有人给大肥鱼的资料点「赞」时，她顺手给对方的 QQ 也点一个（`send_like`），不回消息、不打扰。

## 能做什么

- **静默回赞**：收到「赞我」类的 notice（`notice_type=notify` + `sub_type=like`）就回赞对方，一句话都不发。
- **说一句就能点**：私聊或群里说「赞我」「给我点赞」「点满」，她直接给说话的人点。
- **一天一次不贪心**：同一个号当天已经被回过赞的话，再发「赞我」只回一句「别贪心哦 已经给你点过赞了」，不重复调用接口（QQ 每个号每天被点有上限，省着用）。
- **防刷**：同一个人 `cooldownMin` 分钟内不重复（默认 30 分钟），每天最多回 `maxPerDay` 个人（默认 200）。
- **`/回赞`**：看当前状态和今天回了几个人；`/回赞 10` 改每次点几下（1~50）。

## 设置

| 键 | 说明 | 默认 |
| --- | --- | --- |
| `enabled` | 开启自动回赞 | 开 |
| `times` | 每次点几下（1~50） | 10 |
| `maxPerDay` | 每天最多回赞多少人 | 200 |
| `cooldownMin` | 同一个人多少分钟内不重复 | 30 |
| `onlyOwner` | 只回主人的赞 | 关 |

## 说明

- 只通过 OneBot 的 `send_like` 调 QQ，不访问其他网络地址。
- QQ 一次最多认 20 下，多了会报「点赞数无效」，所以内部按 20 一批发；每个号每天被点也有上限，超了 QQ 会拒绝，她会如实告诉你没点上。
- 只在插件能收到「赞我」notice 的环境下自动回赞；收不到 notice 时可以靠「赞我」指令触发。
