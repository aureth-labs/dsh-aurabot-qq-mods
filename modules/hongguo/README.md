# 刷红果短剧（hongguo）

用专用浏览器刷红果短剧：看推荐、记下看过的，刷到好看的用 QQ 私聊告诉主人。

## 它怎么「看」一部剧

不是拿标题瞎猜，是真的播一遍：

1. 从几个榜单页汇总推荐池（每页约 20 部，去重后几十部）
2. 逐个开详情页，拿剧名 / 简介 / 封面
3. 开播放页 `/player/<series_id>`，**静音**真播 20~90 秒（随机，像真人）
4. 播放途中抓 3 帧画面（canvas → JPEG），空镜太小自动跳过
5. 顺手读这一集的真实热评（按点赞排序）
6. 把「画面帧 + 简介 + 热评」一起交给模型，让它自己判断好不好看、值不值得推

**只有真的觉得好看才分享**，觉得一般就不推 —— 不为了分享而分享。

如果模型看不懂画面（不支持视觉），会自动退回「简介 + 热评」，
并在结果里标出来（`sawFrames: false`），**不会假装看过**。

## 本机执行面

| 项 | 说明 |
|---|---|
| 浏览器 | 起一个独立资料目录的 Chrome（没装 Chrome 才用 Edge），走 CDP 控制 |
| 子进程 | `spawn` 浏览器；`taskkill` / `SIGKILL` 只杀自己起的那个 |
| 读什么 | 页面 DOM、cookie（仅 `hongguoduanju.com`）、video 帧 |
| 写什么 | 自己数据目录下的 `hongguo.json`、`edge-profile/` |
| 不做什么 | 不读其他文件、不改系统设置、不碰你平时的浏览器 |
| 平台 | Windows / macOS / Linux，Linux 无桌面需配 Xvfb |

浏览器窗口默认放在屏幕外 `(-2400, -2400)`，**不抢前台**；要处理验证码时在面板点「显示浏览器窗口」挪进来。

## 风控与停止条件

- 检测到验证码 / 滑块 → **当天停**，记录原因；在窗口里处理完验证后，点面板「现在刷一轮」可当场解除
- 榜单池只有几十部：全看过之后会挑「最久没看」的重看，不会因为没新剧就永久停摆
- 没登录 → 不刷，提示先去面板扫码
- 一部都没播起来（播放页没起来 / 一直停在 0）→ 明确说没看成，**不记成看过**
- 每天看剧数 / 分享数都有上限，**按自然日重置**（跨零点自动归零，不会看满一次就永久停摆）
- 上一轮失败（没登录 / 没新剧 / 风控）后 10 分钟内不再重试，不会每分钟把浏览器拉起来
- 面板里的数字输入被清空时按默认值跑（不会变成 0 秒停留或每 60 秒刷一轮）
- 试运行或总开关关着时，分享发不出去也**不算进配额**，展示墙不会记成「分享给你」

## 设置

- `intervalHours` 多久刷一轮（默认 4 小时）
- `perRun` 一轮看几部（默认 3）
- `maxWatchPerDay` 每天最多看几部（默认 12）
- `maxSharesPerDay` 每天最多分享几部（默认 3）
- `shareEnabled` 刷到好的就私聊发给我（默认开；关掉只自己看）
- `dwellMin` / `dwellMax` 每部停留秒数（默认 20~90，随机取中间值）
- `closeAfterRun` 刷完自动关浏览器（默认开；省内存，下一轮再冷启动，登录状态不受影响）
- `browserPath` 浏览器路径（留空自动找）
- `visionModel` 看画面用哪个模型（留空 = 跟聊天模型）

设置以**面板**为准：`config.json` 里手写的同名 `hongguo.*` 键会被面板值（含默认值）覆盖，改设置请直接在面板里改。
手动刷一轮与定时刷互斥；补封面 / 登录 / 显示窗口在刷剧进行中会提示「稍后再试」。

## 面板

- 显示墙：竖版海报网格，标出「看过 / 分享给你」、评分、她说的那句话
- 登录：扫码，登录态存在专用浏览器里，之后不用再登（扫码成功后窗口会自动收起）
- 自检：真播十几秒抓一帧问她画面里有什么 —— 一按就知道模型能不能看懂
- 补封面：老记录没海报的，按剧集链接去详情页取

## QQ 命令

`/hongguo` 手动刷一轮。

## 已知限制

- 本模块是从模块市场装的（目录里有 `.aurabot-source.json`），但代码已被本地修改：市场若有同名新版本并重装，会整目录覆盖这些修改，升级前先备份。
- 面板接口挂在 `/aurabot/api/ext/hongguo/*`，这个前缀不在宿主的「只允许本机」闸里（与内置 bili 模块同构）：同一台机器上的其它程序也能调它的路由。
- 「现在刷一轮」和 QQ 命令 `/hongguo` 是强制的，不受模块自己的「打开红果短剧」开关限制；试运行与插件总开关仍然管得住是否真发私聊。
- 自动挑浏览器的顺序是 Chrome → Edge（显式填了「浏览器路径」或设了 `CHROME_PATH` / `EDGE_PATH` 环境变量时以显式值为先）
