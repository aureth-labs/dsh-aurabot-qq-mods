# 群聊日报

每天到点，把当天所有群聊（可选含私聊）压成几条要点，私聊推给主人。

和「总结今天聊了什么」不同，它盯的是人做不到的事：**谁在发愁、哪句话被岔开没接住、什么事说定了却没落地。**

## 做什么

- **定时推送**：默认 22:30，读当天的聊天流水，按聊天分组、按活跃度分摊条数预算，交给模型挑要点
- **要点优先级**：有人卡住 > 话被岔开没解决 > 说定了没落地 > 谁能帮上谁 > 情绪与关系变化
- **/日报 命令**：立刻生成一份，不用等到点
- **失败可见**：失败会写清原因，连续 3 次放弃，只在到点后 3 小时内尝试，不会半夜反复重试

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| 每天定时推 | 开 | 关掉只停定时，`/日报` 仍可用 |
| 几点 / 几分 | 22 / 30 | 每天几点推 |
| 总字数预算（条） | 400 | 喂给模型的聊天条数上限，按各聊天活跃度自动摊 |
| 私聊也算进日报 | 开 | 关掉就只看群；和主人的私聊永远不算 |
| 语音记账文件（可选） | 空 | 填了就在日报末尾加一行「今天发了 N 条语音、花 X 积分」，按 `{date, count, used}` 读 |

## 会访问哪里

- 本机：读插件的聊天流水 `plugins-data/aurabot/chatlog/YYYY-MM-DD.jsonl`，写 `modules-data/digest/state.json`（只记「今天发过没有」）
- 可选：读你在面板里填的那个语音记账 JSON，读不到就跳过
- 不联网

## 能力说明

- `filesystem`：读聊天流水、写状态文件
- `plugin-config`：读 `api.config().ownerQQ`，决定推给谁、以及哪些私聊不该进日报
- `plugin-internals`：用 `api.core.hub.chatLogOf / groupName` 取当天流水和群名。这两个接口目前没有公开等价物，插件升级后可能失效（失效时日报会退回「今天还没有聊天记录」并报错，不会静默）
