# 双重人格

> 老实聊天，很枯燥吧。支持定时切换人格、随机切换人格……

给大肥鱼加一层「换人格卡」的调度：到点换、按月排班、按心情换、按概率掷骰子换；也可以给每个私聊、群聊配一张自己的默认人格，让不同聊天里的她像两个人。

所有配置都在面板里点，不用手写 JSON。

## 开没开看设置里的开关，模式二选一

「已安装 → 双重人格 → 设置」里有一个「**启用双重人格**」拨动开关，**默认关着**。关着的时候下面所有规则一律不生效，只有你手动切卡才会变。面板里不再重复放这个开关。

打开开关后，在面板顶部选一种模式，两种**互斥**，**默认是「人格分裂」**：

| 模式 | 干什么 | 规则要不要填范围 |
|---|---|---|
| 人格分裂（默认） | 每条规则只对「生效范围」里那几个私聊/群生效，**不碰全局人格卡** | **必须填**，不填这条规则就不生效（面板会标出来） |
| 全局人格切换 | 规则到点直接换**全局人格卡**，所有聊天一起变 | 不用填，填了也不看 |

- 两种模式下，定时 / 每月 / 心情 / 随机·固定 / 随机·临时 五节**一直都在**，不会再因为切模式被收起来。
- 分裂模式下，分裂表**紧跟在开关下面**，填完就生效，不需要再开别的开关。
- **人格分裂不依赖随机切换**：随机两种关着，分裂表也照样逐聊天生效。

## 五种规则

| 规则 | 触发时机 | 分裂模式下换的是 | 全局模式下换的是 |
|---|---|---|---|
| 定时 | 每天到点（可以配多个时刻）；当时没查到会在下次检查补上 | 范围里那几个聊天的本会话人格 | 全局人格卡 |
| 每月 | 每月指定的几天，从 0 点起 | 范围里那几个聊天的本会话人格 | 全局人格卡 |
| 心情 | 她的心情值落进某个区间 | 范围里那几个聊天的本会话人格 | 全局人格卡 |
| 随机·固定 | 每个会话开始时掷一次（只看范围里的会话） | 那个会话，一直用 | 默认只落当前会话；也可以选「全局」 |
| 随机·临时 | 每个会话开始时掷一次（只看范围里的会话） | 那个会话，只这一轮 | 只这一轮 |

说明：

- **生效范围**是一个文本框，填群号或私聊 QQ 号，一行可以填好几个；号码不带前缀时：是已知群号就算群，否则算私聊。面板会实时显示「→ 会落到哪些聊天」，认不出的号也会列出来。
- **全局人格卡**就是面板「人格卡」页里当前生效的那张，换了以后所有聊天都用新人格，下一轮生效。
- **本会话人格**用的是另一条路：不碰全局人格卡，而是每轮往那个会话的上下文里放一段「本会话人格」，让她在那个聊天里按这张卡说话。所以别的聊天不受影响，面板「人格卡」页也不会变。
- 定时 / 每月 / 心情 三种可以同时开；各自记「今天这个点已经执行过」，不会反复触发。
- 定时是「过了就补」：不要求恰好在那一分钟检查到。设置里「检查间隔」默认 60 秒，就算当时没查到、或者中间插件重启/卡顿，下一次检查也会把当天错过的档期补上（一次补多档时按时间顺序执行，最后生效的是最近那一档），每档一天只补一次。
- 随机两种在「人格分裂」模式下只落在当前会话，即使随机·固定里选了「全局」也不会真换卡（面板会提示）；范围外的聊天不掷。
- 分裂模式下，每个聊天最终用哪张卡按这个顺序定：本会话的临时人格（随机·临时掷中的）→ 本会话的随机·固定人格 / 定时 / 每月 / 心情 按范围定下来的 → 分裂表里给它单独配的卡 → 公共默认人格 → 全局人格卡。

## 人格分裂怎么配

打开总开关、模式是「人格分裂」时，开关下面就是这一节：

- **公共默认人格**：没单独设置的私聊、群都用这张；留空就继续用全局人格卡。
- **分组设置**：每一行左边一个文本框，填要单独设人格的 QQ 号，右边一个下拉选人格卡。一行里可以填多个号，用逗号、空格都行：
  - 群号直接填，比如 `170625223`；私聊号也直接填，比如 `1773199891`。
  - 拿不准是群还是私聊时，她按「是不是已知群号」来判断；想指定就加前缀：`group:170625223`、`私聊:1773199891`。
  - 同一个聊天被好几行命中时，**下面那一行算数**（后面的覆盖前面的）。
- 点底部的「**+ 新增一组**」加一行，行尾「删」去掉一行。
- 每行下面会立刻显示解析结果：「→ 群 大肥鱼、QQ 私聊 · void」或者「认不出：xxx」，保存前就能看出号码填没填对。

分裂靠的是每轮注入的「本会话人格」段，所以不需要等新会话建立，保存后下一轮就按新配置说话。

## 下拉框的初始值

所有要选人格卡的下拉（公共默认、分裂表每一行、定时的每个时刻、每月每一天、心情区间、随机人格池）在新增时**默认选中当前人格**，不需要先自己想一个。留空的行保存时也会补成当前人格，落库不会出现空值。

## 随机模式怎么算概率

1. 会话开始（这个聊天第一次出现在她面前的这一轮）时，先掷「总概率」：命中才继续，没命中这个会话就不换。
2. 命中后从「人格池」里按权重抽一个：权重是纯数字（默认 1），后台自动折算成每个人格命中的比例。
3. 同一会话只掷一次；换了新会话（她重置/新建了那边的会话）才会重新掷。

> 频繁切换人格会导致缓存命中率降低，可能导致额外的开销，请勿设置过高的触发概率。

## 面板

「已安装」→ 双重人格 → 面板，所有设置一屏平铺展开，从上到下：

1. **模式**：人格分裂 / 全局人格切换（分段按钮，点一下立刻保存；默认分裂）。
2. **人格分裂**（分裂模式下才显示）：公共默认人格 + 分组设置（号码文本框 + 人格下拉，可「+ 新增一组」）。
3. **定时 / 每月 / 心情**（两种模式都显示，每节开头都有「生效范围」文本框）：
   - 生效范围：填 QQ 号 / 群号，面板实时显示解析到哪些聊天；分裂模式下不填这条规则就不生效。
   - 定时：时间选择器 + 人格下拉，可加多个。
   - 每月：点 31 天里的哪天，再给这天选人格卡。
   - 心情：区间用「滑块 + 数字框」两种输入；心情值可以读插件的心情模块，也可以自己填一个固定值（默认 50）。
4. **随机·固定 / 随机·临时**：生效范围 + 总概率（默认固定 30%、临时 20%，滑块 + 数字框）与人格池（每行人格下拉 + 权重数字框，权重默认 1）；随机·固定的「作用范围（只当前会话 / 全局）」只在全局模式下出现。
5. **现在的状态**：当前人格、本会话单独开着的人格（可以逐个清掉）、最近 20 次切换记录，还有「立刻切到某张卡」。
6. **不用点保存**：跟插件里其它面板一样，改了就自动存（拖滑块时合并成一次），没有「保存」「重新读」按钮，刷新页面即从配置读回。开关在「已安装 → 双重人格 → 设置」里，关着时面板会提示「配好的规则等开关打开才生效」。

数值项的默认值：检查间隔 60 秒（可设 10–600），总概率固定 30% / 临时 20%，人格池权重 1，心情固定值 50，心情区间 0–100，定时新增行默认 08:00。

## 命令（主人私聊 / 群里都行）

- `/双重人格` —— 看现在开没开、哪种模式、人格和这个聊天的单独人格
- `/双重人格 切 暴躁鱼` —— 立刻换全局人格卡（下一轮生效）
- `/双重人格 重置` —— 清掉当前聊天单独的人格

## 面板接口与权限

- 四条面板接口（`/state` `/plan` `/apply` `/reset`）都声明成面板接口（`api.route(..., { access: 'panel' })`），由宿主的管理面闸先拦：默认只有本机能访问，要远端用必须在插件配置里打开 `security.panelRemoteAccess`
- 在这之上模块自己还保一道：只认回环地址（`127.0.0.1` / `::1`），进程内直调（面板自身、测试）才放行
- 命令（`/双重人格`）只对主人生效；面板接口能读会话标题清单、改全局人格卡与计划，所以都放在面板这一侧，聊天里的人调不到
- 模块没有任何对外发送能力：不会替她发消息，只换人格卡（全局）或往会话里注入一段人格覆盖文本

## 会访问哪里

- 读：`api.core.personas.list()` / `read(id)`（人格卡列表和正文）、`api.core.hub.sessions()`（只拿会话标题，用于列清单）、`api.config()`（白名单私聊 / 群）
- 写：`api.setConfig({ persona: { current } })`（全局换卡，等于在面板里换卡）
- 数据：计划（模式、分裂表、各规则）存在模块设置里（面板 / 「已安装 → 双重人格 → 设置」保存的那份），和面板上其它插件一样走 `api.saveSettings`；`plugins-data/aurabot/modules-data/dual-persona/state.json` 只放运行状态（各规则今天执行到哪儿、每个会话的临时人格、切换历史）。旧版本存在 `state.json` 里的计划会在启动时自动迁移到设置里。
- 不联网
- 能力声明：`filesystem`（读写信 `state.json`）、`plugin-config`（`api.config` / `api.setConfig` / `api.saveSettings`）、`plugin-internals`（`api.core.personas` / `api.core.hub` / `api.core.http.body`）。没有 `network`：全程不发起任何对外请求。
