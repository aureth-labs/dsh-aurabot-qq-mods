# 私人日记（local-diary）

每天让她自己写一篇 markdown 日记，**写给她自己看**。

不是「空间说说」，也不发给任何人——正文只落在本地文件夹里。模块的定位是记忆锚点：
上下文写满了、换了会话、换了电脑之后，她还能翻回来看看当时的一点一滴。

面板里有一个日记本：左边是按月份分组的目录（彩色圆点 = 当天心情，✦ = 写了愿望），右边是一整页日记纸，
藏青装订带、蝴蝶结、蕾丝边，按角色形象配色。目录顶部可以切「最新 / 最早」，也可以点「日历」按日期跳转（写了日记的那天按心情填色）。
正文底部有「← 前一篇 / 下一篇 →」，翻页时小鱼会摆一下尾巴；颜色规则的图例在目录底部。

## 怎么用

- **面板「私人日记」页**：开关、每天几点写、文件夹、补写昨天、镜像进备份、每轮带几篇线索，都在这里。
- **QQ 里发 `/日记`**：现在马上写一篇。
- **她主动翻旧账**：聊天时她自己会调用 `diary_read({ day, query, limit })`。

## 写什么、怎么写

素材全部来自本机已有的东西：

| 素材 | 来源 |
|---|---|
| 当天的聊天流水 | `chatlog/YYYY-MM-DD.jsonl`，默认取末尾 200 条 |
| 当时的心情 | 心情模块的 `contextLine()` |
| 今天看过什么 | 记忆库时间轴里 `kind: 'seen'` 的条目 |

正文完全交给她：**不限长度、不限格式**，可以只写一句，也可以写两千字。不套模板、不做隐私检查。

## 日记最后的「愿望」（可选，想许几个许几个）

写完日记，如果她当天确实有想许的愿，可以在最后写下来，**每个愿望单独一行，以「愿望：」开头**。**写不写、写几个、写什么，完全由她当次决定**——提示词里明确说了没有想许的就别写，不强迫、不补一个凑数。

- 认两种写法：`愿望：` 和 `心愿：`，前面带不带 `#` 标题都行；写了几条就收几条，重复的只记一次（最多 30 条）。
- 命中后写进文件头：`wish:` 是拼成一句的版本（兼容旧面板），写了不止一个时另有 `wishes:` 数组；也记在索引里。面板的目录行上会多一个 ✦，翻到那一页时日记纸上出现一张虚线框着的「愿望」便签，多个愿望按 1. 2. 3. 列出。
- 有愿望的那篇，回写记忆库时额外带上「那天我许的愿：……」（多个用「；」连起来），标签多一个 `愿望`。
- 没写就是没有，不会出现在文件头，也不会影响其它东西。
- 老版本只有单个 `wish:` 的日记照常能读，当作一个愿望。

## 写完她怎么记得

1. 整篇落到 `日记文件夹/YYYY-MM-DD.md`。
2. 正文前 240 字回写记忆库（标签 `私人日记`，来源 `diary`；有愿望时再附一句）。
3. 之后每轮聊天带上最近 3 篇的日期和开头（面板可关）。

## 设置项

| key | 默认 | 说明 |
|---|---|---|
| `on` | 开 | 每天自动写；关掉仍可发 `/日记` 手动写 |
| `at` | `23:30` | 每天几点写，24 小时制 |
| `catchUp` | 开 | 早上 7–9 点发现昨天没写，补一篇昨天的 |
| `dir` | 空 | 日记文件夹；空 = `modules-data/local-diary/diary/` |
| `mirror` | 开 | 文件夹改到外面时，把每篇再抄一份进 `archive/`，这样备份带得上 |
| `inject` | 开 | 每轮聊天带最近 3 篇的线索 |
| `maxRows` | `200` | 一次最多读多少条聊天流水 |

## 会碰到哪些东西

- **不联网**：模块自己不发任何网络请求，也不把内容发到任何服务器。
- **写文件**：日记正文、索引 `index.json`、状态 `state.json`，都在上面说的文件夹里。
- **启动程序**：面板上点「打开文件夹」时会调用系统文件管理器（Windows `explorer`、macOS `open`、Linux `xdg-open`）。
- **插件内部对象**：用了 `api.core.hub.chatLogOf()`（读当天聊天流水）和 `api.core.http.body()`（面板 POST 上来的 JSON），
  所以 `capabilities` 里声明了 `plugin-internals`——插件内部接口升级时这里可能要跟着改。
- **不调用** `runSubagentTurn`，不会 spawn 子智能体。

## 数据文件

| 文件 | 内容 |
|---|---|
| `diary/*.md` | 日记正文（默认位置） |
| `index.json` | 索引：日期、路径、字数、心情、开头 |
| `state.json` | 今天写没写、是否正在写、下次什么时候写 |
| `archive/` | 外部文件夹的镜像（`mirror` 开着时） |

## 备份

插件自带的备份会把 `modules/` 和 `modules-data/` 整个打包，所以**日记跟着备份一起走**。
如果日记文件夹改到了外面（比如 `Documents\我的日记`），把「镜像进备份」开着就行。

## 手写字体（可选）

面板默认用系统楷体（`STKaiti` / `KaiTi`）。想换成自己的手写体：

1. 把 ttf 放进模块目录的 `assets/hand.ttf`（老版本放模块根目录也认）。
2. 刷新面板。

字体不进仓库——各家字体的授权不一样，请自己确认能在你的机器上使用。

## 开发与测试

```bash
cd modules/local-diary
npm test        # node --test "test/*.test.mjs"，零依赖，不需要联网
```

测试用最小的假 api 把 `setup()` 跑起来（不连 QQ、不打网络，只写系统临时目录），覆盖：

- 日记落盘：`YYYY-MM-DD.md`、同日第二/第三篇编号 `-2` `-3`、旧文件不被覆盖、空内容不落文件；
- 索引与状态：`index.json` 逐篇记录，`state.json` 只存 `last`（运行标志只留在内存，写盘会把定时器卡死）、索引丢失后能重扫；
- 面板路由：`/read` 认 POST body 与 `?file=`，不在索引里的路径一律拒绝；`/status` 的篇数、排序、下次时间；`/hand.ttf` 缺字体时的提示；
- 目录配置：自定义文件夹、`mirror` 开关；
- 权限：`diary_read` 只发给主人私聊（`level === 'full'` 且非系统会话）。

## 注意

- 同一天写第二篇会往后编号（`2026-11-09-2.md`），不覆盖旧的。
- 日记是私人的：模块不会把正文发到 QQ，也不会主动发给主人。
- 索引丢了会在启动时自动重扫；面板上也有「重扫」。
