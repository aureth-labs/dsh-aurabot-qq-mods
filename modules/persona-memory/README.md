## 完整版审核稿

本次保留市场模块 ID `persona-memory`，拟从「人设记忆预览」0.1.0 更新到「记忆管理器」0.1.1。完整版包含人物档案、长期整理与召回、来源追溯、编辑与遗忘、旧资料接续、切回原生和按角色重置。安装后在「人物 / 记忆 / 设置」管理。

合并和上架前需要正式 Aurabot 记忆接管接口与 DSH 请求前投影接口。已发布的 1.3.0-rc.1 仅提供只读预览和确认送达，完整版在该宿主预检时会说明缺少的能力。清单最低版本是审核占位，须在依赖版本发布后更新并验证。 [Aurabot 接口跟踪 #445](https://github.com/aureth-labs/dsh-aurabot-qq/issues/445) · [会话归属 #466](https://github.com/aureth-labs/dsh-aurabot-qq/issues/466) · [DSH 请求扩展点](https://github.com/deepseek-ai/deepseek-harness/discussions/6850#discussioncomment-19655548)

已安装市场预览的用户可在受支持的宿主上沿用相同条目。预览只独立保存送达统计，原生记忆的接入由完整版的接续预览确认。手动安装的同名目录由市场安装器保护，转换需保留 `modules-data/persona-memory/` 并核对现有档案。

完整本地测试组合为带适配的 Aurabot 1.3.0-beta.1、DSH 0.2.0-rc.2 和 Node.js 24.18 起的 24.x。宿主及 SDK 适配随独立手动包交付，市场安装只更新模块目录。

## beta.8 玩家选项与兼容边界

常规额度改为每天最多16次、输入60000、输出12000，单次输出1600；节省为8次、输入24000、输出4000，单次1000。它们都是整理上限，不是固定消耗。普通聊天记忆注入上限不变。已有设置不会在安装时被覆盖；需要新档位时点“使用新版常规额度”并保存，自定义值继续保留。

人物页使用原生同源的QQ头像，加载失败显示名字首字。浏览按全部、私聊、群聊、角色经历筛选，空来源放入高级选项；来源展示中文名。重置先选角色，默认该角色全部互动，指定人物/群聊另选，所有角色和单来源放入高级。

重置会清除选定范围在统一档案中的原话、记忆、人物印象和工作状态，并停止复用旧上下文；下一条互动开新窗口。重置默认将明确属于所选范围的历史窗口移出左侧，并禁止旧会话继续使用；DSH日志保留。取消该勾选可保留窗口。普通工作区和其他角色不归档。设定内预写的称呼/关系、照片文件、外部平台内容、游戏存档、费用账本和备份保留。辅助心情/夜间/自驱状态无法细分到单个聊天，会连同该角色重新开始，确认页会说明。未知玩法的独立资料需另行适配，不能承诺抹掉任何模块的所有状态。

跨会话记忆与统一档案不能同时运行；预算管家1.2.0的当前适配可共用，但仍有独立的全局消费熔断。梗百科等独立注入可能增加token，识图/生图/玩法费用不属于增强整理额度。模块内可查看当前组合说明；升级或未知版本显示待复核。本批不自动卸载模块。
