# xiaoai music · 小爱音响接入

Windows 上的 Aurabot 家庭音箱模块：保存完整歌曲、管理顺序或随机歌单、跟随 Aurabot 当前人设的音箱对话，以及北京时间周期与一次提醒。小爱语音入口使用小米云对话记录轮询，并非本地麦克风接管。当前版本为 0.15.2。

## 使用条件与配置

- Aurabot 1.2.1 或以上、扩展 API v1；Node.js >=22.13；Windows 与 PowerShell。使用宿主内部接口，最低版本字段不等于已完成该版本实机兼容测试。
- 内置 `song` 模块；翻唱、TTS 所需环境、音色与模型由用户先在宿主配置。本模块复用已安装环境，不下载或安装可执行程序。
- 电脑与小爱音箱在同一局域网。已开发的设备路径为 L05C；其他型号未验证。播放和识别仍依赖小米服务，原生回答及轮询延迟可能存在。
- 默认网卡名为空。在家庭面板填写实际网卡名；支持首次扫码与已有账号更新；已有账号更新仍要求同一账号。先保存正确网卡；点击“扫码登录 / 更新登录”，在按钮下方显示二维码，用自己的小米账号完成授权，再进行连接检查。凭据保存在当前 Windows 用户的 Credential Manager，兼容项名为 `DBFriend/L05C/MiNA`。更新登录会更新该项，不会随插件包分发。
- 新安装先由用户填写并确认数据目录（建议非 C 盘），通过写入检查后才初始化歌库、歌单、入口游标、会话映射和提醒；选择前只有宿主可能建立的空元数据目录。已有明确 `resourceRoot` 或旧默认目录中的真实资料会继续使用，不强制迁移。“数据管理”的复制核验仅比较原资料目录；歌曲目录可通过下方“音乐目录”添加；不提供搬迁或路径重定位。
- 初始无音箱接入开关、歌曲或提醒计划。先配置网卡、音箱与宿主服务，再按需开启音箱接入入口。可编辑默认称呼“小伴”及同音候选，上传包不含独立家庭成员人设、卡片或编辑器。

## 功能入口

模块 ID 为 `xiaoai-music`，显示名为 `xiaoai music · 小爱音响接入`。面板为独立页面；在 Aurabot 1.2.1 原版宿主中显示于系统分组。模块不会自行修改宿主导航文件。

### 首次使用

1. 填写完整保存目录并确认。这里只做首次定位，不覆盖已有模块资料，也不搬迁旧目录。
2. 选择与音箱同一局域网的电脑网卡，保存连接设置，再扫码。首次使用不需要预先手工写入凭据；多台音箱会列出设备，只能选择受支持且在线的 L05C。验证与保存后点击“检查登录与连接”。
3. 保存主要称呼；AI 补词是可选项，未配置模型时可直接手动填写。
4. 查看功能配置状态，完成基础设置。不会自动开启接入或试播。原曲功能不要求模型和翻唱音色；语音对话和提醒需要模型及语音，翻唱需要音色与对应环境。功能检查仅检查配置，实际下载、合成、扫码和播报仍以实机结果为准。

未完成配置时关闭业务入口；重新进入可继续使用已选目录和已保存称呼。修改网卡或设备后需要重新检查连接。配置完成后，“数据管理”保留原资料目录的复制核验；“音乐目录”管理多处歌曲位置。

### 主称呼与 AI 补足

先填写“主要称呼”，再点击“AI 补足同音词”。调用宿主当前模型，要求至少 10 个、最多 20 个同音或常见 ASR 近音变体。结果数量与格式不足时提示重试，不编造补齐。显示候选后可选择“采用候选到草稿”或“保留原稿”；采用后仍可手动增删编辑，点击“保存称呼”才生效。总称呼上限 30 个，主称呼排第一。模型候选需用户按实际识别结果筛选，不保证每一项都是真正同音。

可设置只说称呼时的应答文字，留空时使用“我在”。保存后使用宿主当前语音设置生成应答；生成成功后可在电脑试听。语音已配置时，模块启动或相关配置变化也会尝试预先生成应答。使用在线语音服务时，应答文字会发送至所选服务。具体声音与设备播放效果以实机验证为准。

此交互参照 Aurabot 1.2.1 人设 AI 润色的“生成候选→选择采用→另行保存”，并不调用或捆绑其人设编辑功能。


在模块自定义面板搜索选版、保存原曲／翻唱、整理歌单，使用顺序／随机、上一轮停止后的重新播放、下一首、暂停、继续与停止。翻唱音色默认跟随宿主翻唱设置，对话声音跟随宿主语音设置。

显式唤醒示例：“小爱同学，小伴播放小星星”。通过 `xiaoai_music` 工具可查询曲库和控制播放；`xiaoai_reminder` 管理一次及日、周、月提醒。指定已保存成品 ID 时准确播放该版本；按歌曲名或来源查询到多个成品时需要进一步选择，不会自动生成默认翻唱。接口检查主人来源；本地管理修改要求同源 JSON POST。提醒可先文字预览再保存，到时会按用户启用的计划调用音箱。关闭音箱接入入口会停止接收并释放本模块播放。

会话映射会持久保存；对话和提醒读取宿主当前人设，不另存人设正文。语音无法可靠识别说话人，不将称呼当作身份认证。长期分类记忆、随机主动关心及保存位置自动迁移未在本版提供。

### 音乐目录

“全部歌曲”上方提供目录管理。选择“全部目录”汇总查看，也可选择单个目录；“添加 / 管理目录”中填写已有文件夹的完整路径，点击“添加目录”。支持本模块生成的曲库及普通 MP3、WAV、OGG 文件夹，递归读取子文件夹，跳过链接。普通音频需要已安装的 ffmpeg（优先使用宿主翻唱环境，也可使用系统 PATH），无法读取的文件显示跳过数量；不会自动安装依赖。

外部音乐直接建立索引，不复制、不修改或删除原文件；可本地播放、加入歌单、交给音箱播放。普通文件以文件名作为标题，按内容识别重复；模块成品保留原有版本 ID。新增原曲与翻唱仍写入标注的“新增歌曲保存目录”。更新目录前需停止本轮播放并等待生成结束。

目录离线、文件被删除或搬走时显示“找不到或无法读取”，歌单里无法匹配的记录也会显示出来。请先连接磁盘、恢复原文件，或通过“添加目录”重新加入现有位置，再按需整理歌单。模块不搬家、不更新旧路径，也不按同名歌曲猜测关联。已有相同成品 ID 或相同普通音频可能在重新添加后继续匹配；清除前可先重新添加目录。

“一键清除失效歌曲”重新检查全部曲库和歌单引用，只清除所有已添加位置都找不到文件的记录，同时从歌单移除；不删除、移动或改写音频及歌曲信息文件。任一已添加目录仍有副本就保留。请先连接移动硬盘：临时离线且没有其他可用副本的歌曲也会被视为失效。访问权限不足会停止清理，不当成文件不存在；内容变化但仍存在的文件不会因本按钮被清除。

外部目录视图不能删除磁盘文件。同一成品同时在主目录和外部目录时，若确需删除主目录副本，先选择“新增歌曲保存目录”再使用单曲删除；该操作的确认框会说明删除文件及移除歌单引用。它与清除失效记录是不同操作。

新增原曲与翻唱仍保存到原主目录；主目录被搬走时，须恢复原保存目录后才能继续生成。歌单、称呼、提醒及会话资料保持原位置。“数据管理”的复制核验仍只检查原资料位置，不涵盖外部曲库。

### 定时提醒

在“类型”选择“周期”或“一次”。周期支持每天、每周（可多选星期）和每月；一次选择日期与时间，统一按北京时间执行。已经过去的日期时间不能新建。一次提醒执行后显示“已结束”，不会继续重复；取消后不再执行。提醒投送失败或执行中断也会结束本次计划，列表显示结果，不自动重播。

到时音箱忙碌或连接未恢复会等待；电脑和 Aurabot 需要保持运行，重启后尚未开始投送的到期提醒会继续等待可用时执行。提醒独立于语音接入开关。已有周期提醒保留，无需重新添加。

## 数据与联网

| 目标 | 用途及发送内容 |
| --- | --- |
| `account.xiaomi.com`、其扫码轮询子域（如 `*.lp.account.xiaomi.com`） | 小米扫码登录及令牌交换 |
| `api2.mina.mi.com`、`userprofile.mina.mi.com`、`api.io.mi.com` | 已登录账号的设备、语音记录与播放控制；携带必要小米登录信息 |
| `music.163.com` 及网易云返回的音频 CDN 地址 | 歌曲搜索、元信息、音源；由宿主 song 服务使用其配置的登录信息 |
| 宿主配置的模型服务 | 宿主当前人设、对话与工具结果、提醒提示词；AI 补足称呼时仅发送主称呼与已有变体，用于回答和提醒生成 |
| 宿主配置的语音服务／Microsoft Edge TTS 服务 | 待朗读文字及语音参数；Windows 本地 TTS 不需要此服务 |
| 本机与所选局域网音箱 | 临时音频 HTTP 传输，音箱须能访问电脑；本地试听仅允许回环访问 |

分离模型的手动下载参考链接可能指向 GitHub、Hugging Face 及 hf-mirror.com；本模块不自动安装这些程序。音频、音色模型、账号凭据、对话记录均不包含在发行包内。使用者应只处理有权使用的音频和音色。

## 能力声明

`network` 用于上述服务及音频传输；`filesystem` 用于持久数据和音频；`process` 用于 PowerShell 凭据访问与已安装的 Python／ffmpeg；`plugin-config` 读取宿主模型、语音、翻唱配置并保存模块设置；`plugin-internals` 使用宿主会话、工具、音频与 HTTP 接口。PowerShell 内含固定的 Windows 凭据 API 封装，不加载远程代码。

## 开发与验证

模块目录运行 `npm test`。仓库根目录运行 `npm run catalog`、`npm run check` 和 `npm run pack -- --only xiaoai-music`。测试使用隔离模拟服务和临时数据；通过不代表音箱听感、浏览器体验或真实宿主验收。
