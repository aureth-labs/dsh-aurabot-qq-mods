# 群聊话题边界

不想让机器人被连续追问带进敏感政治讨论？安装并启用这个模块后，它会尽量转开这类话题，仍可正常聊游戏、文学、日常新闻和生活常识。

## 怎么用

在模块市场安装「群聊话题边界」，确认模块已开启即可，无需填 Key 或配置服务。不需要时，在「已安装」中关闭它。

- **所有 QQ 群生效**，包括从私聊委托往群里发消息；普通私聊不受限制。
- 先提醒模型不要深入敏感政治人物、争议事件和人物影射，也不要把小说情节编成真实历史。
- 回复命中内置的明确词语时，改发「这个话题我就不展开啦，换个聊。」常规聊天回复转语音也在合成前检查。

## 哪些情况仍可能漏过或误拦

内置的是一小份固定中文词表，包含部分中国政治人物、历史事件及少量英文名称。它不拦「中国、历史、新闻、台湾」等泛词，但**命中词表的正常历史介绍、引用或同名内容也会被拦**。目前不提供按群或自定义词表设置。

隐晦影射仍依赖模型遵守规则；图片、视频和现成音频不做识别。其他模块直接发语音时，只能检查它提供的文字备注。这更适合希望少聊这类话题的群，不适合需要完整讨论政治、历史的群。

## 数据与运行

不额外调用模型，不自行联网或上传消息，不改人格文件、不删除聊天历史，也不记录群友政治倾向。正常聊天仍由原有模型服务处理。没有额外依赖，Windows、macOS、Linux 均可运行；目前只针对 QQ 群。

关闭后，不再添加话题规则或检查发送内容。已有聊天历史保留。
