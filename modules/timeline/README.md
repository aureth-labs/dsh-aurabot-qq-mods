# 时间线（timeline）

给 AI 伙伴建一份**自己的日程表**，让她在回答「你现在在做什么 / 几点 / 今天安排 / 考试放假」这类时间问题时，先查日程再回答，而不是即兴编一个时间。

它**不是提醒插件**：不主动发消息、不写定时提醒，因此不会和 `speakup` / `purpose` 抢职责。它只做两件事：

1. **回复前查日程**：命中时间/计划类话题时，把「当前块 + 下一块 + 今日剩余行程」注入她的上下文。
2. **让她自己查**：给她一个 `my_schedule` 工具，回答任何时间问题前先调用，以查到的为准。

## 为什么需要它

大模型在聊天里容易「编时间」：上一秒说在上课，下一秒又说在吃饭。时间线把日程固化成一份可追溯的 JSON，回答一律以查到的为准，就不会自相矛盾。

## 日程是怎么来的

按优先级叠加（后写的覆盖前面的）：

| 来源 | 说明 |
|---|---|
| 周模板 `week` | 「周一~周日」的常规作息，由 AI 按当前人格正文拟 |
| 月度计划 `monthly` | 每月固定的安排 |
| 当日覆盖 `overrides[日期]` | 今天临时改的安排，优先级最高 |
| 节假日 / 事件 | `holidays[日期]` 整天标为节假日；`events[日期]` 整天覆盖 |

## 换人格怎么办

周模板按**当前人格正文**拟。模块会读 `api.core.personas` 拿到当前人格卡，用正文里的作息线索（上课/上班/自由职业…）去拟一份贴合该身份的周表，并把身份标签记进 `meta`。

- **换人格时自动重建周表**（设置里默认开）：下次 60 秒轮询发现 `config.persona.current` 变了，就按新正文重排。
- 也可以手动触发：面板「时间线」页的**按人格重建周表**，或 QQ 里发 `/timeline 重建模板`。
- 内置了**通用周模板**兜底（起床/上午/午饭/午休/下午/晚饭/晚间/睡觉），即使模型没返回也能用。

## 怎么配置

在面板「扩展」页找到「时间线」，点开设置：

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用时间线 | 开 | 关了就不注入、也不给 `my_schedule` 工具 |
| 注入模式 | 按话题触发 | `按话题触发` 普通闲聊不注入；`每轮都注入`；`不注入（只留工具）` |
| 命中后注入今日行程到（点） | 22 | 命中话题后，把当天到该点的行程也注入 |
| 注入话题 | 一串关键词 | 命中任一关键词才注入，可自行增删 |
| 每天自动拟第二天日程 | 关 | 到点让 AI 拟一份草稿写进数据，不发消息 |
| 自动拟稿时间 | 23:30 | 自动拟稿的触发时间（北京时间） |
| 自动拟稿结果 | 只写草稿，要确认 | `只写草稿` 或 `直接生效` |
| 换人格时自动重建周模板 | 开 | 人格变更后自动重排周表 |
| 自动重建后处理 | 保留旧的当日安排 | `保留旧的当日安排` 或 `清掉旧overrides` |
| 称呼 | 大肥鱼 | 仅风格说明，身份以人格卡为准 |
| 城市 / 纬度 / 经度 | 南京 / 32.0603 / 118.7969 | 用于天气和计划 |

## 怎么用

**QQ 私聊命令**（主人可用）：

```
/timeline                 看今天的日程
/timeline 2026-11-10      看某一天的日程
/timeline 拟明天          让 AI 拟一份明天的草稿（到面板「应用」才生效）
/timeline 重建模板        按当前人格重排周一~周日的常规周表
/时间线 / 日程 / 安排      别名
```

**面板「时间线」页**：

- **人格与周表**：看当前人格、身份倾向、周表是否过时，点「按人格重建周表」
- **看某一天**：选日期看当天生效日程，标注当前块
- **日程 JSON 编辑器**：直接改整份 JSON，改完保存
- **AI 拟稿**：让 AI 拟某天草稿，列出最近草稿，点「应用到这一天」
- **动作日志**：追溯谁改了什么

## 数据在哪

全部在模块自己的数据目录：

```
plugins-data/aurabot/modules-data/timeline/timeline.json
```

里面是 `week`、`monthly`、`overrides`、`holidays`、`events`、`drafts`、`meta`、`log`。每次写入都会记一条日志，可追溯。

## 会访问哪里

| 访问 | 用途 | 失败会怎样 |
|---|---|---|
| `https://api.open-meteo.com/v1/forecast` | 拉当天天气，给 AI 拟稿做参考 | 8 秒超时后忽略，照常拟稿 |
| 由 AI 调用其自带的网页搜索工具 | 判断内置节假日表里没有的日期是不是假期/调休 | 判不出来就当普通工作日 |

天气和节假日信息**只用于拟稿参考**，不会主动发出去。日程数据只写在本地数据目录，不上报任何地址。

## 已知边界

- 只注入**主人私聊**。日程是她的现状，群聊不注入，避免为她造「人设/作息」外泄。
- 内置节假日表只覆盖 2026 年，其他年份靠 AI 判断或自己在面板的 `holidays` 里改。
- 模型拟稿需要插件已配置好可用的模型；模型不可用时会回退到内置通用模板。
