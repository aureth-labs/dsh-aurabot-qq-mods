# 豆包语音 2.0

用火山引擎「豆包语音 2.0」把大肥鱼的回复念成语音条，支持声音复刻音色和指令式情绪。
本模块与内置 `voice` 同名，安装后**替换内置语音**：聊天中枢发语音条时调用本模块的 `speak(text)`。

## 做什么

- 直接调用豆包语音 2.0 单向流式接口合成 WAV（拼接 NDJSON 分片、回填流式 WAV 头长度）。
- 按回复里的关键词自动追加语气指令（开心 / 难过 / 撒娇 / 安慰 …），也可在面板填固定语气指令。
- 合成失败时自动退回插件内置的 edge-tts / Windows 语音，不会让她突然不能说话。
- 保留内置语音页的试听、edge-tts 安装、语音识别自检接口；翻唱模块选过音色时语音条照样变声（RVC）。

## 配置

在面板「语音」页底部填写：

| 设置 | 说明 |
|---|---|
| 豆包语音 API Key | 火山引擎「豆包语音」控制台创建，作为请求头 `X-Api-Key`。密码字段，面板不回显、日志自动脱敏 |
| 资源 ID | 声音复刻音色用 `seed-icl-2.0`；预置 2.0 音色用 `seed-tts-2.0`。用错会报 `55000000` |
| 音色 Speaker | 复刻音色 ID（如 `S_xxxxxxxx`）；预置 2.0 音色以 `_uranus_bigtts` 结尾 |
| 语速 | 默认 0；觉得快可调 -10 ～ -20，下一条语音生效 |
| 固定语气指令 | 一行一条，例如「用温柔、放慢一点的语气说这句话」；留空不加 |
| 按文字自动配语气 | 按关键词自动追加语气指令，不参与计费 |
| 超时（秒） | 单次合成超时，默认 60 |

API Key 只保存在本机插件配置里，**不随模块分发**，仓库源码中没有任何密钥。

## 会访问哪里

- `https://openspeech.bytedance.com/api/v3/tts/unidirectional`（豆包语音合成，唯一的外部请求）。
- 合成失败兜底时，由插件内置引擎访问 edge-tts（微软在线朗读）或使用 Windows 本机语音；这部分是插件自身行为。

## 能力声明

- `network`：调用豆包语音接口。
- `filesystem`：把合成的 WAV 写到模块数据目录并清理旧缓存。
- `plugin-config`：读取插件配置与模块设置（音色、语速、语气等）。
- `plugin-internals`：用 `api.lib` 复用内置 TTS 兜底 / WAV 处理 / RVC 变声，用 `api.core`、`api.dsh` 提供面板接口。插件升级后这些内部接口可能变化。

## 替换内置语音 / 回滚

本模块 `replacesBuiltin: true`，安装即接管内置语音。想临时用回内置：面板「已安装」页给 `voice` 行打开「用内置的」；想彻底移除：删除模块文件夹。
