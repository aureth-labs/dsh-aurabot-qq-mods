# 昵称记忆

她会记住大家怎么称呼一个人，以后就用这个称呼叫对方；也可以自己给一直不知道怎么称呼的人起一个。

- 一个人可以有好几个叫法，**最新的那个是他现在的称呼**，旧叫法留着还能认出来
- 只记「谁叫谁什么」，不存聊天记录、不存原话
- 数据在 `plugins-data/aurabot/modules-data/nickname-memory/nicknames.json`

## 她怎么用

| 工具 | 干什么 |
|---|---|
| `nickname_learn` | 听到别人怎么叫某人，记下来；同名更新，新叫法顶掉旧的 |
| `nickname_who` | 查「老张」是谁、某个 QQ 号现在怎么称呼，或者看一眼称呼本里都有谁 |
| `nickname_give` | 给一个没称呼的人起个顺口的叫法 |

`person` 参数可以写 QQ 号，也可以写群里显示的名字（会拿群成员列表对）。

群聊里说话的人如果有记过的称呼，会附带一句「正在跟你说话的 12345，你叫他「老张」」，她自然就会这么叫；群里还会带上这个群记过的几个叫法。不想带这些提示就把「把称呼带进对话」关掉。

## 谁能看、谁能改

称呼本里是别人的 QQ 号和私下里的叫法，所以按说话的场合收了口：

| 场合 | 能看到 | 能记 |
|---|---|---|
| 主人私聊 | 整本（带 QQ 号、旧叫法） | 谁都能记 |
| 群里 | 只有**这个群**里记过的叫法，不带 QQ 号 | 只能记**这个群成员**的叫法，不能给主人起外号 |
| 别人的私聊 | 只有在那儿记过的叫法 | 不能改本子 |

- 「主人私聊」是指 `private:<主人QQ>` 这一侧；群聊里哪怕这一轮是主人在说话，群里其他人也看得见，所以仍然按群的规则来
- 群成员对不上时（比如机器人拿不到成员列表）宁可不记，也不猜
- 同一个聊天里 5 分钟内最多记 12 次，防止有人刷着改
- 「允许群友教她叫法」**默认关**：关着时群友说的叫法她还听得见（能拿来认人），但不落库，只有主人能改称呼本；要让她自己学，得在设置里显式打开

## 主人命令

| 命令 | 说明 |
|---|---|
| `/昵称` | 看记着哪些人 |
| `/昵称 查 老张` | 查这个叫法是谁 |
| `/昵称 设 1773199891 老张` | 手动设一个（QQ 号必须写） |
| `/昵称 删 老张` | 删掉这一个叫法（删的是现在的称呼时会退回上一个） |
| `/昵称 忘 1773199891` | 把这个人的叫法全忘掉 |

## 面板

面板里多一页「昵称记忆」，就是这本称呼本，可以直接改：

- 每行最上面是**现在的称呼**，改完按回车或点「保存」就生效（她下一轮就用新的）
- 后面的小标签是**以前叫过的名字**，点 × 删掉
- 「忘掉」把这个人整个删掉
- 顶上「QQ 号 + 怎么称呼他」可以加一条，右边能按 QQ 号或叫法搜

面板改的是同一份 `nicknames.json`，和她在聊天里记的完全一致。

### 面板接口的访问范围

这几条接口能读能写整本称呼本，所以四条都声明成**面板接口**（`api.route(..., { access: 'panel' })`），先过宿主的管理面闸：

- 默认只有本机能访问；要从别的机器用，得在插件配置里打开 `security.panelRemoteAccess`
- 在这之上，模块还保一道自己的判断：默认只认回环；要放开还要打开本模块的「允许非本机访问这个模块的面板接口」，两道都开才通
- 配了 `security.trustedProxy` 时，只认反代追加的最后一跳 XFF

模块自己的 `localReq()` 只是第二道，不再当唯一一道；进程内直调（面板自身、测试）没有 socket，放行。

## 设置

| 项 | 说明 |
|---|---|
| 启用昵称记忆 | 总开关 |
| 允许她自己起称呼 | 关掉后只能记别人用过的叫法 |
| 允许群友教她叫法 | **默认关**：只有主人能改称呼本；打开后群友也能让她记本群成员的叫法 |
| 把称呼带进对话 | 每轮提示她说话的人该怎么称呼 |
| 每人最多记几个叫法 | 超出的先忘最早那个（现在的称呼不算在内） |
| 允许非本机访问这个模块的面板接口 | 默认关，见上一节 |

## 怎么认人

- 先按 QQ 号（5~12 位数字）
- 再按称呼本里记过的叫法：完全一致才算，对上好几个人会让她给 QQ 号
- 群聊里再按群名片 / QQ 昵称：先完全一致，再唯一包含
- 都对不上就回一句「不知道是谁，给个 QQ 号」

## 叫法会被怎么清洗

- 全角转半角（NFKC），去掉换行、制表符和所有控制字符
- 去掉零宽字符、方向控制符（`\u200b`、`\u202e` 之类），避免名字里藏看不见的东西
- 去掉括号类（`「」『』【】[]<>《》`），免得名字和周围的字粘在一起、或在提示词里被当成结构
- 最多 24 个字，超了截断；写进提示词时再包上「」

## 会访问哪里

- 读写 `plugins-data/aurabot/modules-data/nickname-memory/nicknames.json`（本机文件）
- 群聊里取群成员列表（`get_group_member_list`，只在需要把名字对上 QQ 号时，5 分钟缓存）
- 不联网，不调用模型

