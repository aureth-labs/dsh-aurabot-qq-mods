# 观点

给她自己的看法，并且分两种：

- **核心（三观）**：原则、钱、承诺、关系、边界。很少改，注入时用「你一向认为……」。
- **普通**：可以商量、可以变的看法。注入时用「你目前觉得……」。

聊到相关话题时，先按语义召回候选，再让模型判断此刻说合不合适。

## 它怎么工作

1. 每条看法带一段向量（默认用本机 Ollama 的 `bge-m3`）。
2. 每轮把这句话也向量化，召回相似度高于 `recallFloor` 的候选（默认 0.45）。
3. 候选交给模型重排：判断这句话在做什么（陈述 / 请求 / 争吵 / 撒娇 / 问建议），
   再决定哪条看法此刻说出来合适。吵架、质问、赌气时，讲道理和下判断的看法一律不选。
4. 选中的最多注入 2 条，核心每轮最多 1 条。

如果重排关闭或失败，就退回相似度阈值（默认 0.7）。

## 需要什么

- 一个 **Ollama** 服务（默认 `http://127.0.0.1:11434/v1`），并且拉过 `bge-m3`：
  ```sh
  ollama pull bge-m3
  ```
- 想换别的嵌入模型也行：设置里改地址和模型名。维度变了会自动重建。

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | |
| 向量匹配 | 开 | 关掉就只按阈值 |
| 阈值 | 0.7 | 重排关闭/失败时用的相似度门槛 |
| 召回下限 | 0.45 | 低于这个不进候选，省一次模型调用 |
| 每轮最多注入 | 2 | |
| 核心每轮最多 | 1 | |
| 核心上限 | 12 | 超了要删或归档 |
| 普通上限 | 80 | 超了按最久没用归档 |
| 同话题上限 | 8 | |
| 地址 / 模型 | — | 跟随记忆模块的向量服务，不单独配置 |

## 面板

- **加一条看法**：手写一条，选核心/普通。
- **她现在的看法**：列表、删除、试匹配、重建向量、从记忆归纳。
- **试匹配**：输入一句话，看会匹配到哪条（按语义，不按关键词）。

## 网络与文件

- 向量服务**跟随记忆模块**（同一套 OpenAI 兼容嵌入接口）；记忆那边配好了，这边直接显示并使用
- 只连你配置的嵌入服务地址（默认本机）。
- 数据写在 `modules-data/beliefs/`：`beliefs.json` 和 `vectors.json`。
- 重排会用当前的聊天模型，多一次很小的调用。

## 注意

- 观点是「看法」，不是「知识」。归纳时会过滤教程、方法、打算做的事这类内容。
- 吵架场景不注入讲道理的看法，避免像在说教。
